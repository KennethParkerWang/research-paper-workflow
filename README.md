# Research Paper Workflow

中文科研流程 Skill，v0.1。按当前任务选择相关能力节点，覆盖从选题、假说、目标期刊、方法与证据，到论文写作、去 AI 化、独立审查和归档的 15 条主线。

## 获取与使用

在 [v0.1 Release](https://github.com/KennethParkerWang/research-paper-workflow/releases/tag/v0.1) 下载 `research-paper-workflow-v0.1.zip`。解压后得到 `research-paper-workflow` 文件夹，从其中的 [SKILL.md](SKILL.md) 进入，再按任务读取相关阶段手册。需要单独规划论文图件时，使用[论文图件制作模板](18-按模板编写论文/论文图件制作模板.md)。

本 Skill 提供流程和方法指导。实际研究中的事实、数据、领域方法、期刊要求与用户确认范围，仍须依据当前课题核定。ZIP 为可分享的发布包；本仓库文件与该包对应。
