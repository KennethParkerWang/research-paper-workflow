# 论文编写阶段详细手册

本阶段承接16提纲和15允许结论，制作准确、可审查的稿件；04格式资料与17期刊表达风格按需在此复用。

共用确认、独立验收、证据、回退和临时材料规则见[00阶段交接关系](../00-阶段交接关系/阶段交接关系.md)；当前任务从稿件实际缺口生成。

## 1. 中心职责、进入条件与够用程度

本阶段把[16科研叙事手册](../16-科研故事组织/科研叙事阶段详细手册.md)所规定的论证提纲，以及[15结论验证手册](../15-验证结论/结论验证阶段详细手册.md)所规定的允许结论，写成准确、连贯且可独立审查的当前初稿。图表、公式、文献和补充材料是稿件的组成部分，须与正文共享真实依据。18负责初稿表达与制作，后接独立的[23论文去AI化阶段](../23-论文去AI化/论文去AI化阶段详细手册.md)作表达诊断和保真改写；主张是否成立由15判断，论证路线由16组织，稿件的独立科学审查由[19](../19-独立审稿检查/独立审稿阶段详细手册.md)承担。示例内容不代替实际课题的有效输入。

| 进入时复用什么 | 在本阶段怎样使用 | 不能用写作补出来的东西 |
|---|---|---|
| 01问题与范围、02目标假说及有效确认 | 确定研究对象、问题用语与原先要回答什么；实际结果可以反驳原假说 | 把预期当作已经成立的结果 |
| 03已确认期刊、文章类型和要求说明，05必要证据校准 | 确定读者、篇幅与信息层级；只补查当前缺失或已变化的格式 | 重新选刊，或为了显得像目标期刊追加无关实验 |
| 06理论与方法、07/08计划、13实际执行与偏离 | 解释方法依据，描述实际过程与变化 | 根据结果倒填理想流程、预注册、采样理由或未做的操作 |
| 10资源来源、11实现及12正确性依据（适用时） | 准确描述数据、材料、设备、软件与推导身份 | 虚构版本、参数、许可、实现细节或证明步骤 |
| 14结果分析及现有证据索引 | 取当前有效数值、分析集、不确定性、异常与图表输入 | 从截图猜精确值、为了连贯藏掉负结果或失败 |
| 15允许结论与限制，16提纲与论点对应依据 | 把每一段的目的和表达强度写清楚 | 通过摘要、图题或动词把主张升级 |

输入不一定已经是漂亮的表格或固定文件。AI先读现有权威记录，识别其版本、位置和适用范围；交接不充分时补足关键说明，不能要求用户重新整理全部材料。研究无需代码、实验、统计图或假说检验时，相应输入注明不适用并说明理由。

本阶段够用的成果是一份能回答“研究问什么、实际怎样做、得到什么、允许如何解释”的当前稿件，以及确有用途的图表、公式、引用和补充材料。小贡献可以是一项有边界的应用改进、局部理论结果、复现、负结果、材料澄清或概念辨析；长度、图数和复杂度随职责与期刊要求决定。格式正确与科学正确是两个不同检查，排版完成不能替代19审查。

## 2. AI怎样带着用户进入写作，怎样处理不知道

### 2.1 先交代一条可写的路线

AI先用普通语言概括16已确定的路线，例如“先说明比较对象，再解释实际方法，随后报告主要结果与适用边界”，指出稿件将怎样组织。用户不会选图型、不会写英文或不知道模板怎么用时，AI依据研究对象与有效期刊要求提出首选做法，并给出必要的取舍说明；不要把“先写好引言”“先选图”“先找模板”变成用户的前置作业。

若现有材料支持几种合法表达，给可直接比较的小样例或段落方案，而不是泛问“喜欢什么风格”。例如可解释“方法细节集中成节便于复现”与“方法随论证分段出现便于理解”的区别，再依据文章类型先采用可行方案。只有选择会改变研究身份、主要主张、目标期刊、材料权限或交付范围时，才按00返回对应决定；普通章节排序和措辞修改可继续完成并供审查。

### 2.2 把缺信息按影响处理

| 未知或冲突 | 现在怎样解决 | 什么情况下可以后移 |
|---|---|---|
| 主要结果取哪个版本、分析对象是谁、分母是什么 | 对照14的有效输出和来源；冲突先交14核清，暂停依赖该值的句子与图 | 独立段落可以先写；关键结果不能带着猜值进入19 |
| 证明用了哪个假设、方法实际是否执行、引文是否支持主张 | 打开上游推导、执行记录或原文，定位具体缺口；必要时回06/12/13/15 | 与该问题无关的部分可写；关键科学空白不能用流畅文字掩盖 |
| 非关键背景的精确数字或过强“首次”说法 | 查原始出处；查不到可删除不必要数字、缩小背景表述或改为可验证事实 | 若不影响问题定位与贡献判断，可用有依据的较窄表达继续 |
| 期刊模板版本、初稿是否须严格排版 | 复用03资料，补开现行官方指南核查文章类型与阶段 | 可先形成可读的内部稿；暂缓最终格式声明与受其影响的导出 |
| 某引文只有摘要、图源身份或图片使用条件未知 | 标明核读范围；换成真正可核验的来源，或去掉依赖它的强主张/图 | 可保留内部待核标记，不得把该项写成已核实；不影响科学逻辑的装饰图可省略 |
| 作者信息、资助、数据访问声明尚无实际记录 | 从对应真实记录补取；AI不生成默认的“无冲突”“数据公开”等声明 | 内部稿可明确待核；需要这些信息的完整审查版本须说明未完成及影响 |
| 排版工具、配色、图的次要布局未定 | 沿用现有可编辑格式与工具，制作一个能读懂的版本后核查 | 不影响科学含义的美化可后移，不另设选工具阶段 |

待核内容只保留在当前稿件的既有备注或现有问题记录中，引用其权威依据；不为每个空白新建日志。AI给出“缺什么、影响哪一段、可用什么办法、做到哪一步够用”，无需用户先知道解决方案。需要新证据时，描述具体缺口并回相应阶段，不在18直接启动研究。

学习依据：K-Dense的[scientific-writing](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-writing/SKILL.md)把事实、真实方法与版本一致放在润色之前。本流程吸收这一原则；不移植其多份manifest、文本哈希、每句另请人核验、提交批准系统或强制工具脚手架，已有权威证据与00关口继续有效。

### 2.3 单段、单表、旧稿和改刊请求怎样直接进入

先读取用户实际交来的材料，按这次请求确定交付范围。完整科研链提供必要依据的位置，不能成为处理一个段落或表格前必须补齐的作业。没有15／16记录时，能做准确的语言、结构与格式改进；科学主张尚未核查的范围如实说明，不能在改写中替用户宣布成立。

| 用户当前请求 | AI先做什么，再交什么 |
|---|---|
| “把这段写清楚／翻成英文” | 读上下文和必要来源，识别对象、主张、证据与限定，修改对应段并解释影响含义的改动；不先重写全文 |
| “用这些结果做一个表” | 读实际结果和口径，提出首选行列与表注，制作可编辑第一版；缺关键单位／分母先查或问当前这一项，见6.12 |
| “已有稿，整理逻辑／缩短” | 先按16做需要的反向提纲，保留有效段落与事实；只调整相应结构和措辞，不补造新结果 |
| “按这个模板排版／转换格式” | 查看稿件和真实模板，映射结构、原生表与公式、引用和图源，先形成可读转换版，再查受影响对象；不能靠改后缀完成转换 |
| “改投另一刊” | 先按00处理实际目标期刊变更，复用有效科学内容；只更新变化的文章类型、篇幅、样式与必要要求。新要求涉及科学证据时提出具体缺口，不能当作排版自动补实验 |
| “从这些材料写一篇初稿” | 先整理可写依据与论证路线，提出最小可行提纲，再写有真实输入的部分；关键事实未知保留明确缺口，不用模板示例填充 |

## 3. 04格式资料与17风格：怎样适配已确认期刊

### 3.1 从官方入口核对格式，而不是重新选刊

沿用[03目标期刊阶段规则](../03-目标期刊与确认/目标期刊阶段规则.md)，从03留下的期刊官网与文章类型进入作者指南，区分初次提交、修订、接受后制作三个时点。核对与当前稿件有关的内容：可接受文章类型及章节，标题/摘要/关键词，字数和计数口径，匿名要求，行页号，图表与补充材料，公式及文献样式，当前可接受的文件格式。期刊要求只在原有期刊资料处维护；18引用其中适用条目，并在同一处补记来源、访问日期、模板名称/标示版本及相关变化。

只从期刊或出版社官方页面的链接取得必要模板；第三方模板仅能作为候选，须与官方要求核对。没有官方模板时按指南组织可编辑稿件。已有模板可用且要求未变时直接复用，不重复下载。模板中的示例姓名、结果、图、引文与声明是示例，不能留作真实信息。模板不自动决定研究结构：先把16的有效内容映射到必需位置，再处理样式。

官方指南与旧模板、旧样文冲突时，先核对是否属于不同文章类型或投稿阶段，再查当前官方说明；仍未解决的规则注明待核，保留可读内部稿。不能任选一条方便的规则宣称合规，也不默认把所有来源最严格的要求合并。若现有文章类型确实无法容纳研究身份，把差异交03/05/16处理，不靠改名把综述伪装成原创实证研究。

可用网站操作例子：PLOS的[LaTeX页](https://journals.plos.org/plosone/s/latex)提供官方模板及配套参考文献样式，页面区分初稿PDF与接受后的源文件。实际课题可从该类官方入口检查压缩包说明和版本，先保存到现有格式资料位置，再映射稿件内容。本轮只阅读入口和指南，未下载或应用模板；PLOS也不是本流程已选期刊。

### 3.2 从相关文章学习表达，分清硬要求与习惯

复用03已读的同刊相关论文，必要时补读同文章类型、相近方法与读者的少量代表文章。观察引言需要哪些背景，术语何时定义，方法怎样交代，图表在何处被解释，讨论怎样限制外推，摘要写多具体。把建议写成“可借鉴的表达及理由”，不把已发表个别文章的图数、引用数、夸张标题或遗漏当作规则。

风格学习服务读者：窄领域稿件可以简化共同基础，跨学科读者需要定义关键概念；短通讯压缩次要细节但保留主要证据与条件；质性结果可以将解释与材料相邻呈现。不能为了模仿顶刊叙事，把范围明确的小贡献拔高为普遍机制或通用平台。保持原先术语、测量和结论强度，允许用更清楚的段落与图注表达。

期刊特定风格须按当前目标和文章类型核查。可学习[Ten simple rules for structuring papers](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005619)中的读者视角、相关内容相邻与稳定用词；其写作结构是建议，不是全部领域的强制章法。

## 4. 按研究类型组织稿件，不统一套IMRAD

先确认文章身份，再依据16提纲映射内容。IMRAD适合不少原创实证文章；章节合并、结果与讨论交织、先理论后应用或按史料问题组织，都应服从研究逻辑与现行期刊要求。下面是选择路线的依据，不是新建一组固定模板。

| 研究或贡献路线 | 表达时需要交代的主干 | 特有核查与可缩减内容 |
|---|---|---|
| 理论、数学、形式方法 | 问题与已有结果 → 定义和假设 → 主要命题 → 证明/构造 → 特例、反例与适用边界 | 区分定理、猜想、经验观察；证明中使用的假设显式出现。没有实证验证时不生造“实验”节 |
| 定量实验、观察、计算、应用改进 | 问题 → 实际设计与测量/实现 → 结果与不确定性 → 解释和限制 | 对照、样本/运行单位、分析集、参数、偏离与结果一致；应用改进只声称实际情境内的改善 |
| 质性、访谈、民族志、案例 | 研究问题和立场 → 情境、取材与解释过程 → 主题/案例证据及差异 → 解释与可迁移边界 | 说明研究者角色和反思，展示材料怎样支撑解释；不把被提到次数写成总体发生率，不机械补统计显著性 |
| 档案、历史、文本考据 | 争点与背景 → 史料来源及批判方法 → 围绕问题的材料和论证 → 其他解释、缺失与范围 | 原件/抄本/译本/后人研究分清；引注能定位档案与版本，不能把资料未保存写成事件未发生 |
| 概念、理论综合或辨析 | 问题化与概念边界 → 文献/理论选择与角色 → 综合、修正、分类或模型的论证 → 命题及适用条件 | 命题或框架尚未被经验检验时明确其身份；不用“已证实”包装合理推论，也不把列举文献当成论证 |
| 系统综述、范围综述及证据综合 | 综述问题 → 实际检索、选择、提取和综合过程 → 纳入证据与综合结果 → 证据限制和解释 | 按实际类型选报告指南与扩展；研究与报告数量分清，检索日期、排除和偏倚判断可追溯，不把叙述综述宣称为系统综述 |
| 复现、负结果、短技术说明或局部修正 | 精确对象与必要背景 → 可检验的实施/证明范围 → 已完成结果 → 差异、边界及用途 | 聚焦一个可审查贡献即可；无须为了篇幅填满章节或增加图。负结果仍须如实写方法能力和不确定性 |

质性报告可通过[EQUATOR的SRQR入口](https://www.equator-network.org/reporting-guidelines/srqr/)查原文与相关材料；[SRQR原论文](https://med.stanford.edu/content/dam/sm/chri2/documents/O%27Brien%20et%20al.%20-%202014%20-%20Standards%20for%20Reporting%20Qualitative%20Research%20A%20Sy.pdf)明确报告内容应适应范式、研究和读者，不能成为僵硬格式。历史路线的证据定位与反向材料可参考[AHA标准第2、3节](https://www.historians.org/resource/statement-on-standards-of-professional-conduct/)。[Jaakkola的概念文章方法论文](https://link.springer.com/article/10.1007/s13162-020-00161-0)讨论理论综合、理论适配、分类与模型四条路线；这来自营销领域，可借鉴理论角色的说明，不作为其他学科唯一分类。

实际课题若需报告规范，从研究设计与03要求找适用指南，再核对条目在稿件的位置与不适用原因。通过清单只说明报告内容覆盖，不能证明设计正确或结果可靠。PRISMA主指南和不同扩展有适用范围；应从[官方清单页](https://www.prisma-statement.org/prisma-2020-checklist)进入扩展说明及解释文件，不能给全部文献综述统一加流程图。本轮精读其扩展清单中的标题、检索、选择、提取与展示相关项；未执行真实综述。

## 5. 把提纲写成正文：各部分怎样落笔与核查

### 5.1 引言：背景、近邻、缺口与贡献相接

从读者理解当前问题所需的最小背景开始。背景事实必须有真实来源，宽泛判断可缩小为具体对象、情境或文献范围；不为显得重要而加入无法支持的增长数据或社会价值。关键概念先定义，必要时说明同一术语在不同文献中的不同含义。

近邻工作使用与本研究同一比较轴，例如研究对象、任务条件、理论假设、证据类型或分析尺度。分别写已有工作做到什么、在什么条件下做到、当前工作实际补充什么；不同输入和协议的数值不能直接成为优劣排名。引用应覆盖真正相关的代表与相反观点，不按“必须近五年”“每段若干引用”等比例拼凑。

缺口来自01/02/06/16的有效判断和核读文献。写“在已检索的某范围中仍不清楚某条件”通常比未经充分检索的“从未有人研究”准确。若新阅读发现关键近邻已经回答问题，交16或更早阶段重新判断贡献；18不能删掉近邻或换措辞隐藏事实。

引言末尾说明本研究回答的问题、实际采用的路线及有边界的贡献。是否预告主要结果取决于文章类型与期刊习惯；预告使用15允许表述。不要求固定几段，也不以“首次”“全面”“突破”作为必要词。够用检查是：读者能理解问题、差异和研究承诺，后文确实兑现这些承诺。

### 5.2 理论与论证：把定义、假设、命题与依据写到可检查

复用06已验收的定义、模型、推导与12正确性记录，按16所需次序展开。区分符号定义、领域假设、方法选择和已经证明的命题；定义给出对象范围与边界，假设说明作用和何时可能不成立。引用现有定理时准确给出处、版本和适用条件，不省掉决定结论的前提。

主要命题要让读者知道“对什么对象，在什么条件下，得到什么结果”。证明给出关键步骤和所用引理，例子帮助理解但不代替普遍证明，数值试验也不能证明所有情形。证明太长时，正文保留命题、关键路径和必要假设，完整细节放确有用途的附录并精确引用；不能把有争议的核心步骤藏在未提供的补充材料里。

概念论证未必有公式。可以说明构念怎样区分、理论各自承担什么解释作用、关系为何可推出、在哪些条件下提出命题。示例仅作说明时明确其示例身份；机制箭头表达假设关系时在图注说明。写作发现逻辑缺口时先交06/12/15判断，必要时调整15结论和16提纲，再改正文，不自行添一条看似合理的假设。

### 5.3 方法：写实际执行，使结果能被评估

方法从13实际执行、10材料、11实现及14分析记录取事实。先给整体设计与理由，再交代适用内容：对象与来源，纳入/排除及选取过程，情境与时间，材料/设备/仪器/数据版本，操作、测量和变量定义，对照与偏倚控制，关键参数与依据，分析方法、缺失处理、转换、调整与敏感性检查。无需把所有脚本行和尝试过程塞进正文，但决定结果可解释性和复现的内容必须可找到。

把计划与实际分开：哪些按计划完成，哪些改过、何时改、理由及可能影响是什么；确认性、探索性、描述性和事后分析按真实身份写。不能因某分析结果漂亮而回写为预先规定。引用成熟方法仍须说明本研究采用的版本、关键设置与偏离，不能一句“按某文方法”遮住差异。

质性路线具体交代取材、情境、研究者角色、材料处理和形成解释的过程；用了迭代、饱和、三角互证或成员核查，须描述实际怎么做及依据，而不是列术语。不适用的方法不强制补做。档案路线说明材料选择、来历、版本、史料互证与缺失；概念路线说明理论与文献为何被选择及如何用于分析；证据综合说明真实检索、筛选、提取、质量/偏倚判断与综合办法。原方法已验收的事实直接引用，不在写作阶段重新执行取证。

够用检查是每一主要结果能找到对应的方法，具有相关经验的读者能够判断其实施与局限。新增加但尚无记录的分析不能直接写成做过：纯整理现有结果可留18，分析错误或补分析回14；需要新增研究的工作按00返回07/13等相应位置。

### 5.4 结果：写出观察、估计、差异与不确定，不替15裁决

按16已选的论证次序报告有效结果，不按实验日期堆流水账。每一段先说明读者正在看什么对象或比较，再给结果和图表位置，末尾可用15允许的窄表述概括。正文解释最关键的模式或数值，完整精确值由有用途的表或补充材料承载；同一份信息无需在正文、表、图全部逐值重复。

定量结果保留单位、分析集、独立观察/复现单位、分母、时间点、估计和不确定性定义。说明区间是SD、SE、置信区间、后验区间还是其他范围；不能将重复测量行数当作独立样本数，也不能只留显著性星号。统计显著、科学意义和实际用途分开，具体解释复用14/15判断，不把不显著写成等效或不存在作用。

负结果、可靠反证、异常、失败和不确定结果若影响解释，保留在相应主线或被明确引用的材料中。没有结果不等于零结果；质量不达标、方法失效、未测和真零用不同文字。若只有某条件下有效，呈现该条件以及不一致情形，不能只展示最好的一次。

质性结果以主题/案例的分析陈述连接真实引文、田野笔记或材料摘录，保留上下文、例外及材料身份；一段生动引文不能自动代表全部参与者。档案论证将史料说法、研究者解释和资料缺失分清，保留相反证据。理论结果区分已证明结论与示例、猜想；证据综合分清单个研究结果、综合估计及证据确定性。章节允许解释与结果相邻时仍须让读者辨认这几个层次。

### 5.5 讨论：意义、机制、应用与限制各有强度

开头用已经报告的结果回答研究问题，避免复制全部结果数值。与已有研究比较时核对研究对象、条件、测量、基线和结果身份；差异既可能来自机制，也可能来自设计、情境或不确定性，不能只挑支持的文献。15已考虑的竞争解释在文稿中保留必要的内容与条件，18负责写清楚。

机制表达按证据层级区分“实际检验并支持”“与某解释相容”“提出待检验解释”。应用说明实际适用对象、条件、投入与代价；小规模案例不能直接成为普遍推广建议。不能在讨论首次出现一项未经14记录的新结果、新对照或检验；需要时先回上游处理。

限制说具体原因及其影响，例如取材覆盖使解释只适用于某群体，测量误差可能影响某比较，某假设限制定理适用域，档案缺失使某段时期不可判断。没有依据时不猜偏差方向。可以说明能支持什么、暂时不能支持什么，以及真正必要的后续研究；“未来可做”与已经安排/实施的任务分开，不在18自动发布扩展实验。

### 5.6 结论：用允许的范围收束

是否独立设置结论节按文章类型和指南决定。收束须对应原问题和15的当前判断；对象、条件、时间、证据类型与不确定性不能在最后一段消失。可指出实际贡献与用途，不新增数据、引用依赖或普遍性承诺。若简化后改变了科学含义，就恢复必要限定。

例子仅说明措辞：已有判断是“在所研究情境中观察到关联”，结论不能润色为“建立了普遍因果机制”。理论命题依赖某假设，摘要和结论也要保留该前提或清楚限定对象。判定是否需要进一步降级仍回15；不会因为用户期待强结论就改写证据身份。

### 5.7 标题、摘要与关键词：压缩以后仍与正文一致

在正文有效内容稳定后核对标题和摘要，初写时可先有工作标题。标题准确命名对象、问题和实际贡献，必要时交代设计或研究类型；因果词、普遍性词、方法身份和“系统综述”等标签必须成立。没有通用的最佳字数、冒号模式或新颖性词汇。

摘要是可独立理解的缩略稿：问题/目的、实际方法或论证路线、主要结果、允许结论及必要条件。结构式与非结构式、字数、引用和缩写依期刊规定。定量摘要取同一分析集的主要估计与必要不确定性；质性摘要报告主要解释与情境，理论摘要概括命题与假设范围，证据综合保留综述类型及必要检索/综合身份。不要为填栏目编造数字；短摘要也不省略改变判断的条件。

关键词从研究对象、核心概念、方法和应用情境选择，采用领域确有使用的术语，按指南处理数量与受控词表。标题、摘要、关键词帮助正确检索；不塞入稿件没有研究的热点词。最后逐项与正文、图表、15结论对照，防止摘要保留旧值或较强旧说法。

本节综合项目上游职责，参考K-Dense的[结构与一致性配套](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-writing/references/imrad_structure.md)及[写作原则](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-writing/references/writing_principles.md)。这些原则支持事实忠实与章节间核对；本文的研究类型路线、具体任务边界和缺口处理是项目适配，不宣称所有研究都要采用同一写法。

## 6. 科学图表：从用途、数据语义到最终尺寸

整篇论文的图位、数量、领域惯例、配色、生图参考与结果绘制按独立的[论文图件制作模板](论文图件制作模板.md)组织。本节保留数据忠实、图注、来源及局部制作的详细办法。解释性图默认调用生图模型制作供用户重绘的参考稿；结果图从真实数据和代码绘制，原始证据图沿用真实素材。使用时继续检索目标领域、期刊与外部方法／Skill，不限于本流程已收录来源。

### 6.1 先决定有没有必要展示，再选形式

AI从16论点及14结果主动提出一组有独立用途的候选图位，说明每张图帮助读者完成什么判断，再按稿型、版面和重复程度选出合适而充分的正式图组。用户不知道图怎么做时，不要求先选软件、色板和布局；先给科学含义明确的图表方案，核对源数据和对象，再制作。只有数个关键事实时正文可能够用，精确查值与多维比较通常用表，模式/分布/关系/空间/过程通常用图。图数不作为论文质量标准。

| 想让读者理解什么 | 可选形式及为何采用 | 制作前必须明确 |
|---|---|---|
| 背景对象、装置、材料或数据结构 | 真实照片、界面、字段摘录、结构示意；帮助识别对象 | 真实素材身份、尺度/方向、版本与引用；示意不能冒充实物或实施证据 |
| 已有方法的关系、机制或新方法流程 | 有科学语义的分类、关系图或流程图 | 并列、包含、顺序、依赖和因果分别画；不把发布时间当继承关系，不把相关当因果 |
| 个体分布、群体差异与离散程度 | 点图、分布图、适当箱线/小提琴图或精确表 | 独立单位、样本数、分布摘要定义；样本很小时复杂密度图可能制造稳定分布的错觉 |
| 两个变量的关系 | 散点、分组趋势、已有模型曲线 | 点代表什么、拟合来源、区间及异常；散点关系不自动是机制证据 |
| 时间或有序条件中的变化 | 轨迹/折线、区间带、分面 | 时间是否连续、个体还是聚合、缺测、独立性；不静默跨缺失点连线 |
| 类别或方法的数量比较 | 点估计与区间、适当柱图/表 | 比较基准与单位；用长度/面积编码时基线有明确意义，不能靠截断夸大 |
| 大矩阵、空间模式或连续场 | 热图、地图、等值/剖面图 | 色标、单位、投影/坐标、归一化、缺失与中心；不同色标不能伪装同尺度比较 |
| 质性主题、案例或史料关系 | 主题—材料表、案例并置、来源关系/时间图 | 引文上下文与定位、类别依据、例外；材料数量不直接成为总体频率 |
| 理论条件、概念分类与证明结构 | 定义/条件表、关系图、构造或反例示意 | 假设关系与已证明关系区分；无数据时不制作伪量化曲线 |
| 证据综合中的选择与估计 | 适用指南的流程图、证据表、符合已做分析的估计图 | 研究/报告计数、纳排原因、估计来源与不确定性；不补造未做的合并分析 |

图型须服从问题而非惯用软件默认值。[Ten Simple Rules for Better Figures](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003833)强调读者、表达目的、媒介、图注和避免误导；本流程把这些原则用于选择展示的职责，不把“第一眼突出结论”解释为可以夸张证据。介绍图还须核对对象与关系，保留真实素材、概念示意与测量结果的身份差别。

### 6.2 每个保留图表都能返回原始依据

制作前在既有结果/素材索引里引用：原始表或图像的位置和版本，用了哪些观察/样本/史料，相关分析及处理，输出图件及可编辑源的位置。派生数据、过滤、聚合、归一化、分箱、平滑、图像调整和组合关系要可找到；优先复用14及原实现记录，不再创建独立图表manifest或复制原始数据。

图像结果保留原始文件与原分辨率。裁剪、局部放大、通道映射、亮度/对比度等处理应有科学用途、说明范围，并对比较对象按可比原则处理；不能擦除背景、克隆特征、移动对象或只增强有利区域。拼接不同视野、时间、曝光、样本或来源时，图上有清楚分界，图注交代，不能造成同一次观测的印象。原图与改绘/生成概念图分别注明；概念图不提供测量证据。

他人已有图的原图引用、局部截取、改绘和重新绘制各有身份，核读其科学内容并按实际条件记录出处和使用依据；引文存在不自动说明素材可用。缺少原数据时不能从图片反推并冒充真实原始数据。只有公开图可用时，可以明确引用/展示其原图范围，或只做经过核实的定性说明。

官方图像处理示例见[PLOS Figures](https://journals.plos.org/plosone/s/figures)中的图像完整性段。本流程借鉴保留原图与公开处理的原则，不将其具体实验图规定自动用于每种图；原数据检查与统计/理论判断继续由相关上游负责。

### 6.3 数据编码与不确定性：先读懂量，再画量

逐项明确变量、单位、尺度、分母、样本/重复单位、时间和分析集。缺测、未测、检测限、排除、真零用不同符号或缺口；图例/图注说明其含义。不能把数据缺失填为零，不通过平滑线制造不存在的观测。

坐标和颜色变换注明依据：线性/对数轴及必要的零/负值处理，归一化参照与公式，基线和轴范围，平滑/分箱方法。共同尺度用于直接比较；确需不同尺度时让差异可辨认。用面积表示数量按面积缩放，不能按半径直接放大。双轴确有用途时分别标清对象与单位、说明关系，不能调整范围人为造出相关性；通常可用对齐的上下两图减少歧义。

估计的不确定性与个体离散程度是不同信息。用区间时注明类别、区间水平、计算方法与独立单位；原有分析怎样处理重复测量或层级结构，展示就怎样继承，不在绘图软件里另算一个不匹配区间。显著性标记必须对应已记录检验及多重比较安排，不能替代区间和实际差异。理论、概念或质性图没有估计量时，不强制添加误差条。

色彩承担语义：无序类别用可区分类别编码，有序量用有序色阶，确有中心的偏差量才用发散色阶，周期变量按周期语义处理。类别身份在全稿保持一致。用形状、线型、纹理、直接标签或分面补足颜色，使黑白或辨色困难的读者也能判断；不把灰度检查当作全部可访问性证明。

上述核查方法参考[scientific-visualization正文](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-visualization/SKILL.md)及其[Publication Figure Principles](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-visualization/references/publication_guidelines.md)。本流程保留数据语义与实际导出检查，未采用其软件版本硬钉、脚本、额外manifest或默认尺寸。

### 6.4 单图、组合图与信息层级

一图围绕一个必要比较或关系，复杂内容可按子问题分成面板。组合前检查每个面板独立可读，组合后说明其整体作用。a/b/c等标记、组名、颜色与顺序在图、图注及正文中对应；比较面板按可比尺度排列，必要的尺度差异明确标出。主信息是对象、数据/关系、比较与必要不确定性；次信息是辅助条件或局部放大；完整推理放图注与正文，不塞入装饰性口号。

同一数据的整体与局部图须说明放大区域及尺度，不能让局部选择变成全局代表。图像面板带有正确的尺度条、方向/通道或样本标识（适用时）；尺度条从校准得到，不只写显微镜放大倍率。多来源组合逐项保留身份和出处，不共用一个含糊的来源标签。

图内文字控制到读者能识别对象、编码与条件的程度；术语、坐标、单位、必要数字、公式和面板标记可以保留。没有方向关系不用箭头，没有空间语义不做地图，没有循环不画环。方法图清楚区分输入、实际步骤和输出；若某模块尚未实施，说明其方案身份。展示结果用标准绘图/图形编辑工具和真实输入，生成模型不能猜值或重画测量证据。

### 6.5 图注、表注与正文位置

图注回答“展示什么、每个面板是什么、怎样读、数据与处理是什么、关键限制是什么”。按适用情况交代对象与条件，符号/线型/颜色，单位、样本数与独立单位，误差/区间含义，必要分析和处理，来源与素材身份。完整方法可精确指向方法节，图注保留独立理解所需内容；不能只写“结果见图”。图题/图注的陈述强度不超过15允许结论。

表用于查精确值时，列名/行名写清对象和单位，必要脚注说明分母、分析集、缩写、区间和缺失代码。数值精度与测量/分析一致，百分数与分母可以核对；空白、破折号、零和不适用不能混用。保留可编辑单元格，不把本可编辑的普通数值表截成图片，也不靠空格/回车对齐列。

在正文首次需要读者查看图/表的位置进行明确引用，再说明它对当前论点的作用；不要写“下图”“右边”依赖布局。编号、面板、图注、文件名与交叉引用同步更新。阅读顺序、是否内嵌、图注集中或邻近、表注上下位置、主图与补充图编号依目标期刊的当前规则；内部审查版可采用便于审阅的排布并标明身份。

例如[PLOS Tables](https://journals.plos.org/plosone/s/tables)要求普通表为可编辑单元格，并规定正文首次引用后的放置与编号；其Figures页要求图文件、图注与文内引用一致。实际操作是用编辑器的表格/题注/交叉引用功能组织内容，再核对导出的阅读顺序，不把PLOS的具体位置规则当作通用规定。

### 6.6 尺寸、导出与最终尺度核查

先确定实际用途、期刊、文章类型、阶段、图类型和最终宽度，再选格式、像素与字体。暂时未知时制作可读的内部图并标记尚待确认的格式项；不规定所有图一律300 dpi。结果图保留可重绘代码，解释性图保留提示、参考稿及用户重绘依据，照片/测量图按原始像素与科学细节处理；混合图同时核查其中最弱的必要元素。把位图放进矢量容器也不会增加真实细节，格式后缀不能保证质量。

位图需要的像素宽度按“最终宽度（英寸）×所需每英寸像素”估算。仅改dpi元数据或放大像素不增加真实细节。说明性例子：1800像素图以150毫米宽显示，有效分辨率约305 ppi；这是计算示例，不是本流程要求或研究结果。组合图以最弱的必要元素检查，不能把低清截图放进高dpi画布后宣称改善。

目标要求优先于工具默认值。比如[PLOS图指南](https://journals.plos.org/plosone/s/figures)有自己的格式、尺寸、文本与分辨率要求；[Nature接受后制作指南](https://www.nature.com/nature/for-authors/final-submission)强调适用时点并区分摄影图与可编辑线图。两者只是说明要求会因期刊、图型与阶段而不同，不是推荐目标或统一技术标准。官方页互有冲突或来源时间不明时，先查适用范围并记录待核，不挑一个数字覆盖全部输出。

选工具按图的身份：数据图沿用已验收分析环境与绘图代码；解释性关系图默认调用生图模型生成供用户重绘的参考稿，不默认制作矢量图；真实图像保留原件再作可说明的处理。Word、LaTeX或其他编辑环境沿用现有选择；需要制作真实稿件时再查所用工具的当前官方导出说明，不先指定全体课题都采用某个库、版本或软件包。

导出后实际打开文件，并在稿件最终宽度查看：文字/上下标/符号可读，线与点不会消失，图例和尺度条正确，无遮挡/裁切/空白异常，子图关系清楚，颜色在实际背景下可辨认，透明/字体/位图没有改变含义。检查格式、尺寸、色彩/透明要求和文件大小，同时核对图注与数据。交互悬停不能替代论文静态图的标签和必要数值；如交付交互图，同时保留可阅读的静态展示与数据定位。在线/可访问交付或期刊要求替代文字时，用简洁描述说明图型、变量、主要可见模式及必要例外，不引入新的科学结论；复杂图可配更长说明或可读数据表。网络交互还须核对无需只靠悬停或颜色就能取得必要信息。

技术检查工具只验证文件属性；不能判断坐标是否诚实、区间是否正确、图像处理是否忠实。期刊提供在线评估工具时也须手动查看其转换结果，实际上传材料按已有授权与材料条件处理。本轮未上传图像、使用在线评估器或宣称任何图已符合投稿要求。

### 6.7 只拿着数据、旧图或几段文字，也能接入绘图

用户说“帮我做论文图”时，先实际读取其表格、旧图、方法文字、原论文或已有稿件，判断这次要完成的是构思、提示词、制作、修改，还是一组图的组织。用户只请求一张图，不要求先重走01—16；本流程中的阶段关系用于寻找必要依据，不是强制补办全流程。已有分析图满足用途时直接复用，主要工作可能只是补注、调整尺寸或组合。

AI先用一句图外说明提出首选方案，例如“这张图用于比较同一对象处理前后的变化，我先保留每个对象的配对关系”；随后说明采用哪些材料、画哪些对象或量，以及先交付什么。用户不会选图型、不会描述审美时，AI主动给可查看的第一版。不要先问一串软件、颜色、布局、字体问题；需要用户作实质选择时，只问影响当前图的那一点。

| 当前不知道什么 | AI怎样处理到能继续 |
|---|---|
| 不知道这张图要说明什么 | 从相关段落、研究问题或材料提出一个明确用途；若材料同时支持不同用途，给出简短区别和首选，而不是先做一张包罗全部内容的图 |
| 数据列名、单位、配对关系或区间含义不明 | 先查表头、数据说明和现有分析；仍不清且会改变图义时问一个具体问题。可先做不依赖该项的部分，不能猜数值或误差条 |
| 只有旧图，没有可编辑源或原数据 | 先判断可忠实调整的范围：图外注释、尺寸和组合可继续；改数值、重算区间或精确重画须找依据。截图读取值若确有研究用途，须另说明提取方法与误差，不能当作原数据 |
| 尚未选刊或不知道最终尺寸 | 先按当前阅读用途做内部图，保留可调整源；只将最终格式项留待03／04核定，不因此阻止内容构思 |
| 只有方法文字，不知道画什么 | AI提取对象、操作、输入输出和关键关系，先提出内容草图；不要求用户预先画好结构或编好生图提示 |
| 用户说“像某篇论文那样” | 实际查看参考图，分辨想借鉴的是比较方式、信息层级还是视觉风格；保留本研究的内容和尺度，不复制不适用的结构或数值 |

### 6.8 按图的科学用途走不同的制作路径

以下是可组合的制作办法，不是每张图都要执行的固定任务表。各分支共用6.1—6.6的科学含义、图注和导出要求；只读取当前图实际需要的部分。

#### 数据结果图：从现有分析到可读的第一版

1. 打开实际输入，辨认每一行是人、样本、时间点、运行还是汇总值，列出本图用到的字段、分组、单位及可用区间。配对和重复测量保留对象标识；排序按数值、时间或有意义的类别次序，而非任由文本排序决定。
2. 复用14已经得到的估计、区间和有效分析集。只有逐行数据时，先区分纯展示与新分析：把已知观测画出可以继续；新增估计、拟合、平滑或推断，以及改变分析集、估计对象或科学比较的筛选，须接14对应工作。在已有有效范围内选择本图展示的条件或面板留18，不让绘图库的默认汇总替代分析决定。
3. 根据当前判断选一种首选编码并解释理由。例如配对变化可先画对象连接线，估计比较可画点和已有区间，分布比较保留实际观测；不因软件有按钮就同时做柱图、雷达图和三维图。
4. 在已有绘图环境中，将字段明确映射到横轴、纵轴、分组、线型或面板；先完成轴名、单位、样本身份、区间和缺测表达，输出一版可以查看的图，再调布局。复杂论文可以先完成一张代表图以确定可复用样式，不先画完全部图再统一返工。
5. 实际查看是否能完成预定比较；挑选少量关键点、区间端点、组别和缺测位置，与对应输入核对。图形改变排序或编码时重新查看，纯换字体不重跑统计检验。
6. 用户意见转成具体改动，按6.10处理；用同一图源重新导出，最后配图注并放入稿件查看。保留绘图实现及输入定位，使结果更新后能更新图，而不是只留下截图。

具体软件例子：[Seaborn关系图教程](https://seaborn.pydata.org/tutorial/relational.html)展示了按对象标识分别连线的用法：lineplot／relplot中使用units指定对象、estimator=None关闭聚合。它适合展示已有个体轨迹，不会因此自动提供正确的群体区间；已有区间可由Matplotlib显式绘制。使用其他环境时解决的是同一问题，无须换工具。

#### 背景与已有工作图：把文献和材料变成能理解的关系

先明确读者看完需要认识哪个对象或差异，例如“问题发生在什么场景”“几类方法按什么维度区别”。AI核读相关原文，提取本图需要的对象、共同比较轴、各自输入输出或关键机制，不从标题拼接一张方法名清单。已有近邻阅读有效时复用，只补当前缺口。

按用途取视觉材料：介绍设备、数据产品或软件时，先核官方照片、真实界面或字段实例的内容与身份；解释抽象关系时由生图模型制作供用户重绘的示意参考。介绍多种方法时，先选共同维度，如输入条件或处理机制，再按事实组织并列、分类、包含或对应；时间演进须有依据，不能把并列方法画成前后必经步骤。定性概览无需硬加性能排名。

第一版先保证内容成立：对象命名清楚，代表实例足够辨认，连接有明确含义，读者能找出比较轴。AI结合该领域同类论文的图型与期刊版面，自行选择合适的排列、配色和主次，避免只给用户一段“可以画概览图”的建议。实际制作默认调用生图模型并查看参考稿；仅请求构思或提示词则交付该范围。

随后实际查看第一版，检查代表对象是否偏离主题、分类层级是否混杂、哪些细节妨碍理解；删去无关旁支，将实现细节留正文或补充，保留决定方法身份的特征。图注逐项区分原图、裁切、改绘及概念示意。

#### 方法、架构与机制图：先把关系画对，再改善视觉

AI从06方法和实际实施说明中提取输入、处理对象、操作、输出、必要条件及反馈关系。区分数据流、控制流、包含和作用方向；训练与推断、计划与已实施、假设与已获证据的关系按本研究实际身份表示。方法尚未执行时可以画方案，图中及图注保持方案身份，不虚构设备、样本或结果。

先形成能交给生图模型的内容草图：列明需要出现的对象名称、哪些对象相连、每条连接表示什么、读者需要辨认哪个关键变化。短文字即可，不要求另存一份规范或预先画矢量草图。AI按内容决定组织形式；真实有回路才画回路，没有方向关系不用箭头。论文必须交代的算法参数与完整步骤可放方法节，图保留让读者理解整体工作所需的信息。

方法、架构与机制的第一版默认只调用生图模型，交供用户重绘的参考稿；不把“需要编辑”解释为默认另做一份矢量图。数据点、测量图像、精确公式、计数及复杂拓扑需要由可靠输入逐项核对，不能让生图模型补猜。若参考稿无法正确表达这些精确关系，标出待重绘点，不冒称已经完成科学图。

采用生图时，AI把内容草图转成实际提示：本图在稿件中的位置、所属领域及已查到的图型惯例、对象与关系、重点、允许出现的名称与符号、事实边界、按语义选择的配色，以及用户要求。可借使用时查到的外部能力学习内容式提示，但不把某套色板、分栏或图标写死。返回图片后实际查看文字、关系和遗漏；将具体错误写成修订要求，再查看修改结果。连续修改仍无法保证文字或拓扑正确时，标明只供构思及需用户重绘纠正之处，不无限重生或默认改用矢量工具。

外部[scientific-schematics](https://raw.githubusercontent.com/K-Dense-AI/scientific-agent-skills/main/skills/scientific-schematics/SKILL.md)可学习“明确对象关系—生成—查看—修订”的思路。其模型、付费接口、迭代次数和评分是该实现的选择；本流程不继承这些设置。自动评分不能证明科学正确；PNG包进SVG／PDF仍是位图，需要可编辑线条和文字时须实际制作这些元素。

#### 真实图像：把原始素材处理成可解释的面板

先打开原文件，识别样本、视野／时间、通道、方向、像素和校准信息；需要比较时确定各图是否可以按同一尺度和显示条件处理。依据本图用途选择全貌、局部或通道，不默认每图都加放大框。裁切保留必要上下文，放大区域在全貌中能定位；通道合成说明各颜色对应什么，单通道与合成图的关系可核查。

有空间校准时，用校准信息生成尺度条；只有放大倍率或未知缩放截图时，先找原文件、元数据或可靠校准，缺依据就暂不画物理尺度条。需要测量或重新识别对象的工作接14等相应节点；单纯增加标签、合理裁切和排布留18。

可用[ImageJ分析菜单指南](https://imagej.net/ij/docs/guide/146-30.html)学习具体路径：已知像素尺寸或已知距离后，通过Analyze → Set Scale设置尺度；再用Analyze → Tools → Scale Bar加入相应单位的尺度条，选Overlay保留非破坏性标注。不同图校准不同时分别处理，不能未经核对把一个全局尺度套给所有图。该网页标示IJ 1.46r，实际工具版本的菜单以当前安装为准；本轮没有做图像测量。

#### 组合图：从各面板图源组成一个论证单元

先给每个面板指定用途，例如对象示意、主要比较、必要诊断或局部证据，再按读者需要的顺序组合；不把所有已有输出挤进同一幅图。面板数量、比例和排列由内容与最终版面决定，主图和补充之间的取舍参考16，不能为了突出效果删掉决定结论的反向证据。

导入各面板的真实图源、代码输出或示意参考稿，并保持真实图像纵横比；统一对应类别的编码、字号层级、必要线宽和面板标记。共享坐标或色标前确认变量、单位和变换一致；不一致则分别标明。图例和共同说明可以集中，关键单位和读图信息不能因省空间而消失。

完成后同时查看单面板和整幅图，在稿件最终宽度检视文字、线条、图像细节和阅读顺序；图注按面板解释并能返回各自依据。面板内容改变时只更新受影响位置及引用。真实图像、概念部分和数据图保留各自来源，不把组合后的一张位图当作唯一图源。

沿用用户已有且够用的环境；下面是可执行路线示例，不是统一软件要求。工具不支持当前编辑或导出需求时再换方案，不为学习手册自动安装整套软件。

### 6.10 用户意见怎样变成具体修改

先实际查看用户指的版本与位置，保留已正确的内容。意见涉及科学含义时解释影响并返回相应来源；普通呈现调整可直接制作可比较版本，不要求用户先懂绘图术语。

| 用户反馈 | AI先判断并实际修改什么 |
|---|---|
| “太复杂，看不懂” | 找出本图必须完成的判断；合并重复标签、缩短非必要文字，拆开不同问题或移次要内容到补充；保留关键条件和证据，而非一律删细节 |
| “重点不突出” | 调整论证顺序、直接标签、面板大小、留白和辅助信息层级；检查主比较能否迅速找到，不改变坐标或隐藏样本制造更大效果 |
| “像PPT，不像论文图” | 查看是否装饰、长句、卡片或图标掩盖科学对象，减少无语义视觉元素，统一真实有用的编码与文字层级；论文图仍可有颜色、场景和复杂科学细节 |
| “太丑／要专业一点” | AI指出可观察问题，如对齐、文字拥挤、线宽混乱或图例位置，优先修这些并给预览；不只回复抽象的审美原则，也不无依据强套某种期刊风格 |
| “字体太小／插进论文糊了” | 在最终宽度检查原始像素、导出、字体与缩放链路，回源调整；分别解决缺像素、文字层过密或软件转换问题，不仅修改dpi标签 |
| “数据／箭头有问题” | 定位对应输入、关系或实际实施说明。输入错误回来源修正，绘制映射错误修图源；同步受影响的图注和正文，再看实际输出 |
| “要能编辑” | 明确需要编辑哪些部分；数据图交付绘图实现，解释性图交付参考稿、提示及准确对象关系供用户重绘，组合图保留各面板源。用户明确要求制作可逐元素编辑的版本时再按其要求处理；将图片插入PPT或改后缀不会自动得到可编辑对象 |

### 6.11 什么程度算当前这项绘图工作做完

按用户请求交付实际可查看的图件、必要图注及真正能修改／重新生成的来源定位；只请求构思或提示词时，交付相应可用内容。稿件绘图还要实际查看插入后的版本，而不只检查绘图窗口。已知未解决的问题说明具体影响，不能用“美化完成”或自动评分代替。

文件沿真实课题已有图源与稿件位置维护，不给每个思考点新建文档，也不复制数据、来源和科学结论。14负责分析依据，16负责论证用途，18负责制作与表达，19核对实际最终产物；背景和方法图按需要直接接文献、06或13，不强制先有结果分析。纯布局修正不重审整篇论文，科学关系或数据变化则沿受影响依赖核查。

本节补充的是具体操作指导；尚未用真实或隔离输入实际制作图件，因此不能据此宣称绘图能力已经全面验证，也不能将这一处补充视为其他阶段细节已经充分。

### 6.12 从结果和材料制作可编辑表格

表格工作先明确读者要查什么，再排单元格。AI打开14有效结果或现有材料，为本表提出行、列、顺序和表注的第一版；用户不需要先画好表头。若只需三个数的简单陈述，可直接写正文；需要精确对照、多条件或来源关系时才保留表。制作只整理既有事实，重新估计、检验、改变分析集或综合量回14。

1. **决定比较轴。**通常把同类对象／条件放行、同类量放列，也可按阅读目的交换。列名注明指标、单位、时间和区间类别；组间估计与组内描述分开，不让“变化”同时代表百分比和原尺度差。
2. **逐项对应来源。**从当前结果取数，保留对象、分析集和有效N；把来源中的SD、SE、置信区间读清再命名。取值、缺失和不适用分别表达。某表汇总不同分析集时，分母就近注明，不能给全部指标共用一个含糊N。
3. **做出普通可编辑单元格。**先用简洁表头与必要脚注，成组列有共同含义时再加分组表头；合并单元格服务含义，不用装饰性多层表头阻碍查读。数据列按同一科学口径排序，对可比数值统一显示精度，计算和后续更新仍引用未舍入依据。
4. **完成表题与注释。**交代对象／时点、缩写、分析集、缺失代码、估计／区间以及必要方法或来源定位。正文说明这张表支持哪个判断，不把全部单元格再抄一遍。脚注解释局部例外，不能藏决定性限制。
5. **在最终稿宽度检查并修改。**太宽先去重复列名、缩短已定义标签、分组或拆成有完整对应关系的子表；长表可分正文与确有用途的补充，或按目标允许跨页。不要先缩成不可读小字，也不把本可编辑的表截图。

构造的表格口径例：A组进入20人，其中18人有该项结果，3人发生事件；B组进入22人，其中20人有结果，4人发生事件。若当前只报告有结果者中的事件情况，第一版可这样表达：

| 组别 | 进入人数 | 有该项结果人数 | 事件人数／有结果人数（%） |
|---|---:|---:|---:|
| A | 20 | 18 | 3／18（16.7） |
| B | 22 | 20 | 4／20（20.0） |

表注须说明这是构造示例中的已观测者描述，缺失者不能默认无事件；它不是随机化总体效应分析，也没有计算两组推断比较。若结果记录采用别的估计目标，按其有效分析制作，不能为使表整齐改分母。表格里的“0”“未测”“不可估计”“不适用”须各有准确含义，不全部变成破折号。

其他材料有不同表法：质性可按主题、解释、支撑／反向片段及定位组织，片段数量不等于总体比例；档案可按陈述、来源时间／身份、证实与冲突关系并置；理论可列条件、命题、边界与引用，不能把不同前提的定理横向排成无条件优劣；综述表保留研究与报告、对象、时点和效应身份，不能每篇摘要各占一行便称综合。

**工具操作。**Word等原生表格先插入相应行列，再填写和设置列宽；长表按[Microsoft重复标题行说明](https://support.microsoft.com/en-gb/word/repeat-table-header-on-subsequent-pages)选含首行的表头，通过Table Layout的Repeat Header Rows或表格属性设置。自动分页与手插分页行为可能不同，导出后实际查看每页。LaTeX沿用模板允许的`tabular`及列宽方式；长表确有需要时，按[Overleaf Tables](https://www.overleaf.com/learn/latex/Tables)了解`longtable`的跨页表头／表尾，不把不能分页的普通浮动表反复缩小。目标双栏等限制先核对适用性，再选横排、拆表或补充方案，不无条件加包。

用户已有Excel、Word、LaTeX等源时，直接复用有效内容；导入导出后核对负号、上下标、单位、百分号、区间、脚注、表头和几项源值。实际交付表的可编辑源、阅读版中的正确位置及来源定位即可，不为每张表另建登记表。此节补操作，不证明真实表格已渲染或经过科学审查。

## 7. 公式、符号与推导：表达科学作用，再处理编辑格式

### 7.1 为什么要写这个式子

AI依据06理论/方法与16论点提出公式位置和作用：定义一个量、陈述模型或目标、说明估计/计算、展示关键推导、表达定理条件或结果。能够用明确文字讲清的简单关系不必为了显得理论化加公式；真正决定研究含义的式子也不能为了简洁删掉。用户不懂符号时先用对象和操作解释，再给对应符号。

式子前说明它解决哪个问题，式后解释量、条件与如何用于后文。公式来源、推导与变更依上游记录；标准公式也要核对适用条件，修改已有公式时说明修改。概念关系不是已经验证的数量定律，拟合式不是普遍恒等式，定义符号与推出结论分清。

### 7.2 符号和数学含义核查

沿用一套对象与符号命名：首次出现解释含义、类型/维度、索引范围、单位及必要边界，标清向量/矩阵、随机变量/实现值、估计量/真值。一个符号不在相邻章节代表不同对象；同一对象也不因语言美化换符号。多符号稿件可在当前稿件内放符号表，简单稿件就近定义，不为每篇论文另建独立符号系统。

核对等式/近似/比例/定义关系，条件与量词，分母非零、边界/初始条件、索引、转置、上下标和概率条件；有物理量时检查量纲与单位。数值参数与方法/实现一致。长推导保留关键合法变换与理由，例子检验不冒充证明；科学有效性问题回06/12/15，排版修复留18。符号一致或编译成功只说明对应的形式检查，不说明定理成立。

### 7.3 编号、正文联系与可编辑格式

重要且会被引用的式子用自动编号和稳定标签；无须给所有行内关系编号。正文用“式（编号）”等目标允许方式引用，不手打会随重排失效的序号。长式在合法关系/运算位置分行，保留对齐与编号归属；推导中必要的说明用文字交代，不只堆等号。公式参与句子时处理语法、标点与段落连接，避免正文突然出现无引导的大式子。

Word路径可按[Microsoft官方公式说明](https://support.microsoft.com/en-us/word/training/write-an-equation-or-formula)使用“插入→公式”或Alt+=，输入完整可编辑数学对象，检查线性/专业显示转换后的上下标、分式与字符。LaTeX路径在期刊模板允许的范围内使用原生数学环境；[amsmath用户指南](https://ctan.math.illinois.edu/macros/latex/required/amsmath/amsldoc.pdf)第3章说明单式、多行对齐、分行以及标签/引用，例如equation、align、split与eqref。只选实际需要的结构，不要求先换技术栈。

公式截图容易失去可编辑内容与清晰度，普通稿件优先用所选编辑环境的原生表达。目标期刊可能对公式工具和行内单符号另有规定，例如[PLOS公式段](https://journals.plos.org/plosone/s/submission-guidelines)区分完整公式与普通行内符号，要求不要混用工具拼成同一公式；实际写作按已确认目标核对。

导出后查看实际稿件：希腊字母、负号/连接号、乘号、微分、黑体与上下标没有错换，长式和编号不重叠或出页，交叉引用不为问号，附录和正文编号一致。科学含义核查、编辑文件检查和最终渲染检查相互补充；其中一项通过不能代替其他项。

### 7.4 从已有式子做到能编辑、能引用的稿件对象

只有截图时先读取实际式子与上下文，辨认符号和条件；看不清的下标、量词或运算先找原文，不能按相似公式猜写。已有LaTeX或原生公式就复用，按当前目标工具转换后逐符号核对。构造操作例：一条分组求和式应核对求和上下界、对象索引、分母和定义，再决定单行还是分行；排版不能把条件从式子中丢掉。

Word中先在原生公式对象内输入并查看专业显示，再接正文定义和需要的自动引用；一个式子不能用截图、普通文本和几个浮动文本框拼接后声称可编辑。LaTeX中先选7.3合适环境，给需要引用的式子稳定标签，编译后核对实际编号与正文。跨环境后若某符号不受支持，先查该编辑器允许的表达或替代输入，不能用视觉相近但含义不同的字符蒙混；确需保留图像时说明可编辑范围，保留可重新生成的原源。

编号正确但公式含义有错回相应上游；只发现分行、字体或引用错则修当前对象并查看受影响导出。这里不规定公式数量，也不要求一个纯概念段落增加公式。

## 8. 引文与文献管理：支持当前句子，保持版本与定位

### 8.1 引文支持什么

每个需要外部证据的事实、方法、理论来源、比较或解释，打开原文检查它具体支持什么命题、在什么条件下成立。引文放在相关命题附近，多个分句有不同依据时分清支持关系；综述可帮助认识领域，原研究/原方法用于其直接结果与细节。书目存在、DOI可解析、搜索摘要或另文参考文献不能证明当前句子。

分别辨认引用是在报告前人结果、使用方法、借鉴理论、标注直接引文还是讨论观点。不能把“提出可能机制”引用为“已证实机制”，不能将二手转述当作自己核读原始来源。只读摘要时注明范围并限制使用；关键细节需要全文或可靠原始依据，缺失就暂缓该强主张或换可核验的表达。

直接引文保留引号/引文格式、准确定位和语境；转述使用自己的理解但仍标出处，避免替换同义词式搬写。质性材料、档案、标准、软件、数据、预印本和正式论文按其真实身份引用。档案定位可包括馆藏、系列、盒/卷/件、页/叶和日期；译文说明所用版本及必要的翻译处理，不能将译本页码误当原件页码。

### 8.2 版本、更新与重复条目

核对标题、作者、日期、载体、卷页/文章号与标识符，并绑定实际核读版本。预印本与正式版若论述不同，采用支持当前命题的版本并明确身份，不能沿用旧页码却换上新DOI。相关更正、撤稿、关注声明或版本更新会改变依据时，更新受影响文字及图表，不只改参考文献尾部。

具体网站路径：用[Crossref Metadata Search](https://search.crossref.org/)按标题/作者/DOI寻找候选，进入出版商页面核对书目信息，再读正文支持段；有[Crossmark](https://www.crossref.org/services/crossmark/)时检查当前状态和更新链接。没有更新按钮不能推出“没有问题”，Crossmark本身也不保证内容正确。此处是可用操作办法，本轮未为任何真实稿件完成文献验证。

### 8.3 用已有文献工具减少编号与书目错误

沿用项目已选文献库，保持同一条目的正式位置；没有工具时少量参考文献可先准确手工维护，不强制安装。工具解决插入、排序、去重和样式，不替代内容核验。更新元数据以后刷新稿件，检查文内引用与参考文献双向匹配、重复项、缺项和未经使用却列入的条目；图注、补充材料中的引文也按目标规定处理。

若实际采用Zotero，可参考[添加条目说明](https://www.zotero.org/support/adding_items_to_zotero)：从出版商文章页或目录记录采集，或者按真实标识符导入，再核对元数据；PDF自动识别可能只得到附件或不完整条目。其[文字处理集成](https://www.zotero.org/support/word_processor_integration)能动态生成书目；在稿件中新增/删除引用后刷新，仍须检查导出结果。LaTeX稿件沿用当前模板允许的文献方式和实际bib记录，不为了本阶段新增未经需要的插件。

### 8.4 实际插入、修改与刷新引用

从一句具体文字开始，先核对它需要哪种来源及原文支持位置，再插入对应条目，而不是先凑文献数量。直接引文或需精确定位的材料，把页／节等定位加到该引用，避免把页码直接敲进会被刷新的字段文字里。若一句两项判断由不同来源支持，分清各自引用范围，不将若干书目笼统堆在句末。

Zotero现有集成可按[官方使用说明](https://www.zotero.org/support/word_processor_plugin_usage)使用Add/Edit Citation搜索并选中已核条目、添加定位，Add/Edit Bibliography生成书目；条目信息错先修文献库再Refresh。改刊的文献样式在Document Preferences调整，然后核对正文、图注、补充与书目，不手改全部序号。字段不更新先辨认是否仍为活动引用、是否手动改过或与库条目失联，再查该具体故障；不先把全部引用转纯文本。Unlink会失去自动更新，通常仅确有交付要求时处理另行明确的终稿副本，保留有效可编辑主稿。

LaTeX沿用模板实际采用的文献后端和样式，书目键对应真实条目，正文引用后按该链路编译；BibTeX与biblatex／Biber不能随意混接。出现问号先查键、书目路径和编译链，出现书目与正文不一致先查有效条目及生成状态。参考文献能排出来仍不证明支持句子，原文核查继续按8.1。

## 9. 补充材料与必要末尾信息：让正文短而证据不断

补充材料只容纳确有用途的细节，例如完整证明、协议和参数、额外质量/敏感性结果、完整表、检索式、证据摘录索引、实现/数据访问说明。正文保留评估主张不可缺的设计、关键结果和条件；不能把主要反证、核心证明缺口或失败判断埋到没有明确引用的附件。附件不是原始数据的替代品，也不是把所有临时文件打包。

引用使读者能从正文/图表找到对应附件中的具体节、表或材料，再返回原始依据。附件标识、标题、内容、文件名和当前版本一致；读者能够打开，并知道它属于哪份稿件。补充中的方法、样本、数值、符号与正文复用同一权威来源。按目标要求处理主文/补充的编号及参考文献，而非手工复制多份略有不同的事实。

例如[PLOS Supporting Information](https://journals.plos.org/plosone/s/supporting-information)说明补充文件按提供内容发布、不经文字编辑，且图表格式与正文规则有所不同。可借鉴的操作是核对文件可读性、名称—图注—文内定位与最终版本，具体命名及容量规则仍按真实目标核实。本轮没有制作或上传实际补充材料。

作者、单位、作者贡献、致谢、资助与资助方角色、利益关系、伦理/同意、注册、数据/代码/材料可用性和AI使用等，只处理实际研究与当前目标所需项目，按真实记录写明。没有授权开放的数据不能承诺公开，未获得的批准/许可不编造，未做的工作不归给作者。待核或不适用状态有说明；不从其他论文复制看似标准的声明。这里核对稿件真实性，不另建全面合规系统或外部发送流程。

## 10. 语言、术语与翻译：清楚表达而不改变科学含义

按段落职责写作：交代当前问题/对象，提供必要事实或逻辑，给读者一个与本段对应的判断或下一步连接。并列事项用相近结构，相关内容相邻；跳转前说明关系，避免读者同时记住许多尚未解释的术语。段落长度按信息量决定，不设统一句长、每段引用数或词汇难度。

一概念尽量用一个术语；第一次定义关键缩写，少用不必要缩写，摘要及能独立阅读的图注按需再次说明。不要为避免重复而把技术术语换成含义略异的同义词。明确主语、比较基准、时间/条件和指代，区分“显著”的统计含义与一般重要性，尽量用实际对象与动作替代空泛形容。

翻译先核对科学含义再改善语感：研究对象、否定、程度、可能性、因果/关联、时态、单位、小数和量词要保留，术语采用领域实际用法。参与者原话、档案语句、专名与理论术语涉及不可直接对应的含义时，保留必要原词或解释所用译法，不能为了顺畅改变材料立场。AI无法确认的关键专业词查原始论文/标准用法；用户不了解时给解释与候选表达，不直接把问题丢回去。

修改次序按当前问题决定，但事实和允许结论先稳定，再处理结构与段落，最后集中核对语言和格式。每次实质润色后检查动词和范围有没有升级、限定是否被删、引用支持是否随句子改变。语言编辑通过不说明科学审查通过。风格建议留在当前稿件备注或本阶段现有说明中；简单稿件就近统一术语，无须独立建风格册。

### 10.1 用一段实际材料形成第一稿，再逐层修改

AI先概括本段读者问题，定位可用事实／推理和允许判断，再写短的可读第一稿。写完反查每句承担什么作用：必要背景、证据、解释、限定或连接；没有依据的事实先查，重复的作用可合并，缺连接时补已有前提而非补新科学结论。用户只说“太啰嗦”时，先删重复铺垫和空泛评价，合并相关信息；保留对象、比较、关键数字、否定和不确定性。

构造例：原句“该方法效果非常好，实验充分证明了它在所有场景都有优越性”，若已有允许判断仅为一个场景内的用时改善，应先改为“在已评估场景和相同输入条件下，该方法减少了用时；其他场景的表现尚未验证”，并在真实稿件中接有效结果及引用。不是只把“充分证明”替换成“可能证明”；原句承诺的适用范围也须修正。此例没有提供或虚构任何真实数值。

翻译／英文润色时先确定领域术语与句子逻辑，再处理词序和语感；改完逐项回看比较对象、条件、因果／关联、否定、量词、精度和引用范围。讨论不同译法只需说明有科学影响的差别，不能要求用户先选整套语言风格。多段任务先检查段间问题与答案能否衔接，再做局部句式；不能将每段都润色漂亮却留下重复与矛盾。实际首稿和修订保留在当前稿件的既有版本位置，不另造每句修订日志。

## 11. 全稿一致性、独立审查交接与回退

### 11.1 以权威事实核对重复出现的位置

从现有证据、结果、结论与提纲索引核对“问题—方法—结果—允许结论—表达位置”。无需给每句话重新发编号或新建平行数据库。高影响的重复事实优先检查：研究对象与时段、样本/独立单位/分析集、方法与对照版本、分母、主要估计和区间、参数、符号、图表标签及结论强度。

摘要、正文、图表、图注、公式、补充材料和书目中的同一事实必须一致；两个数字合法不同（例如全样本与有完整数据的子集、不同时间点、独立单位与观测次数）时给不同概念名和清楚说明，不能强行改成同一个数。舍入规则一致，最终值返回有效分析输出，不从旧稿件复制。文件时间较新不自动表示事实版本有效。

随后实际查看当前导出版：章节和内容完整，页/行号和必要匿名信息正确，图表/公式没有裁切和乱码，交叉引用有效，参考文献与附件能定位。每个保留图按最终尺度查看。没有真实稿件时只能检查本手册与纸面路线，不能宣称已完成这些实际文稿检查。

### 11.2 交给23与19什么，怎样判断18完成

完整流程先将当前有效初稿及上述依据交23作表达诊断与改写，再将其当前版本交19独立科学审查。19接收有效的可编辑稿件与可阅读导出，确有用途的图表源/成品和补充材料位置，所用模板/指南适用版本，以及现有证据、14分析、15允许结论、16提纲和必要上游依据的链接。只补充本次新增的实际改动、偏离、未决问题及其影响；不复制整套数据、代码和历史聊天。

18完成的判断包括：

- 主要内容有真实输入，未以占位文字或推测填补关键结果、方法、证明或引文；支持、反驳和未定状态都忠实表达。
- 结构适合真实文章类型与读者，16各主要论点有对应表达，15的条件与强度在标题/摘要/正文/图注/结论中保持一致。
- 图表/公式有科学用途、来源和必要说明，可编辑源与当前输出对应，实际导出可读，引用和补充可定位。
- 当前目标格式中的适用项已核对，尚未解决项及其阻碍清楚，没有把格式通过当作科学通过。
- 交接让23能够对照初稿与依据修改表达，并让19继续核对稿件、主张和原始依据；无必要未决项时可继续下一阶段，不自动增加补缺任务。

19审查发现问题后按00与20组织修订，科学或稿件内容改变后复审；21复用有效审查核对交付，22才固化。18的自查不能冒充19独立验收，也不在本阶段发起投稿或对外发送。

### 11.4 从内容到可审查文稿的实际制作路线

先看现有源文件与目标要求，选择能完成当前请求的现有环境。只有内容未排版时，先把16职责对应到标题层次、正文、图表、公式、参考文献及确有用途的补充；已有稿件只调整受请求影响的部分。04／17资料是格式和表达依据，不另开一个制作项目。

**Word等原生文稿路线：**在现有稿件或适用官方模板中映射内容，使用标题、正文、题注等有语义的样式；通过[官方样式说明](https://support.microsoft.com/en-us/word/customize-or-create-new-styles)修改相应样式，避免逐段反复刷格式。插入原生表／公式与适用图源，再按[题注说明](https://support.microsoft.com/en-us/word/add-format-or-delete-captions-in-word)建立题注，通过[Cross-reference](https://support.microsoft.com/en-us/word/create-a-cross-reference)引用已有对象；不手打会随调整失效的“图3”。刷新字段与文献后导出阅读版，实际查看分页、图表、公式和附件引用；正文全选更新不等于所有页眉／文本框等位置都已正确，仍需核对实际产物。

**LaTeX路线：**复用实际模板／现有主文件，先核对主入口、编译器、图文件与书目后端，再放入相应章节、表和原生数学内容。按[交叉引用说明](https://www.overleaf.com/learn/latex/Cross_referencing_sections%2C_equations_and_floats)设置标签与引用，图表标签绑定相应题注；正文变化后按实际链路编译和查看。遇错先读最早相关错误及附近源码，从[官方错误索引](https://www.overleaf.com/learn/latex/Errors)查该类问题：缺文件核路径，未定义命令核拼写与所需功能，表格多出对齐符核列数／正文中的`&`，数学环境错误核定界和特殊字符。不要只看最后一条连锁错误，也不为让它编译随意删除科学内容或加入一堆包。问号／缺书目查标签、引用键与编译次序；排版溢出回对应长式、表或段落处理。具体命令与环境仍以真实模板为准，本轮未创建或编译稿件。

**最后核对与交付：**从阅读版定位一处主结果、一幅图／一张表、一条公式及关键引用（存在才查），返回可编辑源和有效依据，确认转换与更新没有改含义。所有实际改动受影响的位置都要核对，不能只以几项抽查代替必要全稿完整性检查。交付用户所需的可编辑稿与可读输出、必要图表源和未决影响；若只改一段或一张表，就交该范围。不能把Markdown文本、截图或一个能打开的PDF冒称完整可编辑论文。

以下检查只推演流程，不产生研究结果或虚构论文：

1. **有边界的应用改进。** 如果14只提供一个已确认场景中的比较，18可写方法条件、该场景的结果和限制，用一张有用途的表或图，甚至只用正文；不能为模仿高要求期刊补出跨场景、消融或普遍机制。需要新验证时返回上游。
2. **理论小结果。** 命题只在指定假设下成立，正文先定义假设并给证明路径，摘要和结论保留范围；不强迫加入实验、误差条或性能图。证明缺环先回06/12/15，不能靠附录名遮掩。
3. **质性或档案解释。** 主题由部分材料支持，同时有反例/材料缺失，18把解释与材料相邻呈现，保留来源和例外，讨论可迁移/可解释的边界；不把取材次数变成总体概率，不把空档案等同事件不存在。
4. **负结果与未定。** 原任务正确完成但假说未获支持，18忠实写方法、估计/材料、能力限制与15判断；不以“故事不够好”为由删除，也不把不显著改写为等效。
5. **格式未知而科学内容可写。** 当前官方模板待核，18先形成可读内部稿；可继续不依赖模板的章节与图表科学内容，暂缓最终格式确认，不重新选刊，不声明可提交。

这五种情形能解释何处可继续、何处须返回、何处不适用。具体课题仍需补入实际输入、文章类型、期刊、素材条件和工具，不能把纸面检查冒充真实文稿验证。
