# 结论验证阶段详细手册

本阶段说明从已分析结果形成允许结论的判断过程；示例不是实际课题的结论。

## 1. 中心职责与材料边界

**本阶段回答：证据允许相信什么，允许表达到什么程度。**14回答结果是什么、分析是否可靠；15承接这些有效结果，核查由结果到主张的推理、关键前提、竞争解释和适用范围，形成有依据的支持、反驳、未定或条件混合判断。16再把允许主张组织成论证。结论是否符合原期待，不是任务完成与否的标准。

现行阶段顺序、用户确认、独立验收与回退规则引用[总流程](../docs/workflow-design.md)和[00共用规则](../00-阶段交接关系/阶段交接关系.md)，不在本文另设批准关口。承接[02目标假说手册](../02-目标假说与确认/目标假说阶段详细手册.md)、06设计、07／08计划、13实际执行与偏离，以及[14结果分析手册](../14-结果分析/结果分析阶段详细手册.md)。本阶段不重做完整分析，不重新选刊，也不重复05的期刊证据规模校准。

**记录只增加判断。**使用13形成、14补充的同一研究结果记录，引用同一数据、材料定位、图表、推导、分析版本和验收依据。15增加逐主张判断及理由、原预期与事后解释的身份、竞争解释、允许结论句及限制、未决项与补证去向；不另建结论数据库、证据索引、评分表或一套相互冲突的数值。记录形式按实际研究选择，下面的C编号仅定位考虑点，不代表固定任务或独立文件。

以下引导话术、具体判读办法、够用界限和节点关系属于本流程适配建议。外部Skill及其配套只作为方法资料：不照搬固定候选数、评分、强制输出、脚本或安装指令。来源提出的统计、临床或情报方法都有适用域，不能自动移植到所有科研。

## 2. 科研人员走过本阶段时会遇到什么

这是发现考虑点的纸面推演，不是真实科研经历。一位研究者带来14的结果：部分与预期一致，部分差异不清楚，还有异常或不利材料。AI先复述已确认的问题及原预期，确认每句话讨论哪个对象、条件和结果，区分“实际看到什么”与“可能因为什么”。如果用户不知道如何理解，AI从结果记录提出可理解的解释，说明支持与限制，不要求用户先交一份结论。

研究者会追问：计划设想的前提实际满足了吗？分析虽然完成，测量是否真的代表目标概念？如果另一个解释也能产生同样结果，为什么相信本解释？AI从已有设计和实际执行中定位答案，把缺失报告、实际未执行和已经发现失效分开。决定性前提未知时先核查，不能靠措辞缓和掩盖；不影响当前窄主张的拓展问题可留到后续。

接着比较最强竞争解释、不利结果、共享来源及不同方法的贡献。重复运行、同一材料的多种分析、新材料的复验各解决不同问题。AI解释某个检查究竟检验了什么，避免把检查多、方向一致或文献多当成已经排除竞争解释。

不同路线在此分开：定量研究检查效应范围、精度与设计前提；质性研究检查解释与材料、研究立场和反例的关系；档案研究检查来源、形成语境、转述关系及沉默能否说明缺席；理论研究检查命题与证明前提；概念研究检查定义、推理和反例；证据综合检查对应问题下整个证据体的限制。它们不共同使用统计零假说、统一质量分或“达到饱和”的口令。

最后，AI把“能说、暂不能说、为什么、补什么才会改变判断”写回同一记录，提出补证、缩小主张或停止的具体取舍。独立读者复核关键推理和最强反对意见；16收到可以引用的主张及限制。新证据可靠反驳原预期可以形成成果，不能为了正结果无限补做，也不能事后改写原目标使它永远正确。

## 3. 先固定判断对象，再检查推理前提

<a id="c01"></a>
### C01 逐主张定位：结果、解释、理论与用途不能混成一句

AI先把候选结论拆到可判断的意思，例如“本条件下差异存在”“这种差异由机制M造成”“在其他场景也有用”。只在一句话承担多种证明责任时拆开，不为每个短句新建任务。对照02的原目标、06的主张类型和14的实际结果，标明对象、单位、条件、比较及时间；理论路线则定位命题、量词和定义。

采用K1的主张核查思路，逐句查“实际依据在哪里、从依据到这句话还用了什么”。AI可以解释描述、预测、因果、机制、规范性建议的区别，但不靠换一个更强动词升级贡献。当前目标量或概念不清须先解；仅图表安排、章节顺序可交16／18。够用是中心及辅助主张能分别定位证据和边界，无需穷尽所有未来用途。[K1](#k1)

<a id="c02"></a>
### C02 保留原预期、事后解释与形成时间

回看02确认记录、06设计、07分析安排和13偏离：研究开始前预期什么，哪些条件后来才发现，哪些分析或解释看过结果后才形成。引用既有时间与版本依据；缺乏早期记录时如实写“形成时间无法确认”，不能补造预注册或把事后解释改写为预先预测。

AI向用户说明：新解释可以有价值，但生成它的材料同时被用于解释时，不能冒充独立验证。探索性结论仍可明确表达观察与解释，只是其验证身份和不确定性不同。若新解释需要新材料区分竞争解释，进入[C19](#c19)；若只是解释现有观察，标注身份后继续。可靠反证不自动回02；准备改变核心假说才按00返回02。[M3](#m3)

<a id="c03"></a>
### C03 从证据到主张写出最短推理，并暴露辅助前提

用一段文字连接“实际证据 → 必须成立的前提 → 当前主张”，不复制全部实验方案。对因果解释核对06已有的识别依据及13实际执行；对测量主张核对指标与概念；对证明核对使用的定理和定义；对档案解释核对记录产生与保存机制。独立验收证明实现正确，并不自动证明概念测量、因果识别或外推成立。

逻辑上，“假说及辅助前提成立会出现结果R”与“出现R所以假说成立”不同；R可能也来自竞争解释。没有R时，首先挑战的是假说与辅助前提的组合，需判断哪一处失效。AI应指出具体跳跃，不能只贴“逻辑谬误”标签便判主张为假。数值结果的推断还依赖采集、选择和分析安排；很小的P值不能指明哪个前提出了问题。[K2](#k2)、[M2](#m2)

未知前提若决定当前结论，先查既有材料；原材料不足时作条件判断或暂不判断，并明确需要什么。设计本身不能回答目标问题则回06；发现分析或实现错误则回源头修复，之后更新受影响判断。够用是决定性桥梁可解释，不要求每个微小背景假定都被新实验验证。

<a id="c04"></a>
### C04 依据质量、设计前提和结果精度分别影响哪句话

读取14已经验收的质量、缺失、排除、诊断与敏感性说明，15判断其后果：来源不可信削弱事实依据；设计偏倚可能改变解释方向；精度不足限制幅度或差异判断；范围间接限制适用域。不能将“方法报告完整”“结果可重复”“论文已发表”“样本多”折成统一可信分。

AI用“这个问题会使哪句话变得不可靠，可能向哪边改变，影响有多大”引导核查。缺失报告不等于未执行，已报告不等于实际正确；必要细节可先定位方法、补充材料和协议，无法确认便保留未知。正反材料按同一尺度检查。只补影响当前主张的漏洞，轻微报告问题不能自动触发全部重做。[K1](#k1)、[K3](#k3)

正式偏倚工具或证据确定性框架只在问题与设计匹配时使用：先明确评估的是哪个结果或证据体、工具版本及适用域，再保留域判断与理由。本文不制定跨学科总分、不用检查项数决定真假；正式工具的完整执行须在具体研究中依据其原始说明完成。[M5](#m5)

<a id="c05"></a>
### C05 支持、反驳、未定与条件混合的判读

状态是对具体命题及当前范围的判断，不是给整篇论文贴标签。

| 判断 | 需要解释的依据 | 不能替代它的说法 |
|---|---|---|
| 支持 | 有效证据与相应预期相符，关键前提可辩护；说明支持的是描述、预测还是解释，以及竞争解释限制 | “结果方向对了，所以机制被证明” |
| 反驳 | 证据与该范围内的明确预期冲突，且检验确有辨别力；说明被挑战的是方向、幅度、普遍性还是前提组合 | “没有达到显著，所以假说错误” |
| 未定 | 当前证据不能区分重要可能，或关键前提、精度、材料可见性不足 | “没找到反证，所以成立” |
| 条件混合 | 不同条件或不同子命题的判断确实不同，保留分别支持、反驳和未定的部分 | 把不利条件删掉，只保留一个有利平均结论 |

AI不知道时可以先提出条件性句子：“若测量前提成立，结果支持X；目前Y未核实，因而无法确认更强解释”。每个状态附最少但足够的理由和原证据链接，不要求统一概率。混合不等于对原因已有解释；仅因一组显著另一组不显著，不能宣布组间差异，差异本身须有对应分析依据。[M1](#m1)、[M2](#m2)

## 4. 用竞争解释、独立性与不利材料检验判断

<a id="c06"></a>
### C06 先找最强竞争解释，区分相容、竞争与组合

复用02已经提出的竞争解释，根据实际结果增加有依据的遗漏：共同因素、反向过程、测量或选择机制、实现失效、情境差异，以及理论路线中的替代前提。选取会改变当前主张的解释，不固定数量，不把“什么都有可能”变成不可完成的清单。两个过程可能同时成立，此时不应强选唯一胜者。

AI先用一两句话说明最强对手为何也能解释结果，再问“现有哪项材料让它与主解释不同”。用户没有候选时由AI从原设计、相关近邻研究和异常材料提取；有争论时准确复述反对意见，避免稻草人。只借K4的逐证据横向比较、辨别力和关键证据敏感性，不采用加权分数排名、固定来源等级或“不一致最少就是真的”。同样，相容项最多也不能判真假。[K4](#k4)

<a id="c07"></a>
### C07 检查证据区分了什么，缺席何时才有反证意义

对决定性证据逐项比较：“如果主解释成立会怎样；如果最强竞争解释成立会怎样；实际观察对谁更难解释”。双方都预期的现象只说明相容，不能独占归因。补充分析、消融、反例、对照或材料互证的价值取决于它改变了哪种解释的可行性；名称叫“验证”本身不提供辨别力。

缺席能作反证，至少需说明原解释确实预期它出现，观察有机会发现它，查找范围、测量或档案保存前提可辩护。探测不敏感、访谈未触及、档案未保存或未公开时，“没有看到”可能仍是未知。AI先解释缺席来自世界、方法还是可见性，不能把不同缺失混成无效或不存在。够用是明确当前证据能区分和不能区分的解释；无法区分时允许缩成描述主张。[K2](#k2)、[K4](#k4)、[M7](#m7)

<a id="c08"></a>
### C08 多条证据是否真正增加信息

多论文可能使用同一队列，多指标可能依赖同一测量，同一文件可能被转述多次，同一证明可能共用一个未证引理。AI回到已有来源定位，说明共享数据、批次、参与者、文献链、分析决定或关键假定；不新建来源索引。一个共同错误可以让多条证据一齐稳定，不能按“票数”累积信心。

不同材料或方法相互支持时，应说明各自的误差机制是否有实质差异，以及它们是否回答同一命题。独立性不是完全无关联的二元标签；可写“数据独立但共用测量”“来源不同但可能互相转述”。未知关联先查决定性来源；只影响扩展结论时限定范围继续。够用是不会将同源信息误当多次独立确认。[K1](#k1)、[K3](#k3)

<a id="c09"></a>
### C09 区分重复运行、再分析、复验与新条件推广

同数据同分析的重运行主要检查计算可重复；同数据换合理分析主要检查结果对分析选择的稳健性；新证据的复验考察原主张能否经受新的检验。Nosek与Errington提出，以可能结果对原主张是否都有诊断意义来界定复制，而非只看操作相同。不同领域术语可能不同，记录实际做了什么比只贴名称更可靠。[M3](#m3)

AI核对复验前已有的相关条件承诺、实际差别、测量与精度。成功复验增加的是所检验范围内的依据；失败可能挑战原结论、显示边界或暴露执行问题，不能一见失败就断言造假，也不能事后将全部失败宣布“不算复验”。理论和档案研究不必重演历史事件，可用独立证明、重新核查原材料或新相关材料检验原主张。需新增研究时由[C19](#c19)返回计划及有效实验确认；本阶段不自行启动。

<a id="c10"></a>
### C10 稳健性不等于有效性，矛盾不能平均抹平

复用14的稳健性分析，询问每项变化检验了哪种合理不确定性：估计、处理规则、模型、编码理解、材料选择或证明假设。结果稳定仅支持对已检查变化的稳定；稳定的代理指标、共用偏倚或错误前提仍可支撑不了目标概念或因果解释。模型拟合好或计算收敛也不能独自证明参数可识别。

不利结果先检查是否同一目标、同一条件和可比精度，再区分真实异质、分析问题、材料缺口或解释不足。不能仅按P值是否跨门槛判断冲突；不能用删异常、换定义、换主要指标来消除反证。若声称条件边界，保留该边界是在结果前设定还是事后提出，以及是否已有独立支持。无法解释的决定性矛盾进入未定或缩小主张，非决定性差异可以带限制交接。[M2](#m2)、[K5](#k5)

## 5. 按研究路线判断“证据够支持什么”

以下路线承接14的分析，不是补做所有方法的要求。选择与当前主张相符的一条或必要组合；小贡献仍需支撑对应窄主张，无须升级为普遍机制或全面性能突破。

<a id="c11"></a>
### C11 定量估计、统计检验与阴性结果

先复述14的目标量、单位、比较、估计、不确定性与适用前提，再把结果与02／06／07中有科学或应用依据的有意义幅度相比较。P值不能解释为假说为真的概率，统计显著也不表示效应足够大或有实用价值；P值只能在相应模型与分析程序下解释，不能单独裁决科学结论。[M1](#m1)

AI把“数据还允许哪些重要可能”说清楚。区间若同时容许重要获益、无明显变化或损害，就保留这些可能，不能只挑有利一端。频率置信区间并不是本次参数落在区间内的后验概率；贝叶斯结果需保留先验、模型及敏感性依据，不能将证据比自动变成假说概率。[M2](#m2)

阴性结果区分“证据不够精确”与“在已说明界限内支持无重要差异”。等效或非劣主张要有相应目标、合理界限和检验依据；普通未拒绝零效应不能代替。Lakens的等效方法原文提供相应逻辑，但不是所有研究的统一入口。[M4](#m4)

本流程适配：若界限在看结果后才设定，说明来源与事后身份，不能伪装原计划；资源决定了可排除多大效应时，表达“本研究可排除的范围”与“科学上什么算无意义”两个不同问题。不用观察到的效应计算事后功效来解释阴性，也不以统一样本量、功效值或0.05作为够用线。需要重算交14，新增证据交[C19](#c19)，15仅判断当前数值允许的结论。

<a id="c12"></a>
### C12 预测、仿真、方法比较与局部应用价值

预测有效须对应实际预测对象、独立测试范围、数据泄漏检查和目标使用情境；拟合成功不能自动支持因果或机制。仿真结果说明已模拟的机制与参数条件，不能独自证明真实世界的前提。方法比较检查相同任务、数据、预算及基线是否可比；改进可能来自更大资源或额外信息，须据此限缩归因。

AI复用14的性能、误差、成本和失败条件，解释“在哪种约束下解决了什么实际困难”。局部应用、小幅效率改进、简化流程、补出成立边界都可能有意义，但要有与其声称价值对应的证据：若主张省资源，实际资源依据要可核查；若主张可部署，使用条件与相关代价要有依据。未测的安全性、长期稳定性、群体公平性或其他场景只能保持未知，不因有一个分数就声称全面适用。哪些价值维度必要，由已确认问题决定。[K5](#k5)

够用是局部范围、比较与实际价值说得清楚；不强求每篇应用论文都完成机制识别或所有场景测试。决定当前用途的成本或条件未知先查；其他用途作为待验证拓展交16的讨论材料。

<a id="c13"></a>
### C13 质性解释：可信性来自方法立场与材料连接

读取14采用的质性路线、材料范围、主题或类别、解释过程和反思记录。15检查解释是否回答研究问题，关键材料是否支撑其含义，矛盾、负例和被忽视的立场是否改变范围，以及研究者立场如何影响读法。给出少数生动引语不能自动支持整体模式；出现次数也不能自动证明解释价值或总体比例。

反思性主题分析中，Braun／Clarke强调解释与数据、理论立场和实际方法相称，编码一致性不承担其真实性证明。其作者网站也不把数据冗余式“饱和”作为该方法的统一停止依据。[M6](#m6)

本流程适配：AI挑选支撑核心解释与挑战它的材料，回到原上下文；独立读者核查是否遗漏重要可能、解释是否透明，而不是强求一个唯一正确编码。访谈中的自述可支持所报告的经验或意义，但不会自动证明陈述中的外部事实、因果或人群频率。内容计数、编码可靠性路线、扎根理论、叙事或个案研究分别复用其设计中的核查办法；是否需要一致性、成员反馈、饱和或其他尺度由具体方法决定，不强套Kappa、参与者数或每个方法都要饱和。

用户不知道方法立场时，AI从06与14先解释当前分析实际上允许哪种理解；两者矛盾先回14或06解决，不能到写作时再补一个方便的方法名。够用是当前解释有材料、过程、反例与范围依据，不要求全体参与者同意研究者解释。

<a id="c14"></a>
### C14 档案、历史与文献材料：从“文件说过”到“事件发生过”

先核对既有原件或可靠版本、形成日期、作者与受众、目的、保管链、转述关系和可访问范围。NARA的文献分析资料提供作者、受众、目的、文本依据与未回答问题的核查入口；它是教育分析工具，不是高级档案结论的质量认证。[M7](#m7)

本流程适配：逐主张区分“该作者在此时这样写”“当时有人如此理解”“事件确实发生”“存在特定原因”。文件真实不保证作者内容准确，多份相互抄引不构成独立互证。互相冲突时核查各来源接近事件的方式、利益与可见性，而非只按机构权威排序。档案未记载事件能否反证，需知道该类事件通常会被记录、记录有保存与可访问机会；重要沉默机制未知时只表达检索范围内未见。

AI可在官方档案目录检索原材料标识、日期、相关卷宗和说明，将新定位补回已有材料记录；不要求下载一堆副本。决定性真实性或转述关系先解，超出当前年代、机构或材料范围的推广可后移。够用是读者能区分文本内容、历史解释与未覆盖范围。

<a id="c15"></a>
### C15 理论、数学与计算辅助证明：命题成立与现实有效分开

核对02的命题或猜想、06的定义及假设、14的推导和基础检查。AI逐条检查量词、存在与唯一、必要与充分、有限与渐近、近似与严格，以及所引用引理的适用条件。把数值例子、穷举、符号计算或仿真归到它们实际覆盖的范围：测试很多例子不证明一般命题，近似误差不能在结论中消失。

本流程适配：决定性步骤可让独立读者重推或用另一有效论证核查；必要时检查边界、退化情况与反例。有限穷举只有在范围完整、实现正确且穷举逻辑适用时才支持相应有限命题。发现反例先判断是否满足原前提；满足则反驳原范围，未满足则可能暴露表述或边界问题。定理在形式假设下成立，不自动证明现实对象满足这些假设；应用解释需独立依据。

证明步骤或关键引理未知须先解，其他应用可后移。有效窄定理、特例、必要条件或反例本身可形成贡献；缩小命题时保留原命题状态和新命题身份，不能静默替换目标。方法性判断参照[C03](#c03)的逻辑核查；本轮未阅读专用形式证明Skill，不将本文当作完整证明系统。

<a id="c16"></a>
### C16 概念、解释框架与规范性论证

本流程适配：对概念主张检查定义是否一致，区分是否有用且不循环，正例、边界例、反例能否得到相称处理，关键前提能否推出结论。AI用具体例子说明概念改动解决什么混淆；用户不熟悉时不要求先选哲学立场，而从06已有论证给出解释与待核查处。

新框架的内部一致、解释力、实用整理能力和经验适配是不同主张。几项案例能展示用途，不自动证成普遍完整性；概念精确也不能代替经验检验。规范性建议另需明确价值或原则前提，描述事实不能单独推出应该怎样。重要反例或定义争议先解；其他学派或应用只在当前主张需要时扩展。够用是对应范围的区分、论证和例证成立，可交一个窄贡献；不要求统计显著性或饱和。[K2](#k2)

本轮未找到并实测适用于全部概念研究的专用验证Skill；上述是逻辑核查的项目适配，具体学科方法仍须补查，不能以统一“框架质量分”填补空白。

<a id="c17"></a>
### C17 证据综合与混合方法：整个证据体支持哪一种结论

承接14的综合单位、纳入范围、偏倚、不一致、缺失证据及整合结果，核对这些研究是否回答同一主张。元分析或证据多不会自动提高确定性；解释每个重要局限影响哪项结果及适用范围，不以研究票数或显著项比例决定结论。若适用正式GRADE，针对相应问题、结局和比较保留域理由，明确目标范围或阈值，并避免同一问题重复降级。当前GRADE Book概述也区分不同应用，不能把干预问题的起点套用所有研究。[M5](#m5)

AI说明证据确定性、效应意义和行动建议是不同判断。干预综合的应用结论还可能依赖损害、资源、价值偏好等未覆盖信息；Cochrane要求说明这些取舍，不能从一项有利效应直接推出普遍行动建议。[M8](#m8)

本流程适配：质性证据综合使用所选方法的材料充分性、相关性、方法限制和解释连贯等依据；具体CERQual或其他工具未在本轮完整阅读与执行，需正式使用时补读原指南，不套用干预效应GRADE。混合方法检查两条路线回答的是否同一问题、是否共用材料，以及整合过程新增了什么。收敛不自动保证有效，互补不强求同一答案，冲突也不能用多数票掩盖。决定性整合缺口回14或06；够用是主张、证据体与整合逻辑对应。

缺失证据判断从[14手册A17](../14-结果分析/结果分析阶段详细手册.md)实际的研究／结果可得情况继续，不能仅凭已发表材料的平均值。分别说明已知缺失及其理由、可能仍未识别的研究、可得结果占据的范围，以及这些信息会不会改变本项综合结论；不知道缺失结果的方向就保留未知，不因“未报告”直接断言全体有偏，也不因漏斗检验阴性判低风险。RoB 2 D5检查某一已报数值的选择，不能替代整个合成的缺失证据判断。正式ROB-ME的现行路线针对两干预比较的meta分析结果，须依据适用版本完整作答；无合并估计的综合可透明讨论缺失证据，不冒称已完成该工具。这里只补影响结论的连接，具体查找及诊断仍在14同一记录，不复制一套可得矩阵或评级。[Cochrane第13章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-13)、[ROB-ME官方入口](https://www.riskofbias.info/welcome/rob-me-tool)

## 6. 形成允许表达的主张，并决定是否补证

<a id="c18"></a>
### C18 推断语言、适用域与意义应写进同一句核心结论

AI先写一句读者能理解的允许结论，带上对象、关键条件和必要不确定性，再检查是否把限制丢到脚注或最后一段。优先使用与实际依据匹配的动词：观察到、估计、支持、相容、提示、在前提下推出、尚不能区分、与原预期不符。缓和词不能修复错误推理：“可能导致”仍需要因果解释依据；“初步证明”仍不应代替有效证明。

| 实际依据 | 可表达的方向 | 需另有依据的升级 |
|---|---|---|
| 特定材料中的模式或差异 | 在已说明对象与条件下观察到／估计出该模式 | 全体对象普遍如此、独占机制解释 |
| 多个解释仍相容 | 结果与解释A相容，B尚未排除 | 已证实A，已排除全部其他解释 |
| 有效有精度的窄范围检验 | 在相应前提与界限下支持／挑战该具体预期 | 精确零效应、永不成立、任何场景安全 |
| 解释性材料和透明分析 | 该范围材料支持这样一种解释，说明立场与反例 | 人群发生率、因果效果或唯一正确读法 |
| 有效形式证明 | 在列明假设下命题成立 | 现实中自动适用或经验机制已证实 |
| 局部改进及对应代价依据 | 在该任务与资源约束下改善了指定维度 | 全面领先、普遍最优、长期部署有效 |

这是项目表达适配表，不是按词语自动分级的算法。来源支持的关键原则是主张与证据、前提和不确定性相称，不能仅靠措辞营造确定。[K1](#k1)、[M8](#m8)

适用域至少说明会改变主张的对象、情境、测量、理论条件或资源约束；不必复述所有参数。外推是新推断，需有理由与限制，不能把“值得进一步检验”当成当前应用结论。意义复用01贡献定位与05有效校准：小效应可能有实际意义，显著或大效应也可能无实际用途。期刊期待不能改变证据允许的话；稿件承诺需要更强主张时先核查证据，不能让16包装补足。

**确实要说到其他对象或用途时，怎样判断适用性。**只对当前拟外推的一句话检查，不把所有研究升级为全场景验证：

1. 先并置“依据实际来自哪里”和“现在要用于哪里”：对象／时期／情境、比较与实施方式、测量含义、结果时限及资源条件。用户说“实际能用吗”而不知目标条件时，AI先用现有用途提出具体解释；不能把含糊的“现实世界”当已定义总体。
2. 对差异逐项问它会改变哪一连接：结果产生关系、测量可比性、执行程度，还是用途要求和代价？只列有作用者，给已有理论／材料／不同条件结果的依据，区分已知不一致、合理相容和未知。相似人口构成不保证关系或实施相同；构成不同也不自动否定所有限定应用。不用子组检验不显著证明各条件相同，不从一次探索差异自动确立普遍效应修饰因素。
3. 判断证据覆盖与所需假设。目标是否位于已有材料／条件覆盖内，决定性差异有没有依据？重新加权、模型预测或外部评价都需各自方法条件，不能因做过一种便宣称完成因果迁移。决定性前提缺失时，保留来源范围的有效结论；目标场景只给明确条件下的推算或待验证判断。
4. 把结果意义与行动取舍分开。即使关系有理由可沿用，目标基线、实施成本和所需收益也可能改变用途判断；转成新的绝对量或区间须交14核对应计算与未覆盖不确定性。已有依据足以支撑窄用途即可，不固定要求新地区／新机构实验；只有保留本次用途主张确需的新证据才走C19。

构造的风险尺度例：假设有依据地把风险比0.5用于同一结局／时限，比较条件下基线风险若为10%，对应风险为5%，绝对减少5个百分点；基线若为2%，对应为1%，绝对减少1个百分点。它只演示**固定风险比及给定基线假设下**的换算，不证明风险比真的可搬用，也不把优势比当风险比；未传播风险比或目标基线的不确定性，不能配成完整的目标人群置信区间。预测模型换数据来源、质性解释换语境、档案判断换时期或定理用于现实对象时，也须说明对应哪种连接及必要前提，不照套风险公式。[Cochrane适用性§15.2与相对／绝对量§15.4.4](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-15)提供干预综述范围内的方法依据，跨路线的上述提问属于本流程适配。

<a id="c19"></a>
### C19 必要补证、缩小主张与停止：先说它会改变什么判断

把缺口写成“哪项当前主张因什么尚不能成立；什么信息可以改变判断”，再选择最小必要处理。能从现有材料核实的先核实；需重算的回14；设计无法识别则回06；需新增研究证据先回07／08并按00及13确认范围处理。不要把“未来工作可做”全部变成当前必须完成的任务。

AI向用户解释具体取舍：补查某前提、增加一项有区分力的证据、降低归因强度、限制到已验证条件，或按有效停止条件结束。用户不知道时，AI根据当前目标、已有预算和最有信息价值的缺口提出推荐及代价。补证仍需有可能改变判断，不能只追加更容易出正结果的指标、条件或分析。

| 缺口 | 优先处理 | 可以继续交16的条件 |
|---|---|---|
| 主张引用或形成时间不清 | 定位既有记录；无法核实则标未知／探索 | 事实与身份可诚实表达，未冒充独立确认 |
| 数值、编码、材料定位或推导出错 | 回最早受影响来源修复，更新14与15 | 对当前结论有影响的错误已关闭 |
| 竞争解释未区分 | 核查已有区分证据；必要时补证或缩成描述 | 允许句明确未排除处，无独占解释承诺 |
| 关键设计或测量前提失效 | 回06及相应准备，不能只补样本 | 有效窄主张仍存在，或如实报告当前无法判断 |
| 精度或材料不足 | 判断需要更精确证据还是保留未定 | 结论不声称排除了尚相容的重要可能 |
| 只缺未经主张的其他场景或用途 | 写适用域与拓展问题 | 当前窄主张已获对应依据 |

够用线随主张而定：关键依据可追溯，影响结论的前提可辩护或已明确条件化，重要竞争解释及反证得到处理，措辞不超证据。没有统一实验数、引用数、质量分或显著性门槛。资源不足可以缩小有意义范围，但不能保留大主张而删掉必要证据；原预期受可靠反证、当前只能得到未定或有信息的边界，也可按事实完成。改变选题、核心假说或方案的动作按00返回相应关口，保存草案不代表批准执行。

<a id="c20"></a>
### C20 独立核查与向16交接

验收者从一项核心结论逆向读取原证据、14分析和关键前提，检查最强竞争解释、不利结果、共享来源和表述范围。对支持与反对材料使用相同标准；反对意见必须具体指明推理连接及影响。用本阶段新判断复用有效的上游检查，不能仅因结论符合期待通过，也不因结论小或阴性要求无限升级。重要独立发现按00独立复查关闭。

同一研究结果记录中的最小交接增量是：

- 原预期及其形成时间／版本，事后解释和探索身份。
- 每项主要主张的判断、理由、支持及不利证据原定位、关键前提和最强竞争解释；未排除处保留。
- 允许结论句、对象／条件／不确定性，及不能做的表达升级。
- 决定当前主张的未决项，已决定的补证、缩主张或停止去向；无新增事项时引用既有记录即可。

这些是交接所需信息，不是必须照填的新模板。16引用同一依据安排中心论点、证据顺序和读者路线；不得重新裁决结论或把探索解释改为确证。16发现逻辑跳跃、拟增加解释或表达更强主张时回15；涉及新分析／取证继续按[C19](#c19)和00分流。19后续独立审稿也可在这里发现并退回具体问题。

## 7. 节点关系与未知的处理顺序

**先解未知：**当前主张究竟指什么、决定性来源身份、分析对象或版本、关键前提是否失效、重要竞争解释或不利结果是否被忽略。能查明先查明；暂不能查明时暂停依赖更强结论，允许保留条件或未定状态。

**可后移的未知：**未被当前主张承诺的其他场景、未测机制、未来应用、论文具体章节和表达风格。明示未验证范围后可交16；它们不能成为当前主张偷含的前提。具体研究才能确定的效应界限、补证数量、模型、材料规模、形式工具及预算，不在本轮编造数值。

## 10. 从一项结果形成允许结论：判读操作补充

### 10.1 用户只拿一项结果来，也可以开始

收到“这说明什么”“能不能说有效”“这个反例推翻了什么”时，先读实际结果与上下文，提出要判断的具体句子及当前证据范围。用户没有原假说或上游记录时，可判断当前描述、解释或命题，不要求倒造事前预期。只有一个P值、系数截图或脱离语境的引语，先解释它本身包含什么信息，再查影响当前句子的单位、目标、方法、条件及来源；不能由一个孤立值替整篇研究作裁决。

AI先把事实重述给用户，再拆开新增的推断：观察到了差异，是否意味着有实际价值？有价值，是否因为所称机制？在这里成立，是否允许推广？只核查用户本次需要的连接。没有科学依据的更强说法不能靠“初步”“可能”补过关，较窄而有效的回答可以直接交付。

### 10.2 怎样读效应、界限和不确定性

先确认方向、尺度与已说明的意义参照，再看整个区间允许哪些重要可能，最后选择结论句。下表全部是构造输入，假定14已核实对应分析及区间前提；区间不是未经检查的截图片段，也不代表本流程跑过计算。

| 构造输入 | 实际判断过程与可表达范围 |
|---|---|
| 差值为1单位，区间0.4至1.6；上游有依据地把改善2单位作为当前重要幅度 | 区间在正向一侧，但没有覆盖达到2单位的改善。可以分别说明正向差异与未达到该重要尺度的依据；不能只因显著宣称重大价值，也不能把小幅改善一律说成毫无用途 |
| 差值0.4，区间−3至4；同一重要幅度为2 | 同时允许重要损害与获益，当前精度不能区分；保留未定。把“不显著”改成“无影响”会漏掉尚允许的可能 |
| 14已按适用方案完成等效分析，其相应区间落在有依据的−2至2界限内 | 可按该分析支持界限内无重要差异，说明界限、对象、前提与形成时间；不是证明效应精确为零。不能先看结果再挑宽界限并伪称预定 |
| 一项限定应用在同一任务与输入下，用时减少，但其他对象／资源条件未评价 | 可以形成该条件下的效率贡献；准确度、资源代价和失败情形按实际已测内容说明，不自动升级为全面优越或可部署 |

量表越高越差时方向相反；比值尺度的无效值、界限和变换也不同，不能复制上表数字。理论命题按前提与量词判断；质性解释按材料和语境判断；档案缺席按可见性判断，不套“区间跨零”。具体数值由课题给，识别何种可能仍未排除的方法应由AI说明。

### 10.3 强竞争解释怎样从材料里找出来

从当前推理最薄弱的连接开始：结果是否可能由对象选择、共同因素、测量方式、实施差异、材料形成机制或另一理论前提产生？候选须能解释当前重要事实，并具有与主解释不同的预期，不能只是罗列“也许还有因素”。复用02的对手，根据14异常及相关近邻补最有作用者。

构造例：参加培训者后来表现更好，主解释是培训产生改善，竞争解释是更有动机／原基础更好的人更常参加。两者都预期参加者表现好，所以该组间差本身不能区分。已有随机分配、基线资料、时间顺序与适当分析分别能约束哪些解释，回原设计和执行查；控制几个基线变量不能宣称已排除全部混杂。若没有足够区分依据，当前可以报告关联，不能保留因果句只加“可能”。

质性构造例：“线上服务便利”的材料也可能同时显示只有符合开放时段的人受益。回到不同情境和负例，判断应修改主题范围，还是材料只涉及不同问题；不能让出现次数多的读法自动胜出。档案中多个文件若共同转引一份通告，应先辨认同源，不能按三份材料压倒另一份独立反证。理论反例先代入原前提，满足前提才挑战原命题；不满足则检查是否揭示了需要写明的边界。

记录只需在当前主张旁写清：对手为何有解释力，哪项已有证据能够区分，哪些仍相容，当前结论因此怎样受限。新增对照／新材料仅在会改变当前判断时提出，返回07／13处理；本阶段不因发现对手就自动启动取证。C06—C10及已读竞争解释Skill提供问题入口，这些例子是项目适配，不采用加权总分裁决。

### 10.4 有需要时怎样进入正式偏倚工具

先看评价对象与研究设计，而非先选一个流行表。报告清单用于报告，偏倚工具针对相应结果形成过程，证据确定性针对相关证据体；它们不能互换。以下以随机试验结果的RoB 2为一条具体路线，不规定所有研究都执行它。

1. 定位要评价的比较、结局、时点和实际效应目标。分配干预的效应与遵从干预的效应可能需要不同判断；聚类／交叉试验先找对应变体，不能直接套平行个体随机试验版本。
2. 复用正文、补充、协议、分析安排及已有相关报告，先查有影响的信息；未知不改写为“没做”。按原工具逐问题作答并给来源／理由，区分明确依据、合理判断和信息不足。
3. 按固定域和原算法形成建议判断，再核对它是否与本结果的实际情形相称；需要调整时解释理由。不是每个“是”都表示低偏倚，“无信息”也不统一等于低或高；不能把问题加成总分或添加自创通用域。
4. 形成域判断后再按原规则得整体判断：全部域低才支持整体低；至少一域高，或多个疑虑实质降低信心，可能形成整体高。保留域理由及对当前结论的后果，不能只放交通灯图。

**五域怎样据材料推进。**先明确本次是个体随机平行试验的某个具体结果及分配干预效应；不要只给整篇论文贴“低风险”。下表为阅读原工具后的操作导航，不替代其完整问题和算法，不是另制评分表。

| 评价域 | 先取哪些材料，再作什么判断 | 需要辨认的分支 |
|---|---|---|
| D1随机化过程 | 查序列产生、招募至分配之间的隐藏及基线资料，分别回答1.1—1.3；不能只凭“随机试验”四字通过 | 随机序列与分配隐藏是两件事；一次基线P值小不自动证明随机化失败。按实际报告和不平衡理由判断，不能用基线差反改已知序列事实 |
| D2偏离预期干预 | 本节采用“分配效应”分支：查参与者／实施者知晓情况、因试验情境产生的偏离、它是否影响结局及组间是否平衡，再查是否按原分配组作适当分析 | 知晓分组不自动判高；自然发生或协议允许的变化不都属于该分支的偏离。缺结局在D3处理，不能仅因排除缺结局者又在本域重复归因。若研究问遵从效应，换其相应问题链，不能拿朴素按方案分析冒称足够 |
| D3缺失结局 | 查本结局／时点的随机人数、实有值、缺失原因及分析／敏感性，按3.1—3.4条件跳转，见下例 | 插补值不变成已观测结局；重点是缺失会不会影响该效应及与真实结局的关系，不用固定缺失率线 |
| D4结局测量 | 查测量办法、两组的时点／阈值／获取机会、谁是评估者及其知晓情况，再判断知晓是否能、是否很可能影响本结局 | 自我报告时参与者也是评估者；客观记录与需判断的评分不同。对“所选结局能否代表科学概念”的更广争议另作科学判断，不能全塞进本域 |
| D5所报结果的选择 | 对照在可知分组的结局数据可供分析之前最终确定的分析计划、协议及全部相关报告，核当前这个数值是否可能从多种合资格测量／时点或分析中按结果挑出 | 多种方法本身不等于选择性报告；检查选择依据与形成时点。无关结果的未报告不自动使本数值高偏倚，缺计划也不能假装已排除选择 |

各域的问题回答引用真实材料位置，缺失和推断身份分清；查不到信息时按原问题定义处理，不统一补“无信息”或视为低。原工具明确的五域不能自行增删；这不同于当前科研中按需只核一个局部疑问。用户只请求某域时可以交该部分，但不能把部分完成称为全工具完成。

**把缺失域走到底的构造例。**设一项个体随机平行试验，A／B各随机100人，评价的是分配干预对第12周功能分数的效应，分数范围0—100、越高越好；所审数值是原报告表X中完整病例均值差：A有100个实测值、均值60，B有60个实测值、均值50，报告差10。构造的退出记录另明确：B其余40人因功能持续恶化／功能较低而停止回访；没有其他结局值，没有能缓解该偏倚的分析或合理缺失情景敏感性；分析仍按原分配组。上述事实仅为教学设定，不是凭缺失比例猜出的原因，也不是已实施研究。

| 原问题位置 | 本例回答、依据和后续 |
|---|---|
| 3.1 数据是否覆盖所有／几乎所有随机者 | **N。**本结局B缺40人，其可能值足以改变效应。仅作界限算术：B总体均值可在30至70之间，A−B可在−10至30之间；这不是对缺失者填值或合理情景分析，只说明不能称缺失量无关紧要。进入3.2 |
| 3.2 是否有证据表明该结果未被缺失所偏倚 | **N。**教学设定仅有完整病例结果，且没有能支持该结论的分析证据。不能由“按随机组分析”或“ITT”名称作Y。进入3.3 |
| 3.3 缺失是否可能依赖真实结局 | **Y。**已有功能恶化导致退出的记录，存在这种关系。进入3.4 |
| 3.4 缺失是否很可能依赖真实结局 | **PY。**退出原因具体联系功能较低，组间缺失不对称且当前分析未处理这种关系；这比泛泛“任何缺失都可能有偏”多了本例依据。若这些原因本身尚不可信，必须重核相应回答，不能照抄本例 |

按2019版指南第47页的映射及cribsheet第16页算法图，`N → N → Y → PY`建议D3为**High**。评估者仍核理由是否适用于本数值；若要覆盖默认建议，须给材料依据，不能为了较好评级改答案。作为分支对照：若材料充分证明所有缺失只来自与结局无关的记录故障，且足以回答3.3为N，则沿该分支可到Low、3.4不适用；不能因为有40%缺失就跳过原因判读。这里的条件改变是教学对照，不是对原构造例补造有利事实。

**对整体与结论的后果。**其余四域尚未评价时，交付D3 High及其理由、其他域待评，不声称五域完整评价。若其余域已分别有充分依据判Low，按整体规则，该具体结果仍为High，不是四低对一高投票成低。已识别的高域不能因其他域未知被报告为低，但完整评价的缺项仍须说明。High并不证明真实效应为零、相反或研究造假；当前不能把完整病例差10当作已消除该缺失偏倚的稳定分配效应。先查已有结局／退出资料、核原因与分析，必要时回14作有依据的缺失假设和敏感性；不能只补一句“存在失访”便关闭。补后重新回答受影响问题，不能预先保证评级降低。

### 10.5 补证、缩主张还是停止，怎样作具体取舍

先为当前缺口说明“它阻碍哪句话，可能改变哪项判断”。再比较最小动作，而非先决定增加多少实验：已有来源定位或补说明能解除的先做；数值／推导确错先修；现证据不能区分强解释时，考虑有辨别力的既有材料、必要新证据或较窄主张。当前只是精度不足时，先问哪些重要可能需要区分，新数据是否实际可行；不为获得显著而加样本。

一个有效取舍要说明各选项会保留什么、仍不知道什么、耗费何种资源，以及不同结果将怎样改变结论。若新增检查无论得到什么都不会改变当前主张或行动，它可能是可选拓展，不能自动阻断交16。若设计无法识别所称机制，盲目加样本也不能修复；可报告可靠关联、回设计，或按停止条件结束。无重要缺口时直接交接，不再制造反对意见。

构造例：只有某档案的日期不明而核心解释依赖先后关系，优先查目录、原件说明或相关卷宗；再摘十段同一来源引语并不能解决时序。若当前文章只要证明该作者曾提出某观点而日期区间已足够，未查到精确日可以带范围表达，不必扩大成全史考证。小贡献并不放松必要依据，也不因较窄就要求补成全面理论。
