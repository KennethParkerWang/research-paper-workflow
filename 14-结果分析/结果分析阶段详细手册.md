# 结果分析阶段详细手册

本阶段把实际证据分析为可核查的结果；示例只用于说明操作，具体分析须由当前课题材料决定。

本阶段回答：**实际结果是什么，分析依据是什么，哪些质量、选择和不确定性会改变结果的解释。** 15验证结论接收这些结果，判断假说、竞争解释及允许表达的结论。14可以指出分析前提未满足或某种解释存在风险，但不替15宣布核心假说成立。两阶段沿用同一研究结果记录，分别增加分析依据与结论判断，不各造一套数值、证据索引或版本。

共用任务、确认、独立验收、回退及临时材料处理引用[00规则](../00-阶段交接关系/阶段交接关系.md)。本页的分析节点不等于固定小任务，也不新增用户确认关口；涉及新增取证或实验方案实质变化，依00回到07和13处理。来源是学习材料，下面的路线与够用尺度是本流程适配，保存本页不表示用户批准任何真实研究方案。

## 1. 进入本阶段后怎样推进

先复用[07计划及分析安排](../07-制定实验计划/实验计划阶段详细手册.md)，读取13当前有效证据、实际条件、失败依据及偏离；必要时沿引用核对10来源质量、11实现和12基础正确性。不用重新收集已经有效的背景，也不能只拿一张漂亮结果图开始解释。

AI先用普通语言解释“我们计划比较什么、实际取得什么、哪些观察彼此相关”，再提出最少的分析选择。用户不知道时，由AI先读计划、原始记录、变量说明、转录／档案定位或推导前提，提出有理由的候选和取舍；只把资料不能解决、确实改变研究意义的判断交给用户。不能要求用户先报出检验名称、目标量、主题或缺失机制。

一个可走通的思考过程是：核对问题与证据版本 → 明确分析单位和可用范围 → 理解缺失、异常及数据查看历史 → 描述实际分布或材料模式 → 按设计选择适用分析 → 核对前提和不确定性 → 保存包括不利结果在内的完整结果 → 交15判断。质性迭代、理论推导和证据综合可以往返相应节点，不机械套线性流水线。

| AI具体引导 | 用户不知道时怎样继续 | 本轮需要先解除的未知 |
|---|---|---|
| “这些行是不同对象，还是同一对象多次测量？”给出记录示例，解释它影响信息量。 | 从对象ID、分配表、批次、时间、材料来源及代码生成过程重建层级；说明能确定与不能确定之处。 | 独立单位、配对／聚类关系，不能靠数据行数猜。 |
| “希望报告平均差、风险差、排序变化、预测误差，还是材料中的意义模式？”继承06／07的目标。 | 用研究问题各写一条可理解的结果句，解释各句回答不同问题，推荐最贴合设计的一条。 | 主要分析到底在估计什么；不能按哪个结果更有利选择。 |
| “为什么有些对象／文档／结果没进入分析？”对照预定规则与实际去向。 | 查13记录及原始来源；未知标为未知，不能补成技术故障、零值或无效样本。 | 影响主要分母、质量和解释的排除／缺失原因。 |
| “这项选择在看结果以前已经定下，还是看到结果后才想到？”说明探索也有价值。 | 核对计划版本、已有查看与偏离；无法证明事前就如实写明。 | 主要／探索性质及选择影响，不追写成事前决定。 |
| “这项检查会解决哪个疑问，结果不同要怎样处理？”先提出可行办法。 | 查所用方法原始资料与官方说明；按最小必要检查解释限制。 | 影响分析成立的前提；图形美化、稿件位置等可后移。 |

资料缺乏不总是阻断整个阶段。可先完成不依赖该未知的描述；必须为每个后移项说明影响哪项结果、解除条件、暂时能报告什么。例如批次ID不清会阻断假定独立的区间，但不一定阻断原始观察的汇总。方法参数、领域尺度、具体软件版本和分析实现由真实课题决定，本页不虚构取值。

## 2. 先把证据变成有边界的分析对象

### A01 问题、证据与版本是否对得上

AI从07提取主要问题、对象范围、测量／材料、比较、时间点、分析安排和停止规则，再对照13实际取得的证据。用同一结果记录注明该分析引用的输入位置和版本、执行范围、实现／推导依据及偏离链接。说明“计划取得”“实际取得”“能用于此分析”三者的差别；计划完成不能代替结果完整。

没有专门分析计划时，可以为现有证据形成透明的分析说明，但须交代已知结果与选择时点；不能把新说明称为事前计划。发现证据回答的是另一问题，先界定可报告的实际观察，按00回看最早受影响处；不能悄悄改02假说来贴合结果。A01够用是另一位分析者能定位同一输入，并知道哪些比较原本就要做。依据来自S01／S02和S08，具体版本关系采用00规则。

### A02 分析单位、分母和依赖结构

分清对象／分配单位、测量单位、分析单位和欲推广的对象。例如同一对象多幅图、同一参与者多句访谈、同一研究多篇报告，都不自动增加独立样本量。AI应画出简单层级或用几行记录解释关系：对象内重复、配对、中心／学校／批次聚类、空间或时间依赖、文献样本重叠、共同上游来源及共享对照分别怎样进入分析。

每个数值结果注明实际分母：进入研究的人数与有某项结果的人数、事件数与有风险时间、文件数与条款数、参与者数与引语数不可混用。失访、过滤、分组标签缺失、失败运行与配对不完整分别计数；小计与总计要能对账。不能把所有指标套同一个N，不能把算法重复运行或多个随机种子都当新对象。

依赖处理按研究目的选择：对象内差值、按单位汇总、混合模型／GEE、合适的聚类协方差、区组／时间模型或相应重采样；汇总也可能丢失信息，应说明取舍。不能以正态检验、低相关系数或“使用了稳健标准误”证明独立。S01／S02提供单位先行的思路，S11核对协方差类型的区别。够用是主要结果的信息单位与分母可核查，所用方法确实处理已知依赖；若关键层级未知，先暂停依赖独立性的推断。

### A03 质量问题、排除和异常值怎样处理

先复用10／12／13的有效质量检查，再核对本分析新增的单位、取值范围、编码、单位换算、重复、无穷值、无法解析材料、仪器饱和／检测限及条件标签。AI把发现分成有原始依据的错误、适用规则判定的不可用材料、真实极端观察和来源无法确定四类，解释各类怎样影响分析。检查尺度随测量和材料而变，不能拿一张“无缺失”表证明证据有效。

能核对的错误回来源修正，保留原始依据与修正关系；分析排除写清规则、数量、位置、时点和理由。异常标记只是调查入口：回看原记录、测量／操作条件、模型残差和材料语境，决定是否是错误、模型不合适或有研究价值的异例。没有错误证据时，不因离均值远、箱线图打点或不利于预期就删除。需要稳健方法或合理敏感性比较时说明它改变了什么，全部结果保留。S07区别标记、容纳与识别，且其形式检验限定近似正态单变量场景；不搬入统一阈值。够用是处理可重建，原始事实与分析决定分开，关键质量问题未被隐藏。

### A04 缺失、未发生、未测量和未报告

AI按组、时间、变量／主题及对象检查缺失的位置和可知原因，分清空值、跳题、不适用、没有发生、检测限、掉线／失访、原文缺页、没有测量与测了却未报告。零是实际取值，不能拿来填未知；无事件的暴露量仍可能需要进入分母。档案未发现某件事也不直接等于事件不存在。

定量处理从目标量与产生过程出发。完全随机缺失指缺失概率不依赖已观测及未观测值；随机缺失通常是在给定已观测信息后不再依赖缺失值；非随机缺失允许继续依赖缺失值。单凭观测数据一般不能证明机制。完整案例、多重插补、似然模型、加权或敏感性分析各依赖假设；简单均值填补再当实测值会低估不确定性。是否适用、插补变量、层级、模型兼容性及合理情景需按课题判断，不由本页统一指定。保留处理前后分母和敏感性影响。

质性／档案检查缺失集中在哪些声音、事件或时期，说明它限制了哪些模式；证据综合同时区分缺研究、缺结局、缺方差／摘要统计和缺个体。S01提供缺失处理警戒，S14提供综合中分层辨认与假设披露；Cochrane该章的简化缺失措辞不作为所有个体模型的定义。够用不是“已填满”，而是主要结果能解释其缺失假设；无法解除的未知随结果明确交15，不伪造补齐。

### A05 预定、条件分支、探索与已看数据

核对主要分析、已预定条件分支、数据质量修复、探索分析及新增假说各自的依据。AI查看07版本与13偏离，说明谁看过哪些数据／摘要／比较、何时查看、查看是否影响指标、模型、子组、排除、停止或加样本。已有数据库、看过描述统计、尝试过模型或同一批数据的其他论文都可能影响选择；给组名换成A／B不等于盲态。

合理的新分析可以做，按选择性质披露；不要把所有修复统称探索，也不要把结果驱动的选择称为预定。预定分析若不成立，说明原因、原安排与替代结果及限制。中期查看、提前停止和扩大样本须使用与实际规则一致的推断；不能假定最终一次检验仍有原定错误率。S08说明条件决策与已有数据，S01警示选择性报告。本流程不强制所有路线预注册，也不在14补造注册来证明事前性。够用是结果接收者能看懂选择空间和结果知情程度。

## 3. 用描述与目标量确定实际分析路线

### A06 描述结果与图形怎样帮助发现问题

先展示实际对象与证据，不直接从检验表开写。定量按研究问题给各组／条件的N、缺失、位置、离散、范围及必要分布；偏斜或地板／天花板效应时，均值和标准差可能需要补中位数、分位数、零值比例或分布图。配对画对象轨迹或差值，聚类／批次分层，时间或空间资料按真实顺序展示。分组汇总会掩盖或反转关系时，同时核对分层模式及其依据。

图选择服务问题：散点／原始点查看关联与极端值，分布图查看形态，轨迹图查看变化，效应及区间图查看比较。箱线图定义、平滑／分箱、轴范围／对数尺度、面积与颜色编码应注明；图中的线是SD、SE、置信区间、可信区间还是预测区间必须说清。只有几个观察时不要让密度图制造精细结构，误差条重叠与否不能代替对应比较。S05提供原始数据、简单统计及顺序图的诊断用途。

质性先说明材料构成与语境，再展示候选意义模式、异例和定位；档案可用时间线／来源对照；理论用命题、条件与依赖关系；综合用研究特征和结果表。未测到的数据或未经核对的文本不能用AI补画。这里需要可核查的分析图与表，最终期刊样式与放置由17／18完成。够用是主要模式、信息覆盖和明显问题看得见；不设每项研究固定图数。

### A07 假说、统计假设与目标量不是同一件事

继承02／06／07，AI把科学目标翻译为可由当前设计估计的量或可解释的材料关系，解释其对象、比较、时间、条件与尺度。例如“平均改变多少”不同于“变化分布是否不同”，“发生风险”不同于“有事件者中的次数”，“样本内关联”不同于“干预因果效应”。统计零假设只是某个模型中的限定命题，不等于完整科学假说。

定量选原尺度差值、比例／风险差、风险比／优势比、率比、相关、预测误差等时，说明每个数值到底代表什么、方向如何定义及实际意义参照。标准化效应需注明标准化方法，不能把通用大小标签当领域意义。绝对尺度与相对尺度按问题补充，不能只报最显著的一种。调整变量也须说明估计的是何种条件比较，不能自动称为因果效应。

非定量明确关注经验描述、解释性主题、过程／关系、概念区分、命题证明还是证据分布，不能为了“可检验”改成无意义计数。S01／S02用于先界定目标再分析；具体可识别性依06设计。本阶段够用是结果句能明确说出测到或推得什么；识别或测量逻辑失效回06，15接收其有效范围而不是从显著性倒推目标。

## 4. 定量路线：模型、比较和不确定性

下列是方法候选入口，不是自动选检验器。软件能计算不说明适用；具体模型、参数、区间方法及诊断尺度须与真实设计核对。

### A08 选择匹配问题、尺度和依赖的分析

| 目标与结构 | 可考虑的路线 | 要保留的核查与结果 |
|---|---|---|
| 独立组连续均值差 | 已有设计下的均值差及区间；合理的Welch比较，或匹配设计的回归 | 独立单位、尾部／极端值与不平衡；共同方差推断需有依据。方法比较以同一目标量为中心。 |
| 配对或对象内变化 | 对齐后的差值分析；重复／层级模型 | 对象ID、时间、缺对及差值分布；不能把前后两批数当独立组。 |
| 秩／分布或有序尺度 | 与目标匹配的秩检验、分布比较或有序模型 | Mann–Whitney等不自动是中位数检验；对称差值／同形分布等解释条件分别核对。 |
| 二元事件、分类或计数 | 风险／比例差与区间、适当列联或二项模型；计数／率模型 | 每组分母、稀疏格、事件与暴露时间；过度离散、结构零或分离需有过程与诊断依据。 |
| 生存／事件时间 | 生存曲线、适当时间比较或生存模型 | 时间起点、删失、竞争事件、风险集和模型条件；未发生和未完成随访分开。原日期到实际分析输入见[事件时间操作](#event-time-input-workflow)。 |
| 关联／调整比较 | 与结果尺度匹配的回归，必要时适当非线性或层级关系 | 条件效应、混杂依据、模型可识别性与残差；相关不证明机制或因果。 |
| 预测、算法或数值模拟 | 预定评价集的公平比较、匹配的误差／校准、重复条件或数值误差分析 | 评价对象、数据切分、参照设置、随机与数值变化分别报告，详见A12。 |

AI先推荐最能回答A07的一条，再解释真正有科学作用的替代；不把所有软件方法都跑一遍。S03给出匹配目标与依赖的候选，S10确认独立均值检验的参数与输出。方法前提不成立时分析可以简化为透明描述，或回看设计／计划；小样本并不自动选择秩检验或贝叶斯，也不自动证明研究无价值。够用是主要模型、比较和协变量依据清楚，没有为追求预期结果替换问题。

### A09 假设与诊断应检查哪里

独立性主要靠设计及产生过程；配对均值分析关注差值，回归关注条件均值和误差，不能对合并原始数作一次正态检验就宣布全部满足。AI把每项关键前提写成“是什么、依据在哪里、怎样看到不合适、会影响什么”。图形和形式诊断共同使用，未拒绝不是证明成立；样本少可能检不出问题，样本大可能检出很小偏离。

按实际模型核对非线性、异方差、残差／时序结构、影响点、秩缺失、共线性、完全或近完全分离、收敛、边界估计及过度离散。不同问题用不同诊断，不能通用套VIF或残差正态。处理包括与设计一致的模型、适当方差估计、变换、稳健方法或敏感性；变换／秩方法改变目标尺度时说明。HC3针对独立误差下异方差，不能处理全部聚类或混杂；优化器收敛也不证明参数被识别。S04与S11供核对；没有统一N=30、事件数或诊断p值作为通过线。

够用是最影响主要结果的前提有依据，诊断异常及实际动作可核查。模型太复杂、信息不足时减少无依据参数或改为描述，保留损失与限制；不能靠自动删变量／反复换模型消掉警告。方法本身不成立回06，实现错误回11并补12，分析错误在14修正并同步下游。

### A10 效应、区间与不同来源的不确定性

主要比较报告估计值、单位、方向及适用区间，必要时补原尺度与标准化结果。AI解释SD是观察的分散，SE是估计精度相关量；置信区间依重复抽样解释，可信区间依所设模型与先验，预测区间针对新观察。不能把一种区间换名字，也不能把样本变异当测量、模型或外部适用性的全部不确定性。

区间计算要匹配单位与依赖。重采样须说明对什么单位采样、如何保留配对／聚类／时间结构，置换须有交换性或设计依据；重采样次数多不能弥补独立单位太少或设计偏差。近似、离散、边界、稀疏和非正则情形需核对方法限制。随机种子、数值精度／收敛误差与对象抽样变化分别记录，不能把模拟精度当真实世界确定性。

若用p值，报告对应模型、假设、检验、尾侧、统计量及适当自由度／样本依据；p值不能给出假说为真的概率或效应重要程度。贝叶斯还需先验依据、似然、先验／后验预测、计算诊断和合理先验敏感性；后验方向概率不等于Bayes factor，后者另有模型比较与先验条件。S01给估计与完整结果，S06支持p值解释边界，S14相关段比较两类区间。够用是主要结果精度和重要未覆盖误差能被读者理解；不是所有研究必须有p值或贝叶斯模型。

**测量值再经修正、求差或归一化时，怎样传递不确定性。**复用06的测量模型和10的校准／参照依据，先说明本次量是同一对象的测量结果，还是对象总体的均值／效应；两者的误差来源和区间身份不能混用。处理顺序是：

1. 写出实际计算关系及单位，如`y=读数均值+修正量c`或`r=样本值/参照值`。逐项定位估计、标准不确定性及其来源；证书给扩展不确定性U时按所载覆盖因子k恢复`u=U/k`，不能见“±”就当SD或一律除以2。只有上下限时，所用分布需有理由；未知不是0。Type A／B区分数值评定办法，不分别等于随机／系统误差，也不代表高低质量。[NIST分类说明](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-2-classification-components-uncertainty)
2. 回测量过程辨认共享来源：同一个校准修正、同一次空白／参照测量、共同拟合参数会怎样进入多个值？保留同一输入的身份及必要协方差，别把复制出的相同数值各当独立测量。近线性模型可按各输入对输出的灵敏度合成方差，相关项也须进入；不能把所有相对百分数或原单位SD直接相加。[NIST传播律A.1—A.4](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty)
3. 检查所用近似会不会改变当前判断。分母接近零、曲率重要、输入分布或输出明显不对称时，先查适用的分布传播／数值方法；若用Monte Carlo，每次从有依据的联合输入分布取值，重算输出，共享量在该次取值中共用，不能给每行独立抽一个“共同校准”。核查数值稳定性及区间类型；不以固定抽取次数证明有效。未知分布或相关性只能作有依据的情景敏感性并保留未知，不能因能模拟就补造真实误差模型。
4. 在同一结果记录注明主要分量、关联处理、计算办法、未覆盖来源及其对结果的影响。交18时区分合成标准不确定性u、扩展不确定性U及覆盖因子／覆盖依据，与抽样置信区间、对象间SD分开。`k=2`本身不能保证95%覆盖。[NIST扩展不确定性§6](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-6-expanded-uncertainty)、[报告§7](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-7-reporting-uncertainty)

构造算例：同一稳定对象独立重复100次，读数SD为0.20 mm；同一加法校准修正c的标准不确定性为0.30 mm，假定它与这些重复读数独立，暂不含其他来源。读数均值分量是0.020 mm，`u²(y)=0.20²/100+0.30²=0.0904 mm²`，合成标准不确定性约0.301 mm，不是把0.30也除以√100。若比较两个均值且使用完全相同的加法c，`(均值甲+c)−(均值乙+c)`中的c会代数抵消；不同校准、漂移或乘法修正不能照搬该抵消。共同参照R下的`x1/R`与`x2/R`通常相关，R有不确定性也不等于所有比较都同样变差：先把最终对比写成一个模型，再看哪些共享量抵消或保留。这是条件明确的算术推演，不是仪器校准、总体效应估计或95%区间。

### A11 多重性、探索扫描与敏感性不是同一件事

AI把主要判断涉及的指标、比较、子组、时间点、模型及查看列清，继承07的主次与条件分支。解释很多尝试会增加碰到有利结果的机会，然后按目标选择：预定比较族的错误控制、探索发现的合适FDR策略、联合模型或明确的探索性报告。不能将分割成多篇论文、只展示其中一项或标“主要”作为消除多重性的办法。校正方法、比较族及原始／调整结果要明确；校正也不能消除结果驱动的模型选择。

敏感性每项回答一项有依据的疑问，例如缺失假设、合理排除规则、影响点、模型形式、先验、误差结构或材料解释改变后会怎样。按合理范围报告结果及不一致处，不能将主分析换成最有利版本，也不能让全部方法同向代替设计有效性。子组差异要比较差异本身或交互；“一组显著、另一组不显著”不证明两组效应不同。S01／S03支持分析族与透明选择，S14第10.14节支持决策敏感性；跨领域具体办法需适配。

够用是主要选择风险和最可能改变结果的合理决定已有说明，不要求每项研究固定敏感性数量。新增分析先说明性质与范围；若需要新增证据或方案实质改变，按00处理，不能在14悄悄追加到结果满意。

### A12 预测、计算比较和模拟结果的额外核查

AI先解释评价的是新对象表现、同对象未来时点、限定数据集表现，还是数值方法性质。核对训练／调参／评价边界及对象、时间、来源重叠，查看标准化、插补、特征选择是否只从允许的训练材料学习；最终评价集反复指导选择就已参与开发。S12官方说明提供这些泄漏操作的例子；它不能自动解决领域偏移或所有数据相关性。

公平参照要核对同一输入、评价协议、预算、实现版本和必要设置。比较最好使用相同评价对象的差值并保留依赖，不把交叉验证折、重复拆分或种子当完全独立样本。按对象／数据集／运行条件分别说明误差来源；只对固定测试集做有限比较时，就报告该范围，不能声称覆盖所有任务。分类的类别分布与混淆、概率校准、预测误差的分布按目标选用，平均性能不能遮住失败情形。

数值／模拟说明离散化、停止容差、求解误差、模拟次数／随机性及与理论目标的关系；复用12已有正确性证据，14检查这些因素对实际结果的影响。无法运行、超时、数值崩溃与有效但差的结果分别保留。够用是主要评价独立性和公平性有依据、适用范围清楚，有限改进也可成立；不默认新增全部数据集、全部基线或大量种子。

#### 随机方法模拟：从生成的数据到性能及其Monte Carlo误差

本段用于以重复生成的数据评价统计方法、检验或预测程序，不替代A10的测量分布传播或11已有的离散求解核查。复用07已定的评价目标、情景与资源安排；用于研究取证的生成检查、试运行和正式模拟依00和13的有效确认范围，纯开发正确性核对沿11／12已有规则处理。下面只研究怎样做，不启动运行。

1. **先对应问题、生成机制与方法目标。**把当前要比较的性质写清：估计某个量、控制零假说下的错误拒绝、预测新对象，还是考察特定失配。逐情景确定生成哪些对象和变量、分布／关系、固定与变化条件、各方法实际可见的信息和所用设置。参数估计须核对目标量及其真值，条件效应与边际效应不能用同一个真值打分；真值未知就不伪报偏差或覆盖。若真值来自数值计算或独立参考估计，保留其依据和误差。情景有意违反哪些方法条件要写明，结果只回答这些条件下的问题，不用有限模拟证明一般一致性或现实有效性。
2. **先核生成器和方法，再扩大重复。**沿生成式检查软件参数代表SD还是方差、变量支持范围、概率／相关结构及约束是否如设想；有理论矩、已知特例或已知性质的方法时，用相应依据检查实现。按需要查看生成分布及关系，解释允许的随机波动；原机制要求随机抽取时，不能强行把每份数据的样本均值／相关系数修成总体设定值，以免改变生成机制。确认单轮的对象、真值、方法输出与失败记录对应，再检查所选不同条件；没有运行的检查不记成通过。实现错误回11／12，生成安排本身不回答问题则回06／07。
3. **分开数据集内规模n与重复数R。**n描述每份数据的对象规模，聚类等结构还须说明各层规模；R是同一情景下重新生成整份数据的次数。改变n是在研究另一种信息条件，增加独立重复R是在提高该条件下性能估计的精度。一个数据集内的bootstrap次数、MCMC迭代或算法随机种子，不自动成为R份独立数据；有依赖的重复也不能直接套独立重复的误差公式。
4. **每轮先生成一次，再让方法比较同一输入。**以“情景—重复标识”对应数据和各方法的结果；跨软件亦保持同一份输入的含义。分别保留生成过程与方法内部随机计算的身份、所需起始状态／随机流及实际设置。按所用环境的可靠机制分配不重叠的随机流，续跑和并行时能找到原重复，不能在循环内反复重置同一状态而生成相同数据，也不能把同轮方法当独立样本。固定种子帮助复现，不能证明生成器正确、重复独立或比较公平。
5. **保存本项性能真正需要的逐轮结果及失败去向。**在已有结果位置按需保留目标与真值、估计、方差／SE、区间端点、检验决定或预测损失，以及未运行、报错、不收敛和无有效区间等原因。先核每情景计划R、实际尝试数、有效估计数、有效区间数等是否对账，再看估计分布、异常和方法间差异。每项性能注明自己的有效重复数R_eff；只用成功轮次计算的量是相应成功条件下的性能，不能默称全部尝试的表现。失败率以相应尝试为分母；失败不能静默补成零误差、不拒绝或未覆盖。预定的失败后替代程序若也被评价，应说明评价对象已是整套程序；不为消掉失败临时换法而隐去原结果。
6. **按评价目标选性能，并估计有限重复的误差。**在固定情景、真值θ₀固定且本项重复可评价时：偏差是`mean(估计−θ₀)`，经验SD是估计在重复间的SD；需要兼顾偏差与分散才另看RMSE。覆盖是区间包含θ₀的比例，不是包含本轮点估计；检验拒绝比例在零假说确实为真时才评价第一类错误，在指定备择下评价功效。预测按实际目标选损失、校准等，不强凑偏差／覆盖全表。模型给单份数据的SE、重复间经验SD，以及性能估计的Monte Carlo标准误（MCSE）是三种不同信息。

对独立同分布、具有有限方差的逐轮贡献q，性能为其均值时，MCSE可由`s(q)/√R_eff`估计；偏差取q为估计误差。独立Bernoulli的覆盖／拒绝指示可用`√[p̂(1−p̂)/R_eff]`估计MCSE。p̂为0或1时该代入式虽给0，不能据此说没有模拟误差；很少事件或边界比例需用适当二项区间等说明不确定性，不机械给零宽正态区间。[NIST比例区间说明](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm)

比较方法时保留同轮配对：对均值型性能，先形成每轮差`d_r=q_Ar−q_Br`，再以`mean(d)`和`s(d)/√R_pair`报告差及其MCSE，不能把两项MCSE按独立相加；仅两法均可评价的配对数及因此产生的条件范围须交代。经验SD、RMSE等非均值型性能不能直接套前述q公式；确需其MCSE时核适用解析式，或以独立重复为单位重采样、每次重算同一性能，再用所得性能分布的SD估计MCSE。同轮方法列一起抽，保留失败处理规则；还须核有效重复、分布与重采样稳定性，额外抽取次数没有统一值。[Koehler等2009，§2及§4.1—4.2](https://pmc.ncbi.nlm.nih.gov/articles/PMC3337209/)

构造例：每份数据有n=200个独立对象，同一零假说情景独立生成R=100份，均取得有效检验，5次拒绝。估计拒绝率为5%，其Bernoulli代入MCSE为`√(0.05×0.95/100)≈0.0218`，约**2.2个百分点**；分母是100次重复，不是200个对象或20,000行。它没有证明真实错误率恰为5%，也没有给出精确区间。增加n可能改变方法表现，增加独立R才针对这里的Monte Carlo精度。计划R应从主要性能允许的精度和预算出发：例如对预期比例p₀、所需MCSE ε，可用`R≈p₀(1−p₀)/ε²`作相应独立Bernoulli规划；p₀未知时可考虑其最大方差情形或有依据的初始估计，ε不是95%区间半宽。按原精度／预算／停止安排核查是否足够，需要时续加新的独立重复，不停在恰好有利的比较；不足则报告当前精度及限制，不统一指定R。

交15时给当前情景、方法目标、有效性能及MCSE／相应区间、失败和各自分母，并说明哪些条件未覆盖。相近数字的排序不自动支持优越性；更多重复只能减小相应随机模拟误差，不能修复错误生成机制、目标不匹配或未覆盖情景。[Morris、White与Crowther 2019，§3—6](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/)提供生成、逐轮记录、性能和报告的原方法依据；本段将其接入已有阶段与结果记录，不另建模拟框架。

### A13 解释性主题分析：从材料到意义模式

继承06／07的方法取向，先分清反思性主题分析、编码可靠性分析、内容分析及其他质性方法。AI说明描述字面内容与解释潜在意义、归纳与理论引导的作用，给一小段已有材料示范可能读法；示范不当作完整分析，用户无需预先给主题。先熟悉整个材料集、形成代码和解释，再发展并回看候选主题，检查每个主题的中心概念、内部差异、相互边界与研究问题的关系。主题不是访谈问题标题、码表汇总或软件自动聚类结果。

同一结果记录保留材料定位、代码／主题的关键变化及解释依据；按实际用途复用既有备忘录和编码位置，不为每次想法建新文件。查找异例、不同语境和较少出现但有意义的经验；引语的作用是让读者核查解释，数量与选择按主题复杂度和材料而定。AI可以提出代码、比较及反读候选，研究者须逐条回到原文及上下文，不能用AI摘要冒充参与者话语或漏掉相反材料。

S09主文／05提供流程入口，S13作者官网说明循环性、主题及质量思路。反思性主题分析不以编码者一致率、统一固定码本、固定引语数或信息冗余式饱和作为当然验收门槛。够用是分析在方法上自洽，主要模式具有可定位材料与解释，研究者作用和例外透明；研究者对材料的解释并非未经分析的客观事实，15再判断能承载的主张。

### A14 内容编码、计数和政策文本分析

当问题需要系统分类或计数时，AI先说明代码来自现有理论、材料归纳还是二者结合，以及记录单位、语境单位和分析单位。定义类目、包含／不包含规则、歧义处理及是否允许多重编码；不能对所有文本强求互斥类目。先用合适材料检查规则，再按实际设计作编码与必要一致性评估，保留修订依据。双人编码或Kappa只是特定测量可复制性的一类证据，不能保证分类有意义。

统计时说明是条款、文档、参与者、字符、编码引用还是共现，分别定义分母；多重编码占比可能不合计为100%，文件长度、重复转载和版本关系会影响频次。报告类目与材料的对应及代表性／反向例子，不能从词频直接推断态度、重要性或因果关系。政策工具框架须有研究依据；某类工具比例高低本身不证明“失衡”，评价需要另有目标与判据。

S09的08与06支持类目、定位、单位和一致性记录；舍弃其统一阈值及默认评价句式。若实际需要一致性，先定编码单位、比较范围、独立编码、类目分布和指标，报告相应结果及分歧；不为提高数字先协调答案后假称独立。够用是编码和计数可重建、意义解读有语境、选择与歧义可见；具体软件查询以实际版本的官方说明为准，本页未验证NVivo／MAXQDA点击路径。

### A15 扎根、个案、过程与档案材料

扎根理论仅在上游确需发展理论时使用。按已选方法传统持续比较事件、代码及范畴，说明范畴的属性、关系、适用语境和异例，保留材料如何支持或改变关系的分析依据；不能把主题列表加箭头就叫理论。S09的04提供比较与备忘录思路，其流派一一对应及“顶刊偏好”表述不是方法认证。本阶段不自行换流派；如果需要新取样检验范畴，回07／13确认范围，当前未发展的关系如实列为缺口。

个案／过程分析先明确案例边界、事件时序、观察来源和比较维度，在案例内建立事实链，再按设计进行跨案例比较。AI提示“同一表象还有哪些材料解释”“这一环节实际证据在哪里”，并区分材料明确陈述、分析重构和缺少证据。选择异例或反向材料须说明与问题的关系，不能只摘最顺畅的故事。对过程机制的可信程度交15，不靠时间先后直接宣布因果。

档案与历史资料进一步核对创造者、目的、受众、写作与所述事件时间、版本／转录及保存／编目选择，区分亲历记载、回忆、二手引用与解释。同源转载不是独立对证；材料矛盾可能来自立场、时间或术语变化，应并列分析，不能一律清洗。S15提供原始材料提问法；具体档案操作和证据充分性仍依领域方法。够用是重要事实、关系、冲突与未覆盖部分可追踪，有限时段或案例也可形成结果，不统一要求案例数、饱和或显著性。

### A16 理论推导与概念研究

理论结果先把命题、定义、量词、适用域、假设和依赖引理写清，逐步核对每个推理使用的前提、符号、条件与结论范围。AI从目标逆向寻找必要前提，再顺向复查每步是否真的推出下一步；特别检查局部假设是否被误用于全局、必要／充分条件是否颠倒、边界／退化情形及反例。S16第3章为这种前提和作用域检查提供教学依据，不强制所有证明形式化。

13取得的证明、计算与例子在14分别注明：完成证明、条件性推导、数值迹象、失败步骤或反例。定理调用需核对适用条件；仿真吻合、符号工具返回表达式或几个例子不是普遍证明。若使用形式化／计算工具，复用11／12已有实现与基础检查，仍核对工具形式化的命题是否就是原问题。缺关键引理时，保留已有效部分与缺口，不能润色成完整结论。

概念路线重建定义、论证前提、步骤与可区分的案例，检查概念是否被循环定义、案例是否偷换前提、规范判断是否夹带在描述中。通过有作用的边界例／反例比较解释；不要求制造数据或统计检验。此段为项目方法适配，未找到并阅读覆盖所有概念研究的专用Skill，不把逻辑教材当完整哲学方法。够用是实际推得的命题及条件可核查，普通限定应用或局部辨析也可交接；意义、竞争理论与贡献强度由15／16继续处理。

### A17 证据综合：先检查能否合并，再分析

沿13证据索引辨认“研究”与“报告”、共享样本／对照、同一研究多结局和时间点。AI解释合并要回答共同问题，先核对对象、比较、测量尺度、时间与设计是否足够可比；不能因为软件可输入就合并。先完成每研究结果提取与核对，再说明选择结果、转换尺度、权重、依赖处理和缺失数据的依据，不按最有利方向选取。

可数值合并时，说明共同／平均效应目标、模型条件、区间与异质性；随机效应并不自动消除不可比性、偏倚或结果选择。少研究时异质性和亚组解释常不稳定，不能以异质性检验不显著证明没有差异；预测区间也依模型与足够信息。S14第10章是干预综述中的方法入口，不作为所有综述默认分析。

不能合并时仍须有明确方法：按问题和条件结构化表列各研究的估计／方向／精度、研究特征与缺口；说明如何分组、比较和形成模式。不能只写“叙述综合”，也不能数显著论文的票来判断总体效果。效应方向汇总只能回答有限的方向问题，不能代替大小或精度，使用时需核对独立研究、方向规则与限制。S14第12章支持替代合成及其边界；正式偏倚与证据确定性判断交15。够用是读者能追到每个综合结果的来源和选择，没有强求一张合并菱形。

**可得结果会不会只是被选择的一部分。**先固定当前综合的比较、结局、时点及合资格的结果类型，再沿13已有研究／报告索引逐研究核对注册记录、协议、分析安排、正文及补充，不另造全项目索引。区分“整个研究尚无可得报告”“已知测过该结局但所需结果缺失”“有结果但缺方差／所需分析”“本来未测或是否测过未知”；未知不能改写为选择性不报告，也不能把缺失改成零。实际联系作者取得资料属于按00另行处理的外部动作，本手册研究不发送消息。[Cochrane第13章13.3.1—13.3.3](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-13)

在现有提取记录就近补可用位置、缺什么、已知原因与哪些结果因此未进入此项合成；合资格但无法计算的研究仍在证据描述中。构造例：五项合资格研究中四项有12周结果，第五项注册了12周测量但报告只给6周值。先核是否延期／另有报告或未完成测量；没有依据时写“12周结果不可得／原因未知”，不能拿6周替代、填零或将第五项从综述抹掉。14可报告四项可得结果的分析与未覆盖证据，15再判断缺失的可能机制、规模和影响是否允许总体结论；仅有注册条目不证明已经实施或得到某方向结果。

漏斗图只作为有条件的小研究效应线索：检查独立研究数、精度差异、效应尺度及异质性，再选适用图／检验。干预meta分析中“不足10项一般不宜做不对称检验”是该方法的经验条件，达到10也不保证适用，精度几乎相同或尺度与SE数学耦合时还需另判。不同真实效应、研究实施质量、尺度耦合及偶然性均可造成不对称；对称或不显著亦不能排除缺失。不能统一跑Egger后按P值宣布发表偏倚。[Sterne等2011原方法文章](https://www.bmj.com/content/343/bmj.d4002)

需要敏感性时，先说明要检验的缺失／选择假设和可能改变哪项结论，再比较有依据的情景；选择模型、trim-and-fill等有各自条件，调整值不是找回的真实效应，稳定也不证明没有未知研究。不能合并时仍可对照各项证据是否可得及其影响，不强补漏斗图或合并估计。这里提供缺失证据处理入口；完整ROB-ME评价另按[官方现行工具入口](https://www.riskofbias.info/welcome/rob-me-tool)及原指南核适用对象，不因做了上述核对就声称完成工具。

### A18 混合方法：把对应与不一致也作为结果

只有原设计需要才组合多条路线。AI先说明是质性解释定量、质性形成待验证概念，还是并行比较；分别完成两侧适用分析，再在同一结果记录用联合表或短段把同一问题下的对象、时间、尺度、定量结果与材料模式对齐。不能把两套不同对象的结果强称为相互验证。

对应一致、互补、矛盾或无法比较分别记录；冲突时先查对象范围、测量含义、选择、时序、语境与质量，再判断需回看哪里。质性主题转成变量时说明转换依据与信息损失，后续检验不能把转换过程的选择隐去。S09的10提供整合入口，但“定量回答是不是、质性回答为什么”只是简化说明，不足以约束所有问题；合成后允许相信的整体解释交15。够用是整合真正增加问题相关信息，两侧质量和不一致都可见；无需为用多种方法增加任务。

## 6. 结果记录、交接与必要回看

### A19 保存可核对的结果，而不是只有结论句

在13已经使用的结果记录和证据位置增加本阶段内容，按路线保留以下必要信息，不强制一个新文件或统一格式：输入／版本与分析范围，问题及目标量，单位／分母／依赖，处理／排除／缺失依据，预定或探索性质，方法与实际设置，主要结果及不确定性，诊断／敏感性、异常／不利结果及未决问题。计算结果引用可复核的分析实现和实际输出；材料解释引用原文位置、语境与关键解释轨迹；理论结果引用命题、前提和推导步骤。软件输出和分析者解释分开。

数值核对方向、单位、百分点与百分比、比值尺度、总数／小计、每结果N、区间端点、统计量与适用自由度。精度按测量与表达需要统一，保存可复核的未四舍五入依据；极小p值不用p=0表示，任何缺失或无法估计值不能填成0。图、表、正文中的同一数值应引用同一分析依据，最终稿件一致性18／19复核。

所有预定主要结果都要有去向，未执行／不可估计注明原因；有效负结果、条件混合和不确定结果不隐藏。非显著不是无效应证明；不能用观察效应计算的事后功效弥补缺乏精度。等效、非劣或“接近零”的专门主张须有适当目标、界值及方法依据，14给出相应分析，15判断是否支持。来源S01／S06；没有预设界值时不得看完结果挑一个有利界值。够用是接收者能复核实际结果，清楚其质量和局限，无需读完整聊天猜选择。

## 10. 从实际输入做到可核查结果：操作补充

### 10.1 用户可以带着局部材料进入

“帮我分析这张表”“这份模型输出是什么意思”“帮我编码这段访谈”都是可直接承接的任务。AI先打开材料，提出当前能回答的一个具体问题和首选办法；没有07或假说记录时，形成诚实的当前分析说明，保留已看数据与探索身份，不要求补办完整科研链。只有输出截图时可解释可辨认内容，不能猜缺失的设置、精确数值或诊断结果；先查其对应实现／完整输出，再决定哪些判断暂不能做。

先处理会改变结果含义的未知，例如一行代表谁、分组怎样产生、零和空白怎样编码；用户不知道时先从输入结构与说明重建，并用几行记录解释。颜色、最终图宽、期刊小数位等留18。只要求描述就完成有边界的描述，不顺便开展整套检验；要求推断时再核对其设计依据。

### 10.2 先形成正确的分析对象，再选择计算

1. **辨认键与层级。**先抽看实际行，确定对象、时间、条件、文档／研究标识组成的定位键。检查键重复意味着真实重复测量、合法多条材料，还是导入／合并错误；不能直接去重。保留能够回原记录的标识，行号不是稳定对象ID。
2. **按需要重排，不改变事实。**前后测宽表可变为“对象—时间—值”长表，也可按对象对齐后计算差值；转换后核对对象数、时间数、缺失与几个对应值。若同一对象同一时间有两条值，先查它们是什么，不能用默认求平均让转换成功。
3. **合并时先说明对应关系。**人口学表一对象一行，观测表可一对象多行；按这一关系合并，检查未匹配对象、行数变化与重名列。两侧键都重复会产生组合行，不能把增加的行当新增样本。未知ID不能彼此配成同一人。
4. **形成有依据的分析列。**注明方向、单位、参考值、分母和计算式。百分变化与原尺度差回答不同问题；基线为零时不能照算百分变化，不能为取对数任意加常数。类别编码1／2不表示其间距有科学意义，参考类别和有序性须明确。
5. **确定当前分析集。**说明哪些对象能回答该问题、哪些因何缺失，保留主要分母和选择依据。描述可以使用部分可用值，配对比较则须保持配对；采用完整对仍不保证缺失无偏。需要模型／插补处理时按A04选择，不用一个统一“删空值”按钮处理全部问题。

构造例：P1前后值为2和4，P2为5和6，P3为4和3，P4只有前值8。若当前只描述完整对象的“后−前”，差值依次为2、1、−1，三对平均变化为2/3；有四个对象、七个已观测值、三对可用于该项比较，三个数都要有不同名称。不能把两列分别去空后相减，也不能把该均值描述成四个人的平均变化。是否能据三对推广或比较干预效果，仍取决于设计、缺失及相应推断；本例没有计算检验或区间。

已有pandas环境可用[merge官方参数](https://pandas.pydata.org/docs/reference/api/pandas.merge.html)的`validate`检查预期对应关系，用`indicator`辨认未匹配；它的空键可能互相匹配，须先核对。按[reshape说明](https://pandas.pydata.org/docs/user_guide/reshaping.html)区分`melt`／`pivot`的重排与`pivot_table`的聚合。遇到重复键先解释科学含义，再决定是否有依据聚合。用R、表格或其他环境时检查同一件事，无须为这些操作换工具。以上为本流程操作适配，10仍负责来源准备，14只增补本分析所需转换。

### 10.3 从方法选择到输出判读，而非只取一个P值

AI先用结果句解释要估计什么，再给出与A08匹配的一条首选路线：输入哪些列、怎样处理已知依赖、估计哪个比较、需要哪类输出。已有方案有效则复用；改变方法会改变问题时先说明。实际执行时沿用现有分析环境，核对该版本官方参数，明确缺失策略、方向／参考组、尾侧、区间类型及适用设置；不靠默认值替研究决定。

获得输出后，先检查实际使用的对象数与设计矩阵／比较是否如预期，再读估计值、尺度、区间及关键诊断。将模型项翻译成“谁相对谁、在其他条件怎样时、相差什么量”，再写结果。不能把截距、每个系数、整体拟合与目标比较混成同一种效应。

构造的线性均值关系`E(Y|x,g)=10+2x+3g−xg`中，g=0时x的斜率为2，g=1时为1；同一x下g=1与g=0的差为3−x。于是系数3只表示x=0处的组间差，不能写成所有x下固定差3。若x=0不在有意义范围，先选择有依据的比较位置或中心化解释，不借此改变数据。比较的区间需由完整协方差与适当方法计算，不能把两个系数区间随意相减。此例仅核对代数读法，不是拟合结果。二项／计数等有连接函数的模型还须区分线性预测尺度与概率、率等响应尺度。

| 实际现象 | 先核查与可采取的动作 | 不能以什么冒充解决 |
|---|---|---|
| 输出N小于预期、某组消失 | 回查筛选、变量缺失、类别与连接键，解释实际分析集；必要时修正输入映射 | 改表头N或隐藏软件删行 |
| 设计矩阵秩不足、系数不稳定 | 查重复／线性依赖变量、空类别、参数是否可由当前数据区分；有依据地重参数化或减少不可识别项 | 仅看到“成功返回”就报告全部系数 |
| 完全／近完全分离、极大系数或区间 | 查事件与类别分布、模型适用性及可识别性；评估适合该目标的估计办法或诚实描述 | 只增迭代次数、自动合并类别以求显著 |
| 不收敛或边界估计 | 查输入尺度、参数约束、起点及模型与数据是否相容；复核参数和目标函数稳定性 | 勾选“收敛”或换优化器即认定科学有效 |
| 拟合可以，残差结构／影响点提示问题 | 对照A09定位受影响前提，回原记录、评估有作用的模型修正与敏感性 | 自动删不利点或把所有诊断跑齐 |

实际结果连同这些动作写回同一记录；没有合适推断可报告透明描述和限制。14交付的是可复核的估计／材料结果，不替15解释因果或贡献大小。操作依据包括已读统计分析Skill，以及[statsmodels公式示例](https://www.statsmodels.org/stable/example_formulas.html)与[Pitfalls](https://www.statsmodels.org/stable/pitfalls.html)；示例软件不是统一技术栈。

#### 事件时间资料：从原日期到可核对的在险记录

只在当前研究需要时选用。先继承06／07的对象、比较、时间尺度、终点与观察范围，说明要估计基线状态或随时间变化状态的关联、指定时点的累计发生概率，还是有另行识别依据的因果效应；这些目标不能因某个模型容易运行而互换。下例限首次事件，不直接承担复发事件或全部多状态分析。

1. **先把真实日期与含义交齐。**从10／13引用稳定患者ID、资格条件及日期、可靠观察开始、既往用药及其可查范围、启动／停止依据与日期、首次目标事件、死亡、末次可靠结局获知日期、资料截止和来源版本。区分处方开立、领药与实际使用，诊断／发生日期与录入日期；缺哪种依据就限定为哪种记录暴露或保留未知。无既往记录不自动等于从未使用；既往使用者如何纳入由既定目标决定，不统一删除。协变量也要知道何时取得，不能静默用之后的值作基线值。
2. **把资格、时间原点、进入观察和暴露起点对齐。**按有效方案把日期换成同一尺度，保留原日期；基线暴露按该时点已成立且有据的状态编码，不能用“随访曾使用”回填基线。若目标采用随时间变化的启动状态，启动前后分别编码；未知停药不补成持续服药。改用固定后续时点选人等办法会改变比较人群／问题，先回06／07判断。所选原点早于实际进入时，以迟进入／相应左截断表示进入前未处于本分析风险集，不能补作无事件随访；左删失则是事件已发生在某界限前但确切时刻未知。仅知事件发生区间时保留上下界，不能擅取中点当精确日期。调整进入时间仍不能找回入组前已死亡者或自动消除选择偏差。
3. **形成与目标相配的终止状态和必要区间。**首次事件路线按有效定义确定目标事件、阻止其再发生的竞争事件、可靠观察终止或资料截止哪个先发生，保留原因；末次门诊日是否就是结局可获知的终点须查数据生成过程。无新病历不等于一直无事件，失访与死亡不能混成同一种缺失。需要随时间更新暴露时，在实际进入、有效更新与终止处形成`ID／start／stop／暴露状态／区间末事件类型`，并可回到原记录；同一人拆多行不增加人数。具体工具核其区间边界和事件编码。例如R survival的计数过程使用`(start, stop]`，更新从下一段起作用、事件记在段末；同日先后不明时回源核精度，或按有依据的约定／敏感性保留限制，不补造小时或任意加极小值。[维护者time-dependent文档§2／3.1](https://www.stat.math.ethz.ch/R-manual/R-devel/library/survival/doc/timedep.pdf)、[Surv定义与编码](https://stat.ethz.ch/R-manual/R-devel/library/survival/html/Surv.html)
4. **先沿少量有辨别力的患者时间线手核，再接模型。**核起止次序、重叠／意外空档、事件后仍在险、启动前被计为已启动、迟进入前被计入以及状态未知被当0；不通过静默删行消掉问题。对若干实际事件时点，按本模型定义列出谁当时在险、用的是哪一段暴露、谁发生哪种事件，再与工具实际使用的记录／人数／事件数对应。下表是自构造的首次事件输入示意；0／1仅表示记录中尚未／已经启动，并不证明实际持续服药。这里核普通／原因别在险过程，不能直接套作亚分布风险集。

| 构造原事实（天，使用共同的已选原点） | 应能从派生记录读回的内容 |
|---|---|
| A进入0、启动30、首次事件20 | 只有`(0,20]、暴露0、目标事件`；不能因后来启动，把事件前时间划成暴露1。 |
| B进入20、启动40、首次事件70 | `(20,40]、0、无事件`与`(40,70]、1、目标事件`；0—20不计入本分析在险时间。 |

#### 概率调查资料：从适用权重和抽样设计走到分析

本分支用于依据概率调查资料估计其目标人口的均值、比例或有限关联，不要求所有观察数据使用权重，也不把描述问题改成随机干预。先复用06／07的目标量及10的调查说明；只描述已观察样本时明确该范围，不自动承诺总体代表性。

1. **先确定要代表谁，再选权重。**写清目标人口、时点／跨期范围、个人或家庭层级，以及本项结果实际使用的问卷／模块。逐项回原调查分析指南核其权重适用人口、波次、问卷组合、样本来源和非应答调整范围；列名含“最终”“纵向”不够。单期横截面、两期追踪、模块子样本可能需要不同权重，不能按非缺失人数最多或结果最有利选列。模块权重的适用性来自其设计说明，不是临时删掉若干空值便自动产生的新权重。跨期／多周期拼接先按原指南核目标时期、样本补充、标识及权重构造，不能普遍取最后一期、相加或平均。
2. **把已选权重与相应设计一起交给工具。**核本项适用的分层、PSU／必要阶段、方差估计方法及已提供的复制权重；设计字段须与所选权重、发行版和分析基础相配。Taylor线性化与复制法是依设计选择的路线，不能只给普通回归一个权重便称已处理复杂抽样，更不能把调查权重当成复制观察次数的频数权重。采用复制法时按原指南和当前软件核复制列、方法、是否已含主权重、缩放及中心化规则；不把复制列各跑一次后直接当独立样本。单例PSU先查原设计、错误筛行或域内覆盖；有限总体修正也须有对应阶段及抽样依据，不能为消除报错把单例都设为必入样单位，或用权重和猜总体量。
3. **先声明适用分析基础的设计，再取目标域。**保留该权重分析基础所需记录及设计信息，用调查工具的域／子人口功能处理年龄等目标条件，避免先任意删行再假装仍是原设计。提供者规定哪些记录有资格使用某权重，须先核清；零／缺失权重可能表示不属该分析基础、无相应权重或资料错误，不能一律改1。域指示含义不明或缺失也要单独处理，不能默算域外。R的`subset`须作用在调查设计对象上；Stata的相应路线是`svy`的`subpop()`，不是普通筛行。这保留方差计算所需设计信息，不保证所有缺失或选择偏差已解决。

**一个可手核的单期模块示意。**虚构Q指南明确：本项估计某时点人口中18—35岁者的模块指标均值；准备表`q`含适用模块分析基础的8名个体，分属2层、每层2个PSU、每PSU2人，每PSU恰有1人属于年龄域；本例年龄与结局均完整。指南指定正的`w_mod`及Taylor路线，不需另填FPC；PSU编号在各层内重复，因此需要嵌套重标识。域内4人的`y=(2,8,4,10)`、`w_mod=(0.5,1.5,0.5,1.5)`，域外4人的权重各为1，整份构造权重均值为1。已有R及survey时，可按如下调用关系落实，不要求换软件、安装或实际运行此例：

```r
d_all <- survey::svydesign(ids = ~psu, strata = ~stratum,
                          weights = ~w_mod, data = q, nest = TRUE)
d_age <- subset(d_all, age >= 18 & age <= 35)
m <- survey::svymean(~y, design = d_age, na.rm = FALSE)
coef(m)
survey::SE(m)
summary(d_age)
survey::degf(d_age)
```

域内手核分子为30、权重分母为4，均值为7.5，普通样本均值为6；可用来查错权重、错对象或均值分母用错，不能据此手造SE。`nest=TRUE`在本例只处理层内重复PSU编号，不会修复个人重复、错误联表或跨期身份冲突。域外4人不参与该域的均值分子／分母，却仍保留在原设计基础中；不要先把`q`裁成4行再建立一个新设计。

4. **核输出实际用了谁，以及精度从何而来。**分别对账适用基础人数、域人数、该结局实有值数、因协变量等额外缺失减少的人数，以及相应权重分母。权重若为人口扩张权重，须按指南解释其总量；若像本例被缩放均值1，和为4只是当前权重尺度下的分母，不能写成目标人口只有4人。先核设计方差／SE及域内实际PSU、分层覆盖，再核区间或检验使用的自由度和参考分布，不用人数减1通用替代。`degf()`是核查设计的一项依据，不自动等于任意域、回归或检验的最终自由度；复制设计也不能简单用复制列数代替其有效秩和原规则。survey的`confint(svystat)`默认`df=Inf`，不会因先调用`svymean`就自动给所需小自由度t区间；需要这种区间时，按调查指南和该统计量确定适用df并显式传入，不能无核对地复制`degf(d_all)`。域覆盖不足、单例或缺失SE应保留并查因，不填0、不统一切换某个选项使结果出现。

**接回两期追踪问题。**若要估计基线18—35岁者的两期变化，先核追踪权重究竟代表何种基线／持续居住等人口、覆盖哪些波次和问卷及允许哪些响应模式；有正追踪权重不意味着所有需要的题目都有值。先保留权重适用的完整分析基础，按ID核对两期对应并形成每人的变化量或缺失状态，明确基线年龄域指示，再按原设计声明并作域分析；不先删掉基础中题目不完整者来制造“完整”输入。变化量每人一行或重复测量模型各按既定目标处理，不能把两期行当两份独立个体。完整对又因题目缺失缩小时，记录它相对权重覆盖基础额外遗漏了谁，沿A04处理缺失假设与敏感性；不能说“用了纵向权重，所以完整对代表全部基线人口”。权重未知、方差资料不可得或指南与当前组合不相容时，先补具体来源／方法，或只交有依据的有限描述及未定项；不编造全国区间。正确加权也不自动消除全部非应答、测量问题或因果混杂。

### 10.4 文本、档案和推导怎样形成中间分析

**解释性主题。**AI先读片段前后文及材料集，给出贴近当前问题的候选读法。构造片段“网上预约省了排队，但夜班后总赶不上开放时段”可暂记“减少等待”“服务时间与工作错位”，再回其他材料查便利与排除如何同时存在。候选主题可以围绕“便利以符合既定时间为条件”，而不是把访谈题目“使用体验”直接当主题。发现退休者等不同情境时，检查它丰富、限制还是推翻该解释；说明归并、拆分和命名理由。单段不足以证成主题或饱和，示例不冒充真实引语。反思性路线可保留工作代码与分析说明，不因采用此过程强制固定码本、一致率或唯一正确编码。

**分类与计数。**若问题是政策条款采用哪些工具，先选条款还是文档为计数单位，定义“适用／不适用／不确定”和多重编码规则，再用少量适合材料检查歧义。构造例：一条款同时承诺资金与培训，允许两类时可产生两个编码，但仍只有一条款；不能将“编码总数”和“条款总数”的占比混用。修改类目后检查受影响的既有材料，不只给新材料换规则。需要可靠性评估的路线按其设计保留独立编码和分歧，不能把先协调的结果称为独立一致性。现有电子表或编码软件均可，软件查询是否计文档、片段或引用须实际核对。

**档案与过程。**先为当前解释排列必要事件和材料定位，分别注明材料原话、可证实事实、分析重构与缺口。两份报纸都引用同一通告时，支持的是通告传播而非两次独立对证；时间先后不足以证明机制。遇到冲突先查形成时间、作者可见范围、目的及术语，而非删除“不一致值”。交15时保留尚未闭合的因果或事实环节。

**理论与概念。**从要证明的句子展开量词与条件，再列已成立的引理及所缺连接。构造检查：“每个对象存在一个可行解”不推出“存在一个对所有对象都可用的解”；AI应指出交换量词的具体步骤，尝试符合前提的边界例，或说明需要增加何种有效条件。已有证明可按关键步骤独立重推，不强制形式化；概念辨析可用正例、反例及边界例检验定义一致性。符号软件给出的表达式只能按其实际前提使用，缺引理保留缺口，不能补写成结论。

这几条路线复用A13—A16已有来源；本次重读质性Skill的05／08配套，吸收材料到代码、回看与单位计数，舍弃其通用码本、一律互斥、统一Kappa与默认“政策失衡”等简化要求。未验证NVivo／MAXQDA操作，也未找到覆盖全部档案／概念分析的单一专用Skill。

### 10.5 从研究报告形成综合结果

先定位同一研究的多份报告，把研究对象、比较、结局、时点、尺度方向和效应身份对应起来，再按既定规则选择。先提取原值与定位，再处理转换；例如末次均值、变化值、调整后组差与未调整组差不可只因都叫“差”就混用。共享对照或同样本的多个结果须处理其依赖，不能重复算信息量。

若缺离散程度，先查表注、补充和相关报告，辨认所给是SD、均值SE还是组差SE。仅在相应条件成立时转换。构造例：普通未加权、独立观测的组均值，其SE按s/√n计算；若SE为2、对应N为25，可得SD=2×√25=10。若2是调整后组差、聚类或复杂加权估计的SE，不能照此恢复某组SD。由区间恢复SE还须核对区间水平、所用分布、变换尺度与是否对称，不统一除以3.92。确实缺失就说明并评估适用方法与敏感性，不以0填补。

形成共同方向后，再判断能否合并、拟估计共同还是平均效应、依赖与异质性怎样处理。不能合并时，在同一综合结果中按问题／条件并置每研究估计、精度、设计与限制，说明哪些差异有依据、哪些未知；结果若主要是方向，明确其不能回答幅度。软件生成森林图不是合并适用性的证据，缺一个合并值也不妨碍合理综合完成。效应提取与转换依据为[Cochrane第6章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-06)，不把干预综述方法自动推广到全部材料综述；其他综合类型须补读其方法。
