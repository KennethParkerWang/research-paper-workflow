# 独立审稿、修订与研究包交付手册

本阶段连同20修订、21交付核对和22归档，说明如何独立审读稿件、关闭意见并固化已通过的研究包。

## 本阶段怎样组织工作

本阶段的中心问题是：独立读者能否从当前稿件和实际依据理解研究、判断主要主张成立到什么程度，并指出需要关闭的问题。审查不重新替作者选题，不以结果是否正向、篇幅或检查项数量代替科学判断，也不自动要求扩大成另一篇论文。

现行分工以[总流程](../docs/workflow-design.md)和[00共用规则](../00-阶段交接关系/阶段交接关系.md)为准。19新增独立科学判断；20把具体缺陷送回最早受影响工作；21核对交付版本及材料；22固化已通过的本地研究包。已有有效依据直接引用，改变后只复核受影响部分。共用确认、授权、日常验收及临时材料规则不在这里另造。

本页将公开Skill和官方资料转为可按研究类型选择的审查方法；来源和适用边界见末尾。

## 一位独立研究者的完整经历

以下过程是假设推演。一位未参加核心撰写的研究者接到当前稿件，先定位它要回答什么、提出了哪些主要主张、属于什么类型，以及提供了哪些依据。读者先把作者论点复述准确，再作评价；读不到某个补充文件，就说明该判断目前缺材料，而不猜测作者做过什么。

第一轮阅读研究问题、摘要、关键结果和讨论，确认作者实际上声称了什么。随后沿每项核心主张回到方法、证据和上游判断：比较对象一致吗，数值对应同一人群和条件吗，推导的前提在结论中保留了吗，解释有没有越过材料能够支持的范围？读者会发现一些问题只需补说明，一些需要重新分析，少数会让当前主张无法成立。这些类别应分清。

再读图表、公式、引文和必要补充，检查表达是否忠实于已有依据。读者不会因没有统计检验而否定理论或质性工作，也不会把形式完整的报告当作正确设计。未能独立核查的专门证明或模型留有明确范围，必要时由相关能力的独立读者补查。

审查意见写明位置、发现、影响与可行修正。作者或AI逐项判断根因，选择补说明、修正分析、限制主张或提出必要新取证；用户不了解问题时，先解释不同修正对结论和投入的影响。修订完成后，原发现由独立检查关闭，受影响的稿件、图表和结论同步更新。科学审查通过后，才转入交付版本核对与归档；不存在缺陷就直接继续，不为形式制造补验任务。

## A. 建立准确的审查对象

<a id="r01"></a>
### R01 确定当前版本、材料与审查范围

先定位18形成并经[23表达处理](../23-论文去AI化/论文去AI化阶段详细手册.md)的当前稿件、16论证提纲、14／15结果及结论依据、03现行目标期刊和有关指南；本次无需表达修改时复用已有有效稿件，不强制重跑23所有节点。版本不同不能拼成一个不存在的“当前研究”。没有正式选刊时，可以按科学内容作内部审查，但不声称已满足具体刊物要求。

AI应说明当前可读材料和希望解决的审查问题，帮助不知道怎样准备审稿材料的用户引用已有文件，而非要求重新制作一整套附件。正文、补充或原始依据缺失时，指出它阻碍哪项判断；不必为所有非核心材料一律等待。够用程度是能够确认所审对象及关键依据位置。材料本身不可取得且影响中心主张时须先解决，编辑最终判断和真实录用概率不属于本阶段可知事项。

本点给后续各点提供版本前提；版本更新后回看所影响的发现，保留仍适用的其他审查结论。

<a id="r02"></a>
### R02 保留独立判断，说明能力与证据限度

审查者不只读取作者提供的结论摘要，应能直接定位决定性稿件与依据。任务可以按理论、统计、质性或领域材料分工，不要求一个人掌握所有方法。作者自己的自查可作输入，但不自动替代独立判断。

AI向用户解释“没有读到”“目前看不懂某项证明”“有具体冲突”和“已核查成立”的差别；不了解方法的用户不用替审查者提供专业结论。审查者针对超出能力的关键部分说明需要哪种核查，其他可以独立完成的部分继续。只有影响核心判断且无人能核查的缺口才保留为当前未关闭事项。评审一致或代理数量多不能证明主张为真。

本点与R01共同限定每项意见的身份；跨专业补查依据回到对应主张和文件，避免复制完整研究记录。

<a id="r03"></a>
### R03 先忠实复述问题与主要主张

用稿件自己的对象、条件和研究目的概括中心回答，并区分描述、预测、因果、机制、形式命题、概念澄清、情境解释和综合结论。摘要与正文不一致时记录位置，不能挑较弱的一句替作者开脱，也不能自行扩成较强主张再批评。

AI可先给用户一个短的“读者会把这篇文章理解为什么”，解释词语如“导致”“证明”“适用于所有”增加了什么责任。用户不知道表达强度时，用相同结果分别套两种说法说明差别。够用程度是中心主张及其必要前提可逐项追踪；小贡献的论文可以有一个很窄但明确的回答，不必另造宏大故事。本点连接R04、R05及所有适用路线。

<a id="r04"></a>
### R04 区分科学必要性、目标期刊标准和个人偏好

复用03／05已有刊物依据；[24收集的论坛经验](../24-投稿潜规则收集与研判/投稿潜规则阶段详细手册.md)保留其语境和证据身份，不能直接成为审稿门槛。评论要标明是支撑当前主张不可少、目标刊物明确要求、稿件未解释的选择，还是可选扩展。使用更多场景、更复杂模型或某个喜欢的方法，不能仅因审查者偏好变成必须项。

AI应解释为什么一个窄应用贡献仍可能有价值，以及为什么贡献小也不能省掉支撑它的基本证据。用户希望可控投入时，优先比较有科学意义的范围调整和必要修正。PLOS与JMLR官方审稿指南在贡献定位和评判重点上不同，不能把某刊标准推广成所有论文的门槛。

够用程度是每项重要要求有适用理由，重复满足的要求不重复计工作量。规则来源冲突影响判断时先核对现行官方资料；尚无编辑决定不能填成确定结果。本点约束R05—R15的要求尺度。

## B. 顺着主张回到证据

<a id="r05"></a>
### R05 主张、依据和允许范围是否一致

从R03主要主张定位具体结果、证明、材料、图表或文献，再对照对象、条件、方向、量级、时间、比较与不确定性。相同关键词或一个正向结果，不自动支撑全部解释。引用15已经判定的边界，但检查稿件是否准确表达它，而非重新复制一次结论记录。

AI发现“在一个条件下有效”被写成“普遍有效”时，先解释证据能支持的版本；发现不显著被写成“无效”时，说明结果精度是否足以排除有意义差异。具体统计判断回14／15既有依据，不能用换词掩盖证据缺口。够用程度是重要主张均有可定位依据，并无影响理解的夸大；关键支持链断裂须先修正，非核心延伸可以删去、限制或留作未来问题。

<a id="r06"></a>
### R06 问题、设计与实际执行是否仍对应

比较06设计、07计划、13实际取证和当前方法叙述。实际改变样本、对照、指标、步骤或分析时，稿件应描述真实做法并说明重要偏离，不能保留漂亮的原计划当作已执行方法。探索产生的解释不改写成事前预测。

AI通过引用现有记录帮助用户找出变化发生在哪里，解释“技术修复保持同一问题”与“设计已不能回答原问题”的差别。够用程度是读者知道研究实际做了什么，决定性变化的影响已经在14／15处理；不知道某程序是否执行时先问依据，不把“未报告”直接判成“未做”。改变核心目标或实验方案按00返回原位置，本页不新增确认关口。

<a id="r07"></a>
### R07 定量研究审查分析单位、比较与解释

按既定主张定位采样／实验单位和实际比较，检查重复测量、嵌套、配对或共用样本是否在14分析中被正确处理。由结果及模型依据判断不确定性与假设是否足以承载当前结论，不能把运行成功、显著性或拟合优度当成正确性证明。

针对发现写出具体影响，例如同一对象多个测量被当作独立对象，会改变哪项区间或比较；不是笼统要求“做更高级统计”。用户不知道怎样改时，AI先比较澄清单位、重新分析和缩主张的作用及投入，再把方法问题交回06／14。不规定统一样本数、正态检验、校正方法或重复数；正式判断以相关设计和分析的已有依据为准。够用程度是中心定量结论没有未关闭的决定性分析矛盾。

<a id="r08"></a>
### R08 理论、数学与概念研究审查推理本身

针对形式命题，核对定义、假设、量词、引用的引理和关键推理是否支撑所写结论；数值例子可以展示或寻找问题，但不能冒充通用证明。对反例检查它是否满足命题前提。针对概念或规范论证，分清工作定义、经验判断、价值前提与推出的结论，检查替代定义和主要反对理由有没有被公平处理。

AI帮助不熟悉证明的用户解释“目前哪一步没有成立依据，以及它影响整条命题还是一个推论”。优先定位最早缺口，提出补推理、增加必要前提或缩小命题等实际选择；不把复杂形式化作为概念研究通则。够用程度是中心论证可被合适能力的独立读者核查，相关边界在稿件中保留。证明未闭合、关键概念循环或含义漂移须先解；广泛推广和可选应用可作为后续问题。

<a id="r09"></a>
### R09 质性与情境解释审查方法一致性和材料连接

核对所声称的研究取向、材料生成、分析做法和解释目标是否相互一致。读者从主要解释追到具体材料和必要语境，检查不利材料怎样处理、研究者的解释作用是否清楚；引语数量或软件名字不能代替分析。

AI向用户解释不同质性取向可能需要不同质量依据。反思性主题分析不自动套编码者一致性或固定饱和次数；使用明确编码规则作分类统计的研究则需说明相应程序。若存在方法混用，先定位含义冲突，而不是简单要求增加第二位编码者。够用程度是重要解释有可理解依据、研究者如何形成它可追踪、范围与语境相称；材料含义或方法身份的决定性矛盾先解，不能判定全部社会情境已被覆盖。本点的方法取舍参考S05及M03的限定阅读。

<a id="r10"></a>
### R10 档案、历史与证据综合审查来源和选择

档案路线沿关键陈述回到精确文献或记录位置，分清当时的表述、后来的回忆和对事件的推断，检查形成背景、独立来源与保存／检索缺口。未找到材料不直接证明事件没有发生。二手转引注明经由何处，不伪称亲自查阅原件。

证据综合路线检查拟综合的问题、纳入范围、实际选择、重复或重叠材料、处理差异的方法，以及结论是否保留证据限制。无统计合并可以是合理结果，不能为形式而要求元分析。方法细节和来源质量沿14／15记录核查，必要的新文献判断回相应依据位置。

用户不知道怎样定位旧资料时，AI先从既有索引和出版者／馆藏记录复原出处，说明可检索的位置和目前缺失。够用程度是关键来源可核查、决定性选择及来源限制能解释；原始材料真实性或综合对象不明须先处理，无法取得的材料限制不能用想象补齐。

<a id="r11"></a>
### R11 检查必要复现条件，但不自动重跑

先看所需输入、方法、实现、参数及版本依据能否让合适读者理解工作。根据实际研究检查计算过程、材料步骤、转写／解释或推导的相应可追踪性；不同路线不共同要求一个容器、锁文件或公开数据仓库。

AI将缺失精确说明为“哪个现有结果无法据此核查”，优先查已有资料，不因为标题叫复现就运行真实任务。确需重新计算或取证时，由00判断既有方案范围和相关确认；只读审查不冒充已重现结果。访问受限不自动无效，应说明具体访问途径和可判断范围。够用程度是核心证据的形成过程和边界足以供合适读者核查；来源不可解释、关键计算／转写／推导或操作步骤缺失而阻碍核心判断，以及实际目标刊物必要报告项未满足，均需说明影响并作相应修正。只补与当前判断有关的缺口，不自动要求全量重跑。

## C. 检查表达并形成可解决的意见

<a id="r12"></a>
### R12 图、表、公式与补充是否忠实于证据

直接读取实际产物，核对图表中对象、分母、单位、条件、轴尺度和不确定性与正文及分析一致；公式检查符号定义、前提和适用域。引语或图片不能只凭低清预览猜测处理过程，应回已有原件或说明。不因图多、漂亮或模板整齐认定论证充分。

AI说明发现会怎样误导读者：换尺度可能夸大差异，错分母会改变含义，漏条件会扩大命题。用户不知道怎样改图时，先解释要表达的判断，再用18已有制作指导修正。够用程度是决定性展示能够独立理解并与依据相符；只影响排版的小问题与改变科学含义的问题分别处理。本点连接18及R17的下游同步。

<a id="r13"></a>
### R13 引文支持什么，引用身份是否准确

优先核对影响新颖性、方法或核心论证的文献主张，打开引用的原文及相关段落；不能用题名、DOI存在或参考文献格式正确证明它支持一句话。前人的贡献、反向结果、修订和版本区别按实际影响处理，不做与当前论证无关的全库检查。

AI帮助用户从出版者页面和已有文献库定位具体版本与页码，区分直接阅读和经另一来源转引。Zotero Duplicate Items可发现待核重复，版本不同不直接合并；NARA指南用于说明定位档案所需层级，按实际记录和引用规范裁剪。够用程度是关键文献身份和支持范围明确；决定性误引、遗漏近邻或已失效来源先解，非关键格式细节交18／21处理。

<a id="r14"></a>
### R14 对真实问题提出可定位、可关闭的意见

每项重要意见交代位置、实际发现、依据、影响和可行处理。用“当前正文没有报告如何处理同一对象的重复测量，因而无法判断这一区间的依据”代替“统计不严谨”；进一步依据能证明错误时再写成错误。意见可简短，不必强制另建五列记录。

AI向用户解释这项发现改变哪种结论，以及澄清、修正或补证分别能解决什么。决定性未知标为需要哪些材料才能判断，不能空泛要求“全面加强”。外部Skill的泛化缺陷目录仅供发现相关问题，不以可能存在的风险生成意见。够用程度是作者知道要解决什么，独立读者也知道用什么判断关闭；无法定位和无科学影响的偏好不升级为阻断项。

<a id="r15"></a>
### R15 判断影响及最小充分修正

按对中心主张的作用区分：当前结论不能成立、已有依据可能成立但缺说明、表达／交付不一致、合理局限和可选扩展。同一发现可能影响多个位置，以根因组织，避免逐段重复计成新问题。

AI可以给出有依据的修正选择：引用现成证据、补分析说明、改分析、限制结论、返回设计或提出新的必要取证。用户不知道怎样取舍时先说明每条路保留什么结论、需要什么投入，不把用户追求小贡献改成大规模验证。不能修补时诚实缩主张或按停止条件结束；不得通过删掉不利结果保持原强结论。够用程度是重要问题均有具体处理判断及理由，只有保留中心主张确需的新工作才要求补做。

## D. 20修订、复审与受影响成果

<a id="r16"></a>
### R16 定位最早根因，保留未受影响依据

数据错误回来源，实现错误回11／12，分析问题回14，结论问题回15，叙事或表述回16／18。设计或必要取证失效则回06／07，并按00判断实验启动确认。只有改变核心问题、假说、期刊才返回对应前三关口；改字数或图题不自动重开全流程。

AI使用现有发现与依赖帮助用户理解“这个修正会使哪些结果暂时不能用”。不知道根因时先做最能区分来源、处理、分析或表述的有限核查，不同时重做所有阶段。够用程度是修改位置、影响范围与有效保留部分清楚；根因未定位且直接影响中心结果的未知须先处理。

<a id="r17"></a>
### R17 修订说明与稿件同步，避免只改意见回复

将问题与实际修改、对应依据及新位置关联；不采纳的要求说明科学理由及仍允许的主张。内部修订不必写投稿格式回信，一份现有问题记录即可。将回复留在稿件之外而正文不改，不能关闭需要改变论文的问题。

数值、对象、条件或结论变化后，沿相应依赖检查摘要、正文、图表、补充和提纲；旧结果保留身份，不与新值并列成两套当前事实。AI先解释改变的实际含义，再帮助用户选择最小受影响范围。够用程度是论文所说与修订后的当前依据一致，修改证据可定位；具体回应风格依真实投稿情境决定，本轮不对外回复。

<a id="r18"></a>
### R18 独立关闭问题，冲突靠证据解决

独立发现应经独立复查：检查修正是否真正消除了原影响、有无因修改产生的新问题。只在作者说“已改”或在清单上勾选不足；原发现不成立时也可以据新依据说明撤回。复核同一事实时引用现有记录，不增加一套状态账本。

评审意见冲突时比较其适用标准、材料、逻辑和能力限度，不以多数票判科学真假。AI向用户清楚呈现双方如何使用证据；只有需要用户改变既定科学目标或授权范围的取舍才返回相应确认。够用程度是阻碍当前主张的重要问题已关闭或主张已合理调整，合理局限仍可存在。科学或稿件修改后回19；仅交付整理问题由21检查。

## E. 21交付核对与22归档

<a id="r19"></a>
### R19 核对当前研究包，不重新做一遍科学审稿

从已通过19的版本核对稿件、必要补充、证据索引、可理解的材料或运行说明是否指向同一有效版本，必要问题是否关闭，文件是否能读取。按实际研究选择内容，不要求无代码路线交付代码，不为格式创建空目录。

AI帮助用户引用已有索引，解释当前交付物及受限材料取得方式。链接存在只说明文件能定位，不说明科学内容正确；科学依据复用19结果。文件命名、补齐已经审过的版本文件和打包等仅交付整理问题可以在21关闭；字数核对也可在21，但为满足字数而删改正文、改动图表或其他稿件内容，须返回18等相应位置并由19复查受影响部分。够用程度是另一位合适读者能够定位并理解这份已审查研究包，关键依赖不会因缺失而断开。

<a id="r20"></a>
### R20 固化版本、保留证据，后续变化有明确入口

记录被交付版本、现行文件位置、所用依赖和审查依据，在已有索引说明哪里是当前正式成果。固化可以采用本地受控版本或明确的归档副本，具体方式随现有项目而定，不强制Git、云服务或额外多份导出。无法再取得的原始依据和失败证据按00保护。

AI向用户说明“归档意味着能回到这版”，以及未来修改怎样另行标明而不覆盖被引用依据。临时材料处理沿00，仅有明确可处理对象才讨论；本页不授权删除。需要后来公开发布时，可研究版本化资料库的具体功能，例如Zenodo官方说明区分更新文件的新版本和元数据编辑；这里不创建账户或上传。够用程度是归档内容可读、关键引用有明确指向、后续改动不会被误认为原审查版本；没有新增内容不再另造总结。

## 从实际稿件到可关闭意见与可继续使用的研究包

### 接到一篇PDF、一段推导或一份意见时怎样开始

先读取用户本次指定的对象，再说明可负责的范围：只查统计、只读逻辑、检查图表，还是评审整份稿件。只拿到PDF也可审读它公开呈现的主张、方法、结果和内部一致性，不要求先建立01—18全套记录；但不能声称已核查未提供的原始数据、实现或取证。缺失材料只有影响当前判断时才具体提出，不把所有可能附件都列成前置作业。

用户只要求改已有审稿意见时，先忠实辨认原问题及理由，改成可定位、可执行的表达；不能替未读稿件新增事实指控。用户只要求回复外审意见时，进入下文修订路线，不重新写一篇完整评审；发表决定和录用概率不能由AI承诺。

### 独立审读怎样沿证据走下去

第一遍读标题、摘要、中心问题、关键结果与讨论，形成中性的主要主张和范围，再读实际方法及必要背景。目的在于准确理解作者，不在此时凭印象决定接受或拒绝。若只接受某一专门核查，仍读足以理解该问题的上下文，不必全稿逐句审。

第二遍选择决定中心答案的连接，回到实际证据：对象／比较是否相同、方法是否回答该问题、结果是否支持所写幅度与条件。理论稿沿关键引理和量词检查；质性稿将主要解释与原片段／上下文相连；档案稿核来源身份和转述；综合稿核研究单位、选择及可比性。已有上游有效判断可复用，但评审者要读足以形成独立意见的依据，不能只接受作者摘要。

第三遍查看实际图表、公式、关键引文与补充：例如核对一处主要估计从结果表到摘要是否变了尺度，某图的对象数与方法是否相符，主命题是否漏条件，引用的原文是否真的支持比较。发现重复性问题再扩大到同类位置；关键成果都须得到适当核查，不能以抽到几个数一致就宣布整稿正确。只有图像预览无法看清的地方，报告读不清并定位所需源，不猜测像素含义。

对确实需要重算、重推或复验的发现，先说清它验证哪个结果、需要哪些已存在输入及最小范围，再按00和既有授权处理。原计划与13确认仍有效的范围内工作按相应规则续接；没有进行实际操作，就只能写“需要核查”，不能称已复现。审读不自动跑所有代码，也不因出现“稳健性”字样要求增加全部检验。

完成意见前，回看最强相关近邻和报告规范中真正影响判断的条目，区分科学缺口与期刊必要项；不因用户只追求一项窄贡献而抬高为全面突破。来源与标准不足时缩小审查结论或补适合能力的核查，不用多代理投票代替证据。

### 四类意见怎样写，怎样判断关闭

下面均为构造情形，示范意见和修订依据，不是本流程发现了某篇真实论文错误。

| 发现身份 | 可负责的意见与最小处理 | 关闭依据 |
|---|---|---|
| 有依据的实际错误：同一对象的多次观测被当独立样本，输出与实现已能核实 | 指出具体比较及错误依赖，说明影响区间／精度；回14等相应位置改分析，不能只改措辞 | 独立读者核对实际分析修正、单位和受影响结果，并检查摘要、图表及15结论同步 |
| 报告不足：方法没有说明如何处理重复测量，尚不能判断是否做错 | 写“当前未报告，无法判断该区间依据”，请定位已有分析说明；不直接断言作者用了错误方法 | 现有依据清楚支持正确处理，补入适当说明；若暴露实际错误，再转为前一类处理 |
| 合理局限：证据只覆盖一个条件，作者也未声称全面推广 | 指明限制对读者的作用，核对适用范围足够清楚；不能把新增所有条件当必做 | 核心主张及读者预期与现有范围相称，重要限制没有被隐去；不需凭空新实验 |
| 可选扩展：另一机制或新数据集可能有趣，但当前窄主张不依赖 | 清楚标为可选，并解释其研究价值；不得与阻碍中心判断的问题混为一谈 | 说明其不阻断当前成果即可，不要求为“关闭”完成新研究 |

意见写在现有问题记录或评审稿中，实际位置、证据和影响足够清楚即可，不新增通用五列表。一个根因影响多个段落时列受影响位置，避免重复计问题。原发现被新依据否定，可以撤回并说明；作者说“已改”、改了回复而稿件不变，均不足以关闭实际问题。

### 不同审查意见冲突时怎么处理

先把双方的实际命题与依据并置，问它们是否针对同一目标、版本和标准。构造例：一位要求加入机制实验，另一位认为限定应用比较足够。若当前稿件承诺机制，前者可能指出必要证据；若只承诺场景内改善且证据相称，机制可能是扩展，不能按“更严格就更科学”处理。若目标期刊有实际必要要求，回查03／05，不以个人偏好代替。

真正事实冲突回原数据、文献或推导；概念含义冲突先明确使用定义；能力不足则找相关能力的独立核查。需要改变已确认科学目标或实质方案时才返回已有确认关口。仅修正不成立的评审要求无需用户替双方裁决科学事实。

### 20怎样把意见变成实际修订

先把一条长意见拆成真正不同的问题，复用同一根因的内容。逐项决定：采纳并修正文稿／依据，部分采纳并说明保留范围，或有科学理由不采纳。AI先给用户可理解的推荐和代价，普通编辑或既有范围内修正继续完成；新增取证沿00处理，不因评审要求就自动获准实验。

修订先落到最早受影响来源，再更新结论、提纲、正文、摘要、图表、公式和补充中的依赖；不必机械遍历无关成果。回复中的数值与新稿引用同一有效输出。重新阅读原意见，确认实际改动解决其影响、有无新问题，再由独立者复查关闭。

真实外审回复若属于当前请求，可在本地准备：先直接回答该点处理了什么，再解释依据、重要修改内容及修订稿定位；不采纳时准确复述请求，说明为何现目标／证据不支持这项扩展，并明确相应限制。旧稿行号与修订稿行号分清，长改动给精确节／图位置，不复制一整篇论文到回复。多问题不能只回复其中较容易的一项。内部修订仍可直接用现有问题记录，无需强制回信。

构造回复思路：“已将普遍适用的表达缩为已评价条件，修改在修订稿讨论相应节；现有证据未覆盖其他条件，因此不再保留原推广句。”只有实际完成这些改动后才能写“已”；尚未执行的新实验不能写成承诺兑现。学习来源为[Noble 2017回应审稿十规则](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005730)的直接回应、逐点覆盖和定位；不照搬无条件归责、为满足评审默认追加实验等建议。这里只研究本地写法，不发送任何回复。

### 21／22怎样交付一个以后仍能读懂的版本

1. **先对应当前已审版本。**从现有审查结论定位稿件源、阅读版、必要图表源／成品、补充和关键依据。时间较新不等于已审，旧图配新稿也不构成完整版本。发现科学或稿件内容变化回19受影响复审，纯索引／命名整理留21。
2. **按使用需要选材料。**没有代码就不建代码目录；原始材料受限可保留明确位置、取得方式与当前可判断范围。正式成果、必要失败证据和复现所需输入按00保护，临时缓存不因能打包就进入交付。已有材料直接引用，不复制整套数据和历史聊天。
3. **核对阅读与接续。**从当前索引打开稿件，沿一项核心结果找到对应图／表／推导、必要附件及依据；改名或移动后的相对引用须重新核对。检查源与阅读版内容、编号和当前版本对应；计算路线复用已有运行说明，材料／理论路线保留相应定位与步骤，不强制所有路线提供运行命令。
4. **采用能回到该版的归档方式。**已有可靠版本管理就引用其对应版本及审查依据；只有可覆盖的“最新文件”而无法恢复旧版时，选择确有必要的归档副本或现有受控版本办法，不能只写个日期便声称冻结。归档后的引用要能回到被审内容，不能只指向后来会被覆盖的位置。
5. **说明后续变化入口。**在既有索引简要标明正式版本、依赖／取得方式、审查依据和仍允许存在的限制；未来修改另标版本，按影响回审，不覆盖原引用事实。没有新增信息就不再生成总结、导出套件或新账本。

充分程度是合适读者无需原对话也能知道交付是什么、它为何有效、从哪里核查与怎样继续。打开几份文件不证明所有依赖可复现；缺少关键来源须说明影响并处理。
