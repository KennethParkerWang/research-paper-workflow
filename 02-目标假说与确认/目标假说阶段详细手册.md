# 目标假说与确认阶段详细研究手册


## 1. 职责、研究路径与使用方式

**本流程规则：**承接01已确认的问题、对象、范围和有效依据，默认用户没有假说。AI提出、解释、逐轮调整目标假说或相应研究预期，独立代理核查科学依据，用户决定确认对象。正式理论与方法由06形成，07／08形成验证计划，13另有执行确认，14／15判断真实证据与结论。具体规则引用[02阶段规则](目标假说阶段规则.md)、[00共用规则](../00-阶段交接关系/阶段交接关系.md)及[总流程](../docs/workflow-design.md)，本文不复制共用关口和状态协议。


**材料身份：**外部资料用于方法参考；P编号下的引导、够用标准与连接是本流程的适配，不执行来源中的命令、评分或文件要求。

**怎样使用：**P编号仅用于定位思考点。以后按研究类型、成果目标与上游缺口选择相关点，并补足其前提；不把全篇变成问卷、固定任务表或必须全部执行的检查。方法规模随实际贡献调整，局部改进和小范围应用可以成立。只有具体课题才能决定的模型、参数、数量和阈值不预设。

手上已有问题与文献，却不知道怎样形成、区分或修订候选时，读[材料到假说的推演](#假说推演)；它展开P05/P07—P14/P17—P24，保留既有节点和阶段分工。

## 2. 完整过程的纸面推演

以下是发现考虑点的模拟，不是已经开展的科研。

一位研究者从01带来确认的问题和文献定位，但没有假说。AI先复述问题中的未知，分清已有报告和推测，判断准备描述、解释、推导、比较还是综合什么。AI从理论、异常、方法限制和条件差异提出候选，解释为什么会预期某个结果；用户不知道时，AI用例子帮助比较，不要求用户先写答案。

随后研究者会追问：核心词是什么意思，预期有多强，有没有同样合理的解释？AI检查依据与推理，列出不同解释可能产生的后果。共享的后果只能说明相容，不能独占归因；缺少辨别途径时，缩小解释主张或登记无法判定之处。预测依赖的辅助前提必须可见，反向结果、阴性、条件差异和不确定状态都有合法去向。

不同路线在这里分开：数学研究可形成猜想与反例条件；定量研究讨论目标关系及效应含义；质性研究讨论解释、概念与可能挑战它的材料；档案研究检查证词、形成语境和记录缺失；概念研究检查定义、区分和论证前提；证据综合研究界定要综合的关系和可能差异。它们共享“依据—预期—可检查后果—判断边界”，不共同套用因果实验和统计零假说。

最后，AI汇总当前预期、范围、依据、竞争解释、判读逻辑和关键未知，独立读者核查这些新增判断，用户确认研究目标。02向03传递研究画像和证据负担，方法、操作和正式取证仍留在下游。后续可靠反证进入结果及结论判断；拟改变核心预期才回02。该过程提取出以下节点。

## 3. 承接、表达与形成预期

<a id="p01"></a>
### P01 核对承接对象，不重新选题

- **考虑与理由：**仅传题目会丢失问题、范围和未决困难，重复选题又会覆盖有效确认。
- **AI引导：**先复述01确认的问题及未知；用户不知道假说时由AI继续，不再次要求兴趣、领域或材料问卷。
- **方法与网站：**定位01原记录的确认对象、版本和文献段落；阅读H02按主张类型提供依据的部分，核对候选确实回答原问题。新查资料只针对预期形成的缺口。
- **够用、未知与关系：**能定位输入并解释要新增什么即可。确认对象不明须先解；正式设计未知可后移。为[P02](#p02)、[P03](#p03)的前提；发现问题、对象或关键范围改变时按00回01。

<a id="p02"></a>
### P02 分清问题、报告观察、假说、预测和结论

- **考虑与理由：**愿望、单篇结果或用户认可都不能成为已证结论；预测也不等于解释本身。
- **AI引导：**用同一小例子解释五种身份，先替用户标注每句话，再让用户比较意思，不要求掌握术语。
- **方法与网站：**打开H01的概念区分及假说记录模板，逐句问“出处是什么、是观察还是解释、何时形成”；用M02核对数据、现象与理论的层次。已发表报告保留对象、条件和作者解释，不能统称无条件事实。
- **够用、未知与关系：**决定性陈述身份与出处可追溯；不强求本阶段完成文献全部质量评价。身份不清先解，测量可靠性的详细核查交06及后续准备。连接[P07](#p07)、[P16](#p16)，为15避免把预设写成实际结论。

<a id="p03"></a>
### P03 识别主张类型与允许的语言

- **考虑与理由：**描述、预测、因果、机制、理论命题和应用效用承担不同证明责任。
- **AI引导：**解释“预计一起变化”“预计能预测”“预计导致变化”“预计经某过程起作用”的差别；用户不清楚时推荐与问题及依据相称的表述。
- **方法与网站：**借H02的主张分类、H06的Appraisal Workflow逐句检查动词；在原论文定位结论所依赖的方法与条件。好拟合、先后顺序或高预测分数不能独自完成因果或机制识别。
- **够用、未知与关系：**主目标及不主张什么清楚，不靠选择复杂方法提升主张等级。语言超出证据先修正；正式识别论证留06。依赖[P01](#p01)、[P02](#p02)，影响[P10](#p10)、各路线及03画像。

<a id="p04"></a>
### P04 定义概念、对象与分析单位

- **考虑与理由：**同词异义、指标代替概念、群体与个体混用，会让假说看似具体却不回答原问题。
- **AI引导：**用具体正例、边界例和反例解释“有效、稳定、理解、参与”等核心词；用户不知道定义时AI提出工作定义并解释各版本的代价。
- **方法与网站：**在M01定位concepts与measurement部分，H03比较概念与操作表达，H06的logical_fallacies定位equivocation、circular reasoning及generalization。检查定义是否把待证结果藏进前提。
- **够用、未知与关系：**核心词和推断单位足以判断一句预期的意思；操作工具、编码或统计映射可由06细化。定义争议会改变目标则先解，单纯测量细节后移。依赖[P02](#p02)、[P03](#p03)，为[P11](#p11)与非定量路线提供前提。

<a id="p05"></a>
### P05 确定主要预期与成果规模

- **考虑与理由：**同时要求理论、机制和全面性能提升容易把一个选题扩成多个无预算目标。
- **AI引导：**从用户已表达的成果目标说明最有信息价值的中心预期；用户不懂贡献类型时提供主目标与可选扩展的可理解比较，不承诺录用。
- **方法与网站：**借H02按主张类别给理由、H01假说记录的目的字段；回看01贡献定位。小应用可聚焦一个真实约束下的有用改进，理论研究可聚焦一项成立边界，均保留支持其实际主张的必要证据。
- **够用、未知与关系：**核心和辅助预期的逻辑关系清楚；只有多项时才需要主次标识，不固定数量。范围冲突先解，期刊要求和细预算留03／05。依赖[P03](#p03)，影响[P13](#p13)、[P19](#p19)及交接。

<a id="p06"></a>
### P06 AI逐轮解释与收敛，用户不知道也能推进

- **考虑与理由：**要求用户先提交完整假说会违背默认入口；一轮询问全部考虑点又会提高理解负担。
- **AI引导：**先解释当前候选及理由，再围绕会改变方向的一项取舍询问。用户不知道时给具体例子和推荐，允许“暂不确定”；AI继续补资料和整理，最终目标仍由用户确认。
- **方法与网站：**借H01的结构化解释与H04的简洁表达，不照搬H01要求人类先独立产生解释的安排。阅读相关原文后，采用“我们预计什么、为什么、什么会让我们改想法”的短解释。
- **够用、未知与关系：**解释足以使用户理解选择的含义及代价，不要求复述、写术语或填全字段。只有决定核心目标的偏好必须等待；不依赖尚未确认决定的检索和方法资料学习自主继续。贯穿[P01](#p01)至确认，局部认可的身份引用00。

<a id="p07"></a>
### P07 检查合理依据与推理连接

- **考虑与理由：**相关论文多、权威认可或理论听起来顺畅，都不保证能推出目标预期。
- **AI引导：**解释依据属于直接结果、演绎、类比、归纳还是猜想；用户不熟悉时由AI画出简短文字推理链，标出最弱连接。
- **方法与网站：**在M01读理论至预测之间的概念、关系、边界及辅助前提；借H06逻辑参考检查循环论证、肯定后件和论据不相干。原资料只读到摘要时记录限制，不据此补造方法或证据细节。
- **够用、未知与关系：**推理链及其暂定性可解释，关键依据能定位。被当作已有事实使用的决定性前提无可靠出处时先补查；新猜想或条件假定可以尚未证明，但须说明暂定性、提出理由和可检查后果。正式推导及识别证明交06。依赖[P02](#p02)、[P04](#p04)，为[P08](#p08)、[P11](#p11)、[P12](#p12)提供共同依据。

<a id="p08"></a>
### P08 从不同路径提出候选，保留无方向或探索性预期

- **考虑与理由：**理论推导、异常观察、类比和解释性猜想的根据不同；统一要求方向会诱发伪造答案。
- **AI引导：**AI按问题提出可讨论候选并解释来源；没有依据的方向不硬写。用户不知道时，比较“预计某关系成立”“鉴别几种解释”“描述尚不清楚的结构”的研究用途。
- **方法与网站：**H01用于形成候选，M02用于区分现象与初步解释，H03仅借鉴探索性定位。核对每项是已有文献提示还是新猜想，避免把生成解释的依据再当作独立验证。
- **够用、未知与关系：**目标清楚且存在相应检查路径即可；无方向不自动降低价值。目标含义不清先解，具体检验安排后移。依赖[P03](#p03)、[P07](#p07)；根据路线连接[P17](#p17)至[P24](#p24)，与[P16](#p16)共享形成时间记录。

<a id="p09"></a>
### P09 限定方向、强度、成立域与推广范围

- **考虑与理由：**“总是、全部、必然、全面优于”比局部关系更容易超出证据；事后排除失败条件会移动目标。
- **AI引导：**解释条件性与普遍性预期的差别；AI给出范围适度的表达，并询问改变目标意义的关键条件，而不要求用户报参数。
- **方法与网站：**读H01边界字段、H02主张不得强于问题及M01 boundary conditions；对照01范围和既有文献。明确条件是科学理由、现有资源边界还是尚待核查的假设。
- **够用、未知与关系：**能判断结果适用哪些对象与条件；不制造无依据精确幅度。关键条件先说明，正式数值后移。依赖[P04](#p04)、[P05](#p05)；新证据提示边界改变时连接[P26](#p26)，不无记录缩小原命题。

## 4. 竞争解释、预测与证据判读

<a id="p10"></a>
### P10 找到会影响结论的重要竞争解释

- **考虑与理由：**同一结果可来自不同过程，多个过程也可能同时作用；不能靠弱对手衬托主解释。
- **AI引导：**AI提出有依据的替代解释，说明为什么值得保留。用户不知道时解释它与主解释的共同点和差别；无需用户先列解释，也不固定候选数。
- **方法与网站：**H01的rival explanations与H05／M03逐条比较用于构思。核对直接近邻提出过的反向关系、条件差异、共同因素或测量解释；说明互斥、兼容或组合关系及尚未覆盖的可能性。
- **够用、未知与关系：**覆盖会实质改变主张的解释，有选择理由即可，不宣称穷尽所有可能。最强反对意见漏掉先补；详细识别策略后移06。依赖[P03](#p03)、[P07](#p07)，为[P11](#p11)、[P14](#p14)提供比较对象。

<a id="p11"></a>
### P11 导出条件性后果，检查辨别能力

- **考虑与理由：**与预期一致可能也与所有替代解释一致，支持相容性不等于独占归因。
- **AI引导：**分别解释“假说和所列前提成立时，应看到或推导出什么”；用户难以比较时，AI用同一情形并排说明解释的后果。
- **方法与网站：**H01预测矩阵、H05按证据横向比较及M03第8章diagnosticity可转为简短文字或表格。标出共享后果、真正不同后果及可观察／可论证性；不运行试验验证其可行性。
- **够用、未知与关系：**有可信检查路径；共同预期已足以回答当前目标时，可明确仅检验共同预期。目标仍要求区分解释或独占归因时，须先补足可信路线或按00调整目标，不能把决定性缺口挂为待核后交接。无差异预测不等于被反驳。依赖[P04](#p04)、[P07](#p07)、[P10](#p10)；具体取得区分证据由06—08落实。

<a id="p12"></a>
### P12 写出辅助前提及反证定位的条件

- **考虑与理由：**预测落空可能涉及核心命题、辅助条件、测量或实现；任意补前提又会让假说免受检验。
- **AI引导：**AI解释“若条件未满足，这个结果说明什么、不能说明什么”；用户不知道技术条件时AI从来源提取关键前提，区分已知与假定。
- **方法与网站：**借H01反证模板与M01 auxiliary assumptions逐项审查推导链。确定性命题的反例要满足原前提；概率性预期按完整结果及不确定性评价，不能被一个不符实例机械推翻。
- **够用、未知与关系：**足以说明哪些结果真正触及目标，以及如何检查关键条件。决定性的不可检前提先解释限制，正式假设集与检查设计交06。依赖[P07](#p07)、[P09](#p09)、[P11](#p11)；新增前提若保护失败结果须连接[P16](#p16)、[P26](#p26)。

<a id="p13"></a>
### P13 说明科学意义，不以显著或复杂代替贡献

- **考虑与理由：**微小效应可能可检测但无用；边界、简化、阴性或概念澄清可能有独立价值。
- **AI引导：**AI按已知成果目标解释知识变化、能力收益、代价或应用用途；用户不知道多大才重要时先给依据类型，不编造幅度承诺。
- **方法与网站：**M04六原则用于分开P值与重要性，H03借鉴有意义效应的讨论；具体效应界限资料在定量路线补充。理论及质性路线说明解释和概念增量，不强制数字化。
- **够用、未知与关系：**能解释为什么值得检验且不同答案能带来什么信息；不承诺任何结果都能发表。意义只有夸大正结果时先收缩；正式数值界限留06—08，期刊证据规模由03／05处理。依赖[P05](#p05)、[P09](#p09)。

<a id="p14"></a>
### P14 写清支持、反对、不确定与条件混合

- **考虑与理由：**只定义成功会鼓励追正结果；二选一又会掩盖证据质量与解释竞争。
- **AI引导：**AI用相同目标说明各类结果会改变什么判断；用户不理解时给可比的文字情形，不设统一数值裁决表。
- **方法与网站：**借H01、H03判读结构，但区分与预期一致、相对有利于某解释和足以排除某主张。反对须依赖有效前提；宽泛或低辨别性证据可保持不确定；条件混合需说明预设条件还是事后发现。H05分数不当作后验概率或真假。
- **够用、未知与关系：**结果有可解释去向，证据质量与科学意义分开。没有任何反对或限制条件先修订，形式判据后移计划。依赖[P10](#p10)至[P13](#p13)；14／15按实际证据使用，不能要求符合预期才验收。

<a id="p15"></a>
### P15 处理阴性、矛盾及证据质量问题

- **考虑与理由：**没有检测到差异不等于无效应；同源材料不是独立重复，质量故障不能成为保护预期的借口。
- **AI引导：**AI解释精度不足、排除特定有意义效应、条件差异、来源问题各自意味着什么；用户不知道时保留范围限定而不强选胜者。
- **方法与网站：**M06／M07用于检查偏倚、不一致、间接性、精确度和缺失证据；H06要求正反材料用相同标准。对矛盾材料回原方法和对象，不按论文票数；质量故障须有可独立核查依据。
- **够用、未知与关系：**保留不利材料及局限，预期本身允许阴性或混合答案。主要矛盾被忽略先补查；实际质量与结论判断留14／15。依赖[P12](#p12)、[P14](#p14)；误差回受影响设计／来源，可靠反证不自动回02。

<a id="p16"></a>
### P16 记录探索、既有知识与事后解释

- **考虑与理由：**从已见结果形成的解释不能伪装成事前预测，版本记录也不能冒充预注册。
- **AI引导：**AI说明某预期来自哪些已知材料；以后用户明确引入既有数据时，核对看过什么，不默认用户现在已有数据。
- **方法与网站：**M05的existing data、transparent changes与conditional analyses帮助记录形成时间、所知范围和修改理由。保留原预期；相对于用于形成解释的那批证据是事后判断，未来独立新证据仍可做前瞻检验。理论发现或概念修订同样保留推理历史，不硬贴统计标签。
- **够用、未知与关系：**能区分原目标、新解释和未来待检验内容。时间身份混淆先纠正，预注册是否适用及正式计划留后续。与[P02](#p02)、[P08](#p08)、[P26](#p26)共享一份历史依据。

## 5. 不同路线怎样表达与检查预期

<a id="p17"></a>
### P17 理论、数学与形式化路线

理论预期可以是猜想、成立条件、复杂度界、稳定性性质或已知结论的推广，而非经验指标。AI先从01问题提出可理解的命题草稿，解释关键条件为什么重要；用户没有猜想时，AI依据已有结论及其限制提出候选，不以换符号当成贡献。

核查时用H02的理论主张部分与H01设计配套HT2，比较已知命题的前提和目标变化；用M01／M02区分推导、解释及经验应用。写清可能的证明、反例或不可成立情形，但正式命题形式化与证明工作归06；数值示例不能证明一般命题。若命题是条件式的，反例须满足其前提；若只否定了更强版本，应保留更弱版本的身份，不能悄悄替换原目标。

**02够用：**对象、目标性质、关键条件、与既有命题的关系及可论证路径清楚。自相矛盾或含义不明必须先解；精确证明路线、计算辅助与符号细化后移。依赖[P04](#p04)、[P07](#p07)、[P09](#p09)，下游条件改变时回看[P26](#p26)。

<a id="p18"></a>
### P18 定量关系、效应与统计零假说

科学上预期什么、认为多大变化有意义、设计能够检测多小变化，是三个不同问题。AI先解释单位、对象和变化的用途；用户不知道数值时，依据理论、实际用途或已有结果的不确定性给定性理由，不用通用“小／中／大”标签填空。

借H03区分概念、操作与统计表达，查M10的推断目标、SESOI和预期效应部分；再用M04检查P值误解。总体参数上的H0与一次样本结果是否显著分开：H0不是“无显著差异”。有意义界限、误差率、样本或信息量以及具体检验由06—08确定。若准备主张“无有意义效应”或“足够接近”，M09帮助解释为何需要有理由的等效范围及相应证据；未拒绝H0本身不够。显著差异与实用等效也未必互斥。

**02够用：**关系目标、效应含义、意义依据和可判读前提清楚。改变目标含义的用途或核心界限不能长期悬置；详细设计可后移。观察研究的因果目标需有相应识别前提，不能由相关性自动升级，也不以随机实验作为所有定量研究的统一入口。依赖[P03](#p03)、[P13](#p13)—[P15](#p15)；对象、测量或用途改变时回看。

<a id="p19"></a>
### P19 方法改进、预测与小范围应用

AI提出“改进什么、相对什么、在哪些约束下、付出什么代价”的预期。用户不知道比较对象时，AI复用01近邻资料，核读原方法的任务、条件和收益，不要求用户先提供基线。收益可为能力、成本、可靠性或使用范围；一个局部约束下的有用改进不必同时承担新机制和普遍领先。

H01设计配套HT2用于区分预测评价、工程表现和理论主张，M10帮助分开预期幅度与价值。逐项比较成本、信息输入、任务口径及使用条件，指出需要公平比较的原则；不在02形成固定数据集、完整基线清单或提升百分比。能跑、拟合更好或榜单领先不能独自支持科学机制。

**02够用：**可信比较对象的类别、改善维度和允许的权衡足以说明目标。所谓“更好”若不回答01问题须先修正；评测、独立测试、实现和预算细节留06—08及对应准备。依赖[P05](#p05)、[P09](#p09)、[P13](#p13)；比较条件变化后回看目标，范围根本变化按00处理。

<a id="p20"></a>
### P20 质性、体验与解释性研究

体验如何被理解、意义怎样形成、讲述方式有什么差异，不必先改成“X提高Y”。AI根据01问题解释认识目标，提出工作预期、关注角度或待解关系；用户不知道范式时，用普通语言说明这些表达能支持哪种结论。预期不是规定最后必须出现的主题。

H07研究设计、备忘录和比较资料提供整理线索；M13样章用于核对理论取向、研究者解释和分析目标的一致性。AI写明关注角度来自哪里，哪些材料会挑战、缩小或改变解释，如何保留负例及研究者自身预设。主题、解释和材料并非完全无前提生成；事后形成的主题保留形成身份。应按所选质性取向解释适当的质量依据，不把统一编码簿、编码者一致性或固定饱和次数当成通则。

**02够用：**对象、认识目标、暂定预设、开放之处及可挑战位置清楚。目标本身含糊先解；抽样、访谈、编码、分析软件与充分性判断留06—08。依赖[P03](#p03)、[P04](#p04)、[P08](#p08)、[P16](#p16)；若下游发现实际要作因果或统计推断，回看目标及其证据责任。

<a id="p21"></a>
### P21 个案解释与过程追踪

相同结局可能来自不同过程。AI把机制预期写成过程主张及其可能迹象，解释主解释和替代解释是否互斥、包含或共存；用户不知道区分办法时，AI比较它们在同一情境下应留下什么不同材料。

M14原文及作者补记用于检查过程描述、背景知识和诊断性证据；H05只借横向比较。不凭时间先后或词语出现直接认定机制，不把过程追踪的检验分类做成必须全填的表。需要同时问某迹象是否应该出现、能否看到、其他解释是否也可能产生它；事件描述本身仍需依据。

**02够用：**过程主张、重要替代解释、关键条件和初步区分后果清楚。若只能检验共同预期，先限制独占归因；正式搜集与判定计划留06—08。依赖[P07](#p07)、[P10](#p10)—[P12](#p12)，连接档案来源[P22](#p22)；背景或来源改变后回看解释力。

<a id="p22"></a>
### P22 档案、历史与证词的来源批判

文件说过某事、当事人如何回忆、机构希望表达什么，与事情实际怎样发生是不同层面的主张。AI替用户说明准备使用哪一层，不因官方文件、亲历身份或古老文献就自动接受其全部内容。

在M15文件分析页面依次查看作者、时间、受众、目的、背景和其他视角；用H08来源评价表分开真实性、内容解释及佐证，检查多条来源是否来自同一原报道。材料是节录、翻译、回忆录或后期整理本时，说明其怎样影响预期。再分清“没有发生”“没有记录”“尚未找到”：只有在有理由期待记录生成、保存且可检索时，缺失才可能有较强区分力，检索未发现本身不是证明。

**02够用：**预期依赖的来源性质和关键限制明确。若以某项“既定事实”或记录缺失作核心依据，其性质及期待依据须先解；完整档案鉴定、搜集与取证设计后移。依赖[P02](#p02)、[P12](#p12)、[P21](#p21)；新档案说明或独立来源改变前提时回看。NARA教学表只作入门提示。

<a id="p23"></a>
### P23 概念辨析与论证研究

AI先说明是在规定一个工作含义、描述既有用法，还是为特定用途改进概念。用户不熟悉分析方法时，AI提出典型例、边界例和替代定义，解释定义不同会怎样影响命题；不能把约定术语的结果写成经验发现。

用M16 Definitions的1.3—1.5区别定义用途，H06逻辑参考检查偷换含义、结论藏入前提及反例处理；复用M01／M02检查概念与理论层次。对具体论证列出前提、推出什么、何处可挑战，涉及价值标准时将其作为明确前提而非未说明事实。检查论证是否循环，不武断宣布所有形式循环定义非法；未被一组例子反驳也不等于定义普遍成立。

**02够用：**核心概念、待论证主张、定义用途、关键前提和挑战位置明确。概念混乱或论证把结论当根据须先修正；完整形式化与论证由06开展。依赖[P04](#p04)、[P07](#p07)、[P08](#p08)；定义改变可能改变目标，连接[P26](#p26)。本轮未取得适用的专用concept-analysis Skill正文，以作者署名的哲学方法综述和已有材料补足，不将检索概念分块Skill当概念分析。

<a id="p24"></a>
### P24 证据综合、重复验证与边界检验

证据综合的预期可涉及整体模式、一致性或条件差异，不必提出新的因果机制。AI解释当前想认识哪种关系，按M11定位综合对象、比较、结果和分组；用户不知道时，先比较这些目标能回答什么。不从方便取得的文章倒推目标，也不预设一定元分析。用M12查拟议差异的机制或独立理由，保留方向未知；看过结果后才提出的分组明确为事后探索，“一组显著另一组不显著”不能证明组间差异。

重复验证先按M08界定承接的原主张及预计重要的条件。AI说明一致和不一致结果分别如何改变信心，区分同数据计算复现与新证据评价原主张；方法或情境变化后，失败可能主要影响推广范围，也可能挑战原主张，不能预先统一保护或否定。

**02够用：**综合或重复目标、重要边界、差异预期的理由、既有阅读范围及可改变判断的结果清楚。核心对象变动回01；纳排、检索、合并、正式差异比较及重复操作留06—08。依赖[P09](#p09)、[P14](#p14)—[P16](#p16)。M11／M12主要针对干预综述，质性或其他综合须按问题裁剪，不能把GRADE或统计异质性模型统一套用。

## 6. 够用判断、修订与交接

<a id="p25"></a>
### P25 区分必须先解决与可交下游的未知

**AI先判断未知改变什么。**若它决定目标含义、决定性依据是否可信、核心条件是否自相矛盾或根本有无检查路径，就要补查、澄清或降低主张后再供确认。不能只写“待核”而声称目标成熟。若它是正式模型、工具、测量、样本、参数或操作细化，则说明下游需要解决什么及失败影响，不重复提前做设计。

用户不知道资源或技术细节时，AI依据已有资料给条件性判断，不把未知当用户承诺；不为澄清可检验性擅自运行PoC、预实验或研究性试运行。H01质量配套HT1与H02失败类别帮助分开想法问题、实现问题和资源问题。

**够用与关系：**从[P01](#p01)、[P07](#p07)、[P11](#p11)和相关路线提取少量决定性未知，标出先解或后移及理由。有意义的局部目标可缩小工作范围，但不能在保留原主张时删掉必要验证；期刊负担细化交03／05。没有成熟候选可以如实结束本次候选形成，不强行确认。

<a id="p26"></a>
### P26 判断实质修改，保留旧预期的身份

AI比较修改前后的科学含义：核心关系或方向、主比较、因果／机制层级、关键适用条件、用途及成功含义。文字修改很短也可能改变目标；定义或界限修改不能自动视为小修。用户不懂差别时，AI用同一结果在新旧表达下会被怎样判断来解释。

借H02版本保护、H01偏离记录和M05透明变更，引用旧版本及修改理由；新解释相对于已用于生成它的证据保留事后身份，未来独立检验可另立前瞻目标。原目标不变的技术细化归06／07，并按00判断13授权；核心预期改变回02，选题改变回01。可靠反证进入14／15，本身不要求重新确认或不断换假说追正结果。

**够用与关系：**修改理由、影响和保留部分清楚，无需重做未受影响成果。依赖[P09](#p09)、[P12](#p12)、[P16](#p16)、[P25](#p25)；只增加02特有科学判别例，共用回退执行引用00。

<a id="p27"></a>
### P27 独立检查新增的科学判断

独立读者检查当前假说是否回答01问题、依据与推理是否可定位、强度与范围是否相称、重要替代解释是否被公平处理、检查后果和辅助条件是否可信、未决项是否阻断选择。AI提供原文定位和实际阅读限制；用户不必先学会审查方法。

H02审查提示提供“实际查过什么”的做法，HT1及H06用于指出具体发现、对目标的影响和最小修正。不以引用数、评分、固定轮次或是否符合预期代替判断，也不重复已有效的上游核查。来源未报告某程序不等于程序确实未做；正式科研的实现与证据质量检查在对应下游处理。

**够用与关系：**决定性疑问关闭或明确限制，审查足以支持可理解的目标选择。仅有大纲、链接或“看起来合理”不足；质量核查不替代用户决定。汇集[P01](#p01)—[P26](#p26)中的实际相关部分，并为[P28](#p28)提供依据。

<a id="p28"></a>
### P28 汇总用户确认对象及向03的增量

AI用简短语言汇总当前预期、对象与条件、关键依据、重要竞争解释、哪些结果改变判断及主要未知，引用已有记录。用户此前不知道或只认可一项偏好时，仍须明确完整对象；不要求用户重写假说书。采用开放或概念路线时，确认清楚的工作预期与待解问题，不强迫方向性定量答案。

确认后的交接增加研究画像、贡献类型、证据负担、未决可行性及允许的表达范围，给03用于期刊匹配和任务难度解释。不得随期刊偏好自动改变假说，也不把用户确认当假说成立。06接收逻辑及待细化方法，14／15接收原预期和形成身份用于实际判断。

**够用与关系：**另一位读者能定位有效确认及其限制，理解下一阶段需要新增什么。用H01记录思路、H02审查依据及现行02规则；确认、记录、等待和依赖处理全部引用00，不建立新关口。依赖[P25](#p25)—[P27](#p27)。

## 10. 材料怎样变成候选假说

本节不再增加一批假说术语，而是说明已有问题、原文与用户反馈怎样形成可讨论的预期。下面的甲/乙报告、模型名、观察和文本全部是构造材料，不是现实论文、用户材料或已取得结果；用它们演示推理，不能引用为研究依据。真实使用须替换为当前课题实际读过的来源及条件。

### 10.1 从两条材料走到候选，而不是把作者展望改成自己的假说

假设01已经确认的问题是在一种标签与计算受限的场景中，比较成熟简单办法和复杂办法的收益、代价及适用条件。AI拿到两条构造材料：甲称“在其小规模标签条件下，简单模型A误差较低”；乙称“在其标签较充足的条件下，复杂模型B误差较低”。

第一步不是投票选一个方向，而是回原文定位这些话怎样得到：比较任务、目标量、信息输入、调参机会、样本结构、使用场景及不确定性是否相同。若甲只有默认参数的B，乙用了充分调试的B，标签多少还不是唯一差别；若连误差定义都不同，先澄清能比较到哪一层。AI据此把“原文报告”“可能解释”“尚无依据”分开讲给用户，不要求用户先给出理论。

接下来找能够连接材料与当前问题的理由。例如，有限标签可能改变复杂办法的估计负担，但只有这一句话仍不足以推出A必然占优。AI应补查相应学习机制、方法条件和最接近的反例；文献只支持一种可能时，就说这是解释线索。然后提出可调整的候选：一种是“在已限定的资源与信息条件下，简单办法可能取得较有利的能力—成本权衡”；另一种是“现有差异主要来自比较设置，公平比较后不一定保留”。这两个候选不是必然互斥的世界，二者可能同时贡献于观察差异。

若无法辩护优势方向，可将02目标保留为比较收益与代价如何随条件变化、区分哪些解释，而不是制造一个正向预期。若意义本来就在局部约束，只讨论该范围；不自动扩成证明所有模型、所有任务、所有数据规模的规律。正式资源设置、模型族、效应量和检验规则留06/07；02需要说明拟认识的关系、理由及哪些条件会改变它。

**AI给用户的可理解解释可以是：**“两条材料目前不冲突到只能留一条。它们的条件不同，而且比较设置可能影响结果。我建议先把目标放在你已经选定的受限情境，弄清什么权衡能成立，以及差异是否来自比较方式。你更关注这一局部用途，还是希望研究条件变化本身？”用户不知道时，AI用两种成果分别会回答什么、增加什么负担来帮助比较；不要求用户先发明假说，也不把这个构造建议当真实选题决定。

### 10.2 把竞争解释变成可区分的后果

继续上述构造，只列会改变判断的解释与证据需求，不制作固定实验表：

| 候选及关键前提 | 什么现象仅表示相容 | 什么信息可能帮助区分，以及限制 |
|---|---|---|
| H甲：受限条件下，方法本身的估计/资源特性带来局部权衡优势 | 在一次受限比较中A误差较小 | 在信息、评价与适当优化机会相容后，局部权衡是否仍存在；但优势存在本身还不独占证明所设机制 |
| H乙：观察差异主要来自B未被恰当设置或评价口径不同 | 在原设置下A误差较小 | 修正有依据的设置/口径差异后，原差距是否改变；若改动还改变信息或成本，也不能只归因于调参 |
| 两者共同或其他解释 | 某些条件下优势有、另一些没有 | 先定位哪种条件/误差来源对应哪些变化；若关键区别无法观察，保留未区分，不用排名宣布赢家 |

这张表说明为什么“看到A较好”不等于证明H甲；“另一设置下无差异”也不直接反驳所有局部优势。每个后果都须问：所列前提是否成立，若看不到这一现象，是解释不成立、测量不够，还是比较并未触及它？02说明这种逻辑与初步信息路径即可。确切怎样公平调试、如何取样与计算、何种精度足以区分，由06/07继续形成方案，不能在这里悄悄试跑。

反向也要检查：若多个候选无论什么结果都能临时解释，就指出是哪条连接过宽，缩小预期或寻找不同材料；不要为每次结果加一条保护性前提。没有辨别性并不意味着任一候选已经错，而是当前不能作所要求的独占判断。

### 10.3 多项预期怎样关联，哪些结论不能互相替代

先用逻辑关系解释主次，再决定是否需要拆开，不按统一数量产出“主假说/子假说”：

- **联合目标**：若拟主张“降低相关成本，同时保留有用能力”，两项都承担主张。成本下降但能力损失超出可辩护范围，不能只挑成本作成功；能力范围未定时要承认该目标还需细化。不能用“不显著变差”直接代替保留能力的证据。
- **替代目标**：若事先允许“成本降低或能力提高”任一种形成有意义成果，要说明它们各自的价值、代价及允许表述。不能看到结果后把原来的“且”改成“或”，再声称原目标全部支持。
- **条件目标**：若预期只在条件C下成立，要写明C的科学理由及其在结果前后的身份。后来观察到一小组有利情形，不可无记录地把它补为原定条件；组间差异需要相应比较，不能从一组显著另一组不显著推出。
- **核心目标与解释分支**：局部实用收益可能是核心，某种机制是辅助解释。没有机制证据不一定抹去可靠收益，但必须撤回机制语言；反过来，机制相关迹象不能替代用途收益。二者都重要时，向下游分别交证据义务。

这些关系影响03对证据负担的解释、06方法和07判读安排。统计多重性与具体规则按适用研究另定；概念、数学或档案路线也可有联合论证与条件命题，不硬套统计检验。

### 10.4 把含糊预期改到哪里为止

“A更好”要先追问好在哪个维度、相对什么、在何种用途与约束下；“更稳定”要区分对扰动敏感、重复测量一致、跨场景性能还是动态过程有界。AI先按原问题解释不同含义及证据责任，不能自行选择最容易取得好数值的定义。

再区分方向、形式与尺度。有依据才提出随条件单调上升、超过某范围才出现、先增后减、滞后出现或主要改变波动而非平均等候选；没有依据则保持未定，不把这些形式全列为必须测试的套餐。跨论文的条件差异只是形成候选的线索，不能直接当作同一系统的函数关系。

02结束时通常应有“在已说明对象与条件下，相对可信比较，我们预期什么关系/权衡，理由是什么，哪些信息会挑战它”的可理解表述。精确指标、界限、模型和评价程序可以交06/07，但若连哪种用途才算有意义都不清楚，须先解释并讨论；不能全部改名为技术细节。没有合理幅度依据时不编数字；用户接受某个范围也不证明科学预期成立。

### 10.5 非定量路线怎样形成开放但有内容的预期

**构造档案例：**01关注一个组织怎样落实某项制度。材料甲是上级面向下级发布的要求，材料乙是多年后的个人回忆，称实际做法有差异。AI先区分规范要求、事后记忆与实际实践：两段话并非测量同一东西，不能立刻宣布制度“执行失败”。拟解释可能是地方既有做法影响落实，也可能是回忆目的/时间选择，或记录本来不覆盖具体执行。

AI据此提出工作预期和材料需求：若要判断实践怎样变化，需要接近实际活动的同期材料及其形成语境；若只研究组织怎样自我表述，原有文本或许能回答较窄问题。应说明什么迹象会支持或挑战各解释，以及它们是否来自独立来源。未找到某项记录时，先判断是否本应形成、保存并可找到；不能直接当反证。这是P21/P22推理的展开，具体档案取得与分析仍交下游。

**构造意义研究例：**01若关心人们怎样理解一段经历，AI可以确认“研究不同处境下的意义组织及其变化”，并交代初始理论视角与尚开放的部分；不必给“X提高Y”的预测。预期的内容体现在关注何种区别、为什么重要、哪些相反叙述或语境会迫使解释修订。不能提前规定必须出现的主题，不能把AI拟的访谈回答作为材料，也不让“开放”变成研究什么都说不清。

概念路线则可以先给竞争释义及其不同推论；数学路线给猜想与成立条件。后续使用何种论证/解释传统、怎样取证，由06细化。02不冒充完成这些工作，也不要求所有路线先有数值预测。
