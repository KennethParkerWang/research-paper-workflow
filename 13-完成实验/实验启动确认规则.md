# 实验启动确认规则


## 从已有方案开始讨论

承接01选题、02假说、03期刊，以及06设计与07／08计划步骤。AI整理并解释已有方案，用户不用重新完成计划；未决定的部分由AI提出选项，逐轮询问和调整。

讨论可以在07／08方案形成后开展。确认后落实10资源、11所需实现与12正确性检查；正式研究开始时这些条件仍须满足。已有准备及检查有效时直接引用。

## 必须商讨的内容

| 内容 | AI需要解释与询问什么 |
|---|---|
| 实验目标 | 要回答哪个问题、填补什么证据缺口、与已确认假说有什么关系。 |
| 实验方法 | 采用什么方法、为什么适合、主要比较与对照、可选路线及代价。 |
| 待检验结论 | 希望检验哪些判断，哪些结果支持、反驳或仍不能确定；实际结论随后由证据决定。 |
| 实验细节 | 数据／材料、适用条件、参数与步骤、评价指标、重复安排、结果和偏离记录方式。 |
| 资源与停止条件 | 时间、设备／算力、预算与主要依赖，失败时如何处理，达到什么条件应停止。 |

每轮围绕当前关键取舍，AI用可理解的语言解释，依据用户回答更新方案。用户不知道时提供选项与理由；局部讨论或认可不自动构成完整实验启动确认。

理论、测量、观察或证据综合研究使用相应的研究目标、方法、验证细节与资源安排，不强套同一种实验形式。

## 明确确认后执行

AI汇总调整后的方案、关键细节、资源范围、停止条件及未决事项，引用已有正式记录。独立代理核查方案是否清楚、能回答问题、包含必要证据与可验收条件；用户决定是否启动。

保存用户对具体方案及范围的明确确认，绑定版本与约束。尚未确认时可以讨论、查阅资料和草拟方案；预实验、研究性试运行、正式取证或实验性数据采集须先在相应确认范围内。前置任务不能仅因被归入10、11或12而绕过该关口。

确认后按共用循环一次发布一个任务，独立验收、证据交接及临时材料检查后再调整下一项。已确认范围内的执行修复、重复运行及约定补验复用有效确认，不逐任务重复询问启动许可。

## 实质变化与再次确认

实验目标、核心方法、待检验结论、关键数据／对照／参数／评价方式或资源范围实质变化时，AI解释原因与影响，重新商讨，更新用户确认后执行受影响任务。原计划内补验也要检查已有确认仍有效且覆盖该任务；独立验收代理不能代替用户新增或扩大的启动决定。

改变选题、核心假说或目标期刊时，还需返回相应确认关口。日常任务质量仍由独立代理验收，方案确认不保证得到预期方向的结果。

记录与回退统一遵循[任务与阶段衔接规则](../00-阶段交接关系/阶段交接关系.md)，复用现有设计、计划和证据，仅补充讨论、确认及变化。本页只保存启动规则；执行中的具体工作、证据与不同研究路线见[实验执行阶段详细手册](实验执行阶段详细手册.md)。两页均是流程研究资料，未开展实际实验，也不是已获批准的真实科研方案或已安装Skill。
