# 实验执行阶段详细手册


本阶段把已确认计划落实为可解释、可追溯的实际证据；也涵盖按方案进行观察、理论推导、质性取证、档案研究与证据综合。


本页的记录与分流按实际研究类型使用，不增加固定小任务数或文件体系；实际方案范围仍以用户有效确认为准。

## 1. 本阶段增加什么，怎样走过完整过程

### 1.1 承接已有决定，新增实际事实

06回答“用什么理论和方法回答问题”，07及其内部08回答“怎样取得证据、按什么顺序操作”；10落实实际输入与资源，11在需要时实现，12检查基础正确性。13不重新选题、设定假说或选刊，也不凭运行中遇到的方便条件悄悄重设计。

13新增的核心成果是已执行工作的证据：实际用了哪些对象、材料、版本和条件，发生了哪些操作，保留了哪些原始产物，控制是否成立，哪些尝试失败、缺失或偏离，以及这些事实允许哪些后续分析。方案中的“拟做”必须与记录中的“实做”分开。

14在这些依据上开展结果质量、不确定性、模式和异常分析；15判断假说、竞争解释及允许表达的结论。13可以识别某次取证无法解释、某项任务尚未完成、某条计划分支应暂停，但不以“结果符合预期”作为执行通过标准，也不提前替15宣告核心假说成立或不成立。必要的现场质量检查属于执行；跨条件统计比较、主题归纳和科学解释按14与15职责承接。

### 1.2 假设科研人员进入本阶段

以下是流程推演，不是真实科研经历。研究者收到确认后的方案，通常会这样思考：

1. 我现在要取得哪一条必要证据？上游版本和用户确认是否仍适用于这项工作？此前已验收的成果能否直接用？
2. 面前的实际输入是否就是计划中的输入？对象身份、单位、设备状态、实现版本和许可是否落实？有哪些事实仍不知道？
3. 操作开始后，哪些因素必须保持一致，哪些因素按设计变化？由谁操作、谁测量、谁知道分组，顺序是否产生影响？
4. 每次操作会产生什么原始记录？怎样把它与对象、条件和尝试联系起来，避免覆盖前次证据或把重复测量当独立证据？
5. 工作中出现空值、异常或中断时，它是预期现象、技术问题，还是设计无法取得所需证据？应按哪条已有规则处理？
6. 修复、重试或补验是否仍属于确认范围？我是否已经看过会影响这个选择的结果？记录需要怎样说明？
7. 预算、时间和必要资源还够完成哪一部分？达到停止条件时，怎样保住已有证据并说明剩余缺口？
8. 操作结束后，别人是否能定位输入、复核产物和理解失败？完成的是一次运行、一项科研任务，还是本阶段？
9. 交给14时，哪些证据可分析、哪些有限制、哪些应隔离，哪些任务尚未做？是否把解释误写成原始事实？

这些问题形成“有效方案与条件 → 操作身份与控制 → 原始证据 → 缺失、失败和偏离处理 → 独立验收 → 14分析”的依赖链。工作量由证据缺口决定，不把每个问题变成一个单独任务。

### 1.3 AI怎样引导，用户不知道时怎样推进

AI先用一段可理解的说明承接已有方案，例如：“本项要取得用于比较A与B的测量，主要控制是同一批材料和相同测量规则；目前只缺设备是否仍校准的依据。”随后只围绕影响当前操作的关键未知提出选项与依据，而不是把全部手册变成问卷。

- 用户不懂方法时，AI说明它观察什么、容易被什么因素混淆、预计会留下什么证据，再用与问题相关的例子解释。
- 用户不知道参数或运行规模时，先引用07中的依据和10实际能力；存在可信选项时说明代价，明确哪些可由现有计划决定、哪些必须修订方案。
- 用户不知道是否看过已有结果时，记录知情范围不确定，不替用户补写“事前未知”。AI可以整理已有记录，不能把后来生成的说明伪装成当时记录。
- 对设备状态、材料身份或档案是否完整等事实，先核对证据。未知写成未知；缺少会使取证无法解释的事实，暂停受影响操作并定位应补的最早上游工作。
- 可以在尚未启动时查阅方法、解释和草拟；研究性试运行、预实验和正式取证都须属于有效实验确认范围。已有范围内的普通修复、重复运行和约定补验依00继续独立验收，不逐项重复请求启动确认。

## 2. 执行前：确认有效，进入条件实际满足

### 2.1 把方案确认与执行就绪分开检查

启动讨论与明确确认按[现有规则](实验启动确认规则.md)办理。本页不重复建立确认表。13执行前引用同一正式方案与确认记录，检查五类依赖：

| 要核对的依赖 | 本阶段需要知道什么 | 不满足时怎样处理 |
|---|---|---|
| 决策与目标 | 当前任务对应01/02的哪条问题或假说、06的哪项验证逻辑，是否仍属于确认方案的目标和范围 | 先定位最早失效决定，按00回退；结果不符合期待本身不使原假说确认失效 |
| 计划与步骤 | 使用哪一版07/08，预定输入、条件、对照、测量或验证办法、必要输出、容许偏差、重试与停止规则是什么 | 缺少影响可解释性的安排先补计划；涉及实质方案变化再回启动商讨 |
| 实际资源与许可 | 10交来的对象、材料、设备、环境、数据访问及必要许可是否可用，实际限制是否改变计划 | 引用10依据，仅补变化；缺关键资源不以“先跑再说”替代就绪 |
| 实现或操作正确性 | 需要代码时引用11与12；无需代码时引用测量、装置、抽取规则、推导前提等相应12检查，当前输入或版本变化后是否仍有效 | 补查受影响部分；重复有效验收没有新增价值 |
| 任务预算与依赖 | 本项能在现有时间、耗材、设备或算力范围内完成，前置任务已验收，原始证据有可保留位置 | 先解决实际阻碍或按停止规则缩小/结束；超出现有授权范围提出具体取舍 |

有效确认不是实验成功保证；资源已准备也不等于用户已确认方案。某项检查只能说明基础正确性时，不把它写成方法已获科研证实。

### 2.2 核对预实验、试运行与正式取证的身份

预实验可能回答“设备能否得到读数”“招募方式是否可行”“问题是否被理解”；正式取证可能回答核心研究问题。两者的目的、对象使用、可用证据和下游用途要明确。依据已有确认开展的小规模试运行，不自动授权扩大规模或改变关键条件。

若计划允许把预实验样本纳入正式分析，须在原记录中保留其时间、条件和用途依据，并检查方法是否一致；若它已被用于调参、修改访谈问题或选择指标，不能抹去这一知情历史。是否合并以及它能承担何种分析由07安排、14核对，13提供实际事实。源资料中的“廉价先试”只是成本思路，不能绕过本流程实验确认。

### 2.3 固定事前规则，允许诚实的后续发现

把已存在的主要测量、验证条件、排除、重试和停止规则绑定到方案版本。必要的后续选择记录发生时间、已看过哪些结果及理由，不能回写成事前安排。探索、质性迭代和理论尝试可以合法产生新问题，但新增验证须回07/08并判断是否属于有效确认范围。

OSF官方说明把时间明确的计划、排除规则和预期偏离作为研究透明度的内容；本流程借鉴其事前/事后区分，使用已有本地计划即可，不强制注册、创建OSF项目或公开材料。[OSF官方注册说明](https://help.osf.io/article/330-welcome-to-registrations)

够用程度是能回答“这项规则何时确定、执行时依据哪版、决定时掌握什么信息”。不同研究的可预先固定程度不同，不给质性或理论路线强行套统计阈值。

## 3. 操作身份、单位与控制怎样落实到现场

### 3.1 区分对象、测量、独立单位和尝试

需要同时识别四种身份：

- **对象或来源身份**：样本、参与者、病例、材料、档案条目、文献报告、理论命题或数据条目的实际来源。
- **研究单位**：设计中承担分配、抽样或独立比较的单位，及其层级关系。
- **测量或取证单位**：一次读数、一个时间点、一段访谈、一页材料、一条抽取值或一个证明步骤。
- **执行尝试身份**：本次何时、由谁、用什么配置操作；一次任务可能有多次尝试，一次尝试可能产生多个测量。

本流程适配办法是复用对象原有编号和任务身份，在记录中补上必要关联，不强制另造一套编号。共享材料的多次测量、同一参与者的不同片段、同一研究的多篇报告都要保留共同来源。多个运行编号不能自动说明证据相互独立。

动物研究的ARRIVE单位说明特别提醒区分实验单位与下属测量；其他研究要从06/07确定自己的独立单位，不能照搬动物单位定义。[ARRIVE实验单位正文](https://arriveguidelines.org/arrive-guidelines/study-design/1b/explanation)

**如何核查**：选一条计划中的主要比较，沿“实际分配/抽样单位 → 所属对象 → 测量 → 原始产物”读一次。若同一对象被重复计数、批次混同或报告重复纳入，先修复关联；统计处理留给14，不通过改编号伪造独立性。

### 3.2 实际输入与分配要可核对

计划写“某数据集”“某种材料”通常还不够定位本次操作。执行前引用10已有来源和版本，记录实际使用的子集、筛选条件、材料批号、样本状态、对象时间窗或文献集合。输入变化要判断上游验收和确认是否受影响。

执行分配与抽取时按已定规则，保留实际名单或对应关系、生成分配的依据、实施者及时间；记录调换、无法进入、跨组污染和退出等事件。随机安排适用时，保留实际序列而非只写“随机”；非随机或目的取样按相应设计记录依据，不改写为随机实验。人员姓名不必重复到全部产物中，可在适当权限的已有记录使用可追溯标识。

对照组、比较材料或基线也要有实际执行证据；不能仅在计划中出现。共享对照应能识别被哪些比较引用，不能当作多份新增独立证据。对照未执行、条件不匹配或受污染时，标明失去哪些比较能力。不同研究允许不同对照形式，没有对照时引用设计理由。

ARRIVE对照、随机化正文提供了动物研究中的具体提醒：报告所有实际组别，说明实际分配办法和无法控制的混杂。本流程只借鉴记录思路，不推广其动物研究要求到观察、档案或质性研究。[对照](https://arriveguidelines.org/arrive-guidelines/study-design/1a/explanation)、[随机化](https://arriveguidelines.org/arrive-guidelines/randomisation/4a/explanation)

### 3.3 操作者、设备与环境要记录到影响解释的程度

操作者差异可能改变操作、判断或接触对象的方式。按设计记录实际执行者、角色分工、培训或熟练程度的相关变化，区分操作、测量、转录、抽取与核查的责任。AI协助时记录它承担的实际环节和可影响取证的工具/模型版本；AI生成的示例、猜测和补全不能充当实测数据或原话。

设备与环境记录复用10：实际设备或仪器身份、配置与固件/软件版本、相关校准日期、关键环境、容许范围和状态。电子环境关注代码和依赖、硬件、数据接口、远程服务版本；现场环境关注地点、时段、操作条件和无法控制的因素。只有可能影响当前证据的细节才进入结果记录，型号列表不能代替状态证据。

必要的校准、检查样本或装置验证由计划和12决定。13核对实际检查结果及有效期，观察操作过程中漂移、故障或配置变化，及时标记受影响区间。若更换设备仍在允许范围且已有等效依据，记录变更并补必要检查；若改变关键测量含义或可信度，先回最早受影响工作。

NIH官方严谨性页面以生物医学为范围强调设计、方法、分析、解释与报告的一致严谨；它不是全学科设备清单，也不替本流程确定校准限值。[NIH官方说明](https://grants.nih.gov/policy-and-compliance/policy-topics/reproducibility)

### 3.4 顺序、时点、批次和执行位置也是条件

照步骤完成仍可能留下顺序混杂。例如所有A条件上午测、B下午测，或访谈员在看过第一批结果后系统性改变追问。13依据07/08实际落实交错、分块、顺序平衡、间隔或洗脱安排；未安排且发现关键混杂时，不临场选择最方便顺序。

记录关键操作时间、测量时点、时长、频率、批次、设备/位置、前一步与后一步的关系，以及中断后继续的状态。无需为每个普通动作逐秒记时；达到能区分关键条件与可能混杂的程度即可。时间单位、时区或时间基准容易混淆的研究明确基准；物理量记录单位与换算来源。

重复与长期观察尤其要区分“同一单位在后续时点”与“新增独立单位”。设备或材料跨批使用时，保留批次变化及对照状态，不能通过仅保留最终汇总表消除实际差异。顺序效果、时间漂移或批次效应交14处理，13提供事实，不临时把不利批次删去。

### 3.5 盲法按环节说明，不能只贴“已盲”标签

适用时分别说明分配、执行、测量/评价、数据处理环节谁知道条件和预期方向，标签如何隐藏，何时揭盲，谁保管对应关系。实际揭盲或明显条件使盲法失效时记录发生时间、原因、已接触证据和受影响环节。

不能盲时说明实际限制，并落实计划中的可用控制，如一致的测量规则、事前判断标准、独立评价或对结果方向不知情的核查。是否需要这些控制由方法决定，不能把增加人员或检查作为通用升级要求。质性研究中研究者与参与者关系、反身性记录可能比组别盲法更贴合方法，不强制双盲。

ARRIVE盲法正文区分多个环节与实际知情情况，本页借其分环节记录方法；具体方法是否需要盲、可怎样盲仍依06/07。[ARRIVE盲法正文](https://arriveguidelines.org/arrive-guidelines/blindingmasking/5/explanation)

本节够用程度：另一位执行者能知道本项实际条件及主要偏倚控制，验收者能发现计划与执行不一致；不要求把全部学科控制压进同一张通用清单。

## 4. 每次取证怎样留下可用的原始依据

### 4.1 一个最小记录联系输入、操作和产物

每次尝试使用既有任务结果记录，至少能定位下列信息。现有仪器、研究平台或执行系统已可靠保存的信息直接引用，不重复抄写。

| 信息 | 本阶段要记录的实际事实 | 可以怎样保持精简 |
|---|---|---|
| 目的与依据 | 本项证据缺口、有效方案及确认版本、关联上游检查 | 链接既有计划，不复制设计全文 |
| 尝试身份 | 本次身份、起止或取证日期、执行者/系统，是否为重试、续跑或补验 | 引用系统实际任务号；手动操作用能唯一识别本次的标识 |
| 输入与条件 | 实际对象/材料/数据/文献/命题、子集、版本、必要参数及单位、环境/设备、分配和顺序 | 引用10/11记录，补本次差异；实际参数不能只留“默认” |
| 已发生操作 | 关键步骤、调用或人工操作，检查结果、中断及恢复，适用的盲法和角色事实 | 保留能重建关键过程的步骤；不逐字复制无意义控制台输出 |
| 原始证据 | 原始读数、数据/图像/音频、现场笔记、来源页或证明过程的正式位置，格式与必要元数据 | 一个权威副本和引用；需要时使用内容标识/校验值，不强制所有对象计算哈希 |
| 完整性与状态 | 预期产物是否产生、缺失/异常/失败、实际覆盖、哪些部分可用 | 用实际数量或范围对账，不用“全部完成”概括尚缺内容 |
| 偏离与处理 | 哪项计划未照做、何时发现/决定、已看哪些结果、依据与影响，关联修复/后继尝试 | 就近追加事实，保留被更正的值和理由，不另建平行事实来源 |
| 资源与剩余问题 | 实际时间、设备/耗材/算力/费用的相关证据、停止原因、待核查内容和执行处置 | 估计与已发生量区分，未知注明；财务明细已有位置就引用 |

### 4.2 原始证据、整理结果和解释分开

原始证据是本次取得或引用的直接依据；整理结果是经转录、清洗、编码、换算或汇总后的材料；解释是研究者对其意义的判断。三者可以在一份记录中联系，但应能辨认其来源与处理关系。

原始文件或纸质记录不因发现错误而原位改成“正确结果”。在已有正式位置保留原件和更正说明，派生材料记录操作、规则、版本和输入；外部服务不能长期保留时，按资源条件保存必要可读取证据并说明访问限制。不能存原件的情况记录确切理由、可核查定位和证据能力限制，不宣称已完整留存。

电子数据保留变量含义、单位、缺失编码和对象关联；图像保留能够检验测量的原始信息，截图或美化图不能自动替代原图；访谈保留时间戳/片段定位及转录规则；档案保留馆藏定位与原页/原段；理论推导保留定义、前提、推理步骤及引用定理。选择哪些关键中间材料取决于它是否支撑核查、失败诊断、复现或下游引用，不因一句“可以再做”而清除唯一依据。

计算研究中应把结果与实际代码、输入和参数相连，保留图表背后的数值及来源；这些做法受到PLOS计算可复现指南启发。本流程按必要证据选存，不要求存所有可重建中间文件或公开发布。[PLOS原文](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1003285)

### 4.3 防止覆盖、混同和误归属

下一次运行前先确认前次证据已有正式可读取位置，输出位置不造成覆盖。并行设备、人员或代理承担同一任务的不同部分时明确输入、条件与产物归属，避免两个尝试写到同一输出却被当成一次。

接续已有工作先核对实际产物和状态，不能只依据“上次说完成了”重复提交。对已经记录的同一产物补验或更正时引用原身份，不再生成一份看似新增的证据。外部平台父任务隐藏子重试时，保留能够获取的尝试关系，若只能得到总量就说明粒度限制，不虚构子尝试次数、耗时或成本。

临时材料检查依00；本页不会授权清理。与失败依据、原始证据或下游引用相关的材料先保留。

## 5. 执行中怎样识别问题、修复和停止

### 5.1 监控执行条件，避免偷换成结果筛选

监控围绕计划中的操作和质量条件：输入是否匹配、设备是否有效、记录是否可读、数量是否齐全、对照/操纵是否实施、过程是否达到约定状态。控制有数字也不等于控制成立，应按既有条件解释。检查阈值来自计划或可追溯的方法依据，不能看到结果后临时调到“刚好通过”。

看到预期方向的结果不能跳过检查，看到相反方向也不能直接宣布仪器坏了。必要的操作质控是为了确定证据能否解释，而不是选择想要的结果。质量检查若需要接触核心结果，记录知情时点；计划要求盲评时不擅自揭盲。

若现有检查无法检验测量工具是否真的到达研究现象，13说明这条证据能力缺口，暂停依赖它的取证并回06或07定位原因。记录局限不等于已解决局限。research-lab-notebook的方法模块提醒区分工具能力与主张范围；本流程仅借此诊断角度，不照搬其具体干预控制或追加人类关口。[Research methodology正文](https://raw.githubusercontent.com/osteele/research-notebook/main/skills/research-lab-notebook/references/research-methodology.md)

### 5.2 技术失败、负结果和未决结果用不同事实支持

| 实际情况 | 13可以怎样记录 | 怎样继续 |
|---|---|---|
| 技术失败 | 文件损坏、输入错用、测量不成立、实现错误、中断未产出必要证据等，附具体依据和受影响部分 | 按计划诊断；范围内修复后补相应12检查，再重试。不能把它作为假说反证 |
| 有效执行但未出现预期现象 | 实际操作与必要控制通过，保留原始结果、覆盖与限制，记录“不出现预期方向”这一事实 | 可以完成执行任务并交14/15；负结果不是执行不通过 |
| 有读数但无法判定 | 敏感度/覆盖不足、关键对照失败、部分条件缺失、身份不明等使当前结果不能回答问题 | 说明被阻断的判断，按既有补验或停止条件处理；不勉强叫支持或反驳 |
| 部分有效、部分失败 | 标明可用范围、失效范围及二者关系，保留全部尝试 | 只在依赖允许时推进可用部分；不能以局部成功掩盖必要缺口 |
| 反常但可信的现象 | 原始依据、质控状态、发生条件及已核查事项 | 交14分析，必要新验证先按计划与确认范围判断；不能为消除反常任意重跑 |

“没有显著差异”“没有观察到事件”“访谈未提某主题”“检索未找到报告”“没有完成证明”不是同一种否定证据。13提供各自过程能力和范围，14/15据此判断。技术失败与有效负结果可能并存于同一任务，须按部分而不是整任务一刀切分类。

### 5.3 缺失、异常与排除：保留事实，说明规则

缺失先回答哪一对象、哪一变量/时点/材料/步骤缺失，缺失如何发生，以及还能取得什么依据。区分未计划、未执行、已执行未记录、记录不可读、无法访问、对象退出和测量不适用。空格、零、未检出、缺失或未找到不能互相替代。

异常先保留直接证据及上下文，再依计划核查单位、转录、输入、设备、身份、重复和过程。真实极端值不能仅因难解释而删除；技术错误更正要保留旧值、更正依据及受影响产物。异常是否影响模型、主题或主张是14/15的后续工作。

实际排除要能联系到对象、条件、规则版本、发生原因和决定时点。事前排除规则与结果后新增排除分开；事后处理不能说成计划规定。保留尝试、对象、测量、排除及可分析材料之间的数量或范围对账。排除是否合理、对结果有多大影响交14判断，13提供未排除材料及实际选择过程。

ARRIVE纳入排除模块强调规则时点和实际排除理由，是动物研究记录参考；本流程将其适配为各路线的去向可解释，不套用动物样本数或伦理端点。[ARRIVE纳入排除正文](https://arriveguidelines.org/arrive-guidelines/inclusion-and-exclusion-criteria/3a/explanation)

### 5.4 重试必须说明重做什么、为什么和改变什么

重试可能是同一输入重跑、从已验证检查点续做、重新测量同一对象、重新取样或新条件验证。它们对独立性、资源和证据用途影响不同。重试前先保存原次失败和有用的部分证据，引用失败尝试，明确本次输入、改动、预期修复点和所用规则。

修复不改变研究目标或关键方案且仍在现有确认范围时，执行者按00推进并接受独立验收。需要代码修复回11，受影响基础正确性回12；需要改变测量、对照、关键参数或数据时先判断07/08与13确认是否受影响。不能将“重试”用作绕过方案变更的名称。

同一随机条件的重复可能用来检验技术可复现性；新随机条件可能增加变化覆盖，二者均须保留实际依据。不能重跑到出现满意结果再只报最后一次。系统自动重试也要纳入可获取的记录与资源量。重试上限、恢复条件、不能恢复时的处置由计划决定；未定且影响资源或证据意义时先补明确判断。

### 5.5 偏离记录发生时点，判断最早影响

偏离是实际执行与有效计划不一致，可以是操作意外、输入变化、许可或资源限制，也可以是依据新证据作出的主动修改。发现时记录原安排、实际发生、时间、原因、已见结果、受影响对象/条件和即时处置；既有记录没有当时信息就如实注明追记，不猜日期。

| 偏离或变化 | 本阶段判断与最小处置 |
|---|---|
| 容许范围内的操作波动、按已定规则恢复 | 记录实际值及理由，复用有效确认，验收其是否仍满足计划 |
| 误操作、数据或实现错误 | 保留错误依据，修复最早来源，复查相关部分与下游引用 |
| 关键输入、对照、参数、指标、资源安排或核心方法实质改变 | 暂停受影响任务，先更新07/08或06，回13商讨并由用户明确确认新方案；不把追认写成事前授权 |
| 新现象引出的额外研究 | 先作为发现记录，提出它回答的证据缺口和代价；判断是否属于既有确认范围，再安排相应任务 |
| 原目标、假说或期刊变化 | 按00返回01、02或03相应关口，不在执行记录中自改核心决定 |

“事先列了很多可能分支”也不等于任意操作已被确认。执行者和独立验收者都要核对这次分支与确认对象、约束及资源的关系。其余共用回退细则引用00，避免在13产生第二套判定规则。

### 5.6 资源停止是科研处置，不是消失的记录

每次尝试记录与本项有关系的实际量及单位，包括失败、中断和部分完成的消耗。时间、设备占用、算力、调用量、耗材和费用不是同一单位；估计、计量和已确认账单不混写。来源无法提供分项量就保留总量与范围，未知不记为零。

按计划检查剩余资源是否足以取得必要证据。预算不足时先说明哪些必要比较、覆盖或核查尚缺，提供已有范围内有科学意义的收尾办法；只能形成较窄证据时如实交接。小贡献可以有明确范围，不能靠取消必要对照或只留支持结果降低成本。

达到停止条件时，记录时间、触发依据、已完成范围、仍运行或等待的工作、原始产物位置和剩余缺口。暂停、取消、耗尽资源或按事实终止都可成为真实状态；不能因为会话结束就把尚在运行的任务写成完成，也不能默认无期限继续占用资源。后续工作须依据状态、剩余依赖和确认范围决定，停止原因不能替代科学结论。

research-lab-notebook的计划执行模块把工作边界、费用证据和未完成状态联系起来，本页借其停止意识，不移植调度器、财务台账或每阶段人类审查。[Plan execution正文](https://raw.githubusercontent.com/osteele/research-notebook/main/skills/research-lab-notebook/references/plan-execution.md)

## 6. 不同研究路线怎样执行，哪些控制不适用

以下路线按06/07选择，也可以在一项研究内组合。先明确每条证据的职责与相互关系，再决定操作细度；不要求每项研究同时实施所有路线。

### 6.1 测量、干预与观察研究

正式执行沿实际对象进入、分配或观察安排、操作与测量、过程质控、产物核对的顺序展开。干预研究要记录实际干预是否到达计划对象、时间与强度、对照是否同条件实施；观察研究记录真实暴露、事件、场景及时间，而不把观察到的差异改称随机操纵。

AI可先展示一条关键比较需要的实际过程：哪两个条件、谁承担独立单位、怎样操作、在哪里留原始测量、哪个检查失败会使比较无法解释。用户不知道设备容差或测量含义时，查相应方法或设备官方依据，再回07/12补充分界。专业操作、校准限值、样本安排和必要许可须由具体研究资源确定，本页不会代填。

执行时保留个体/单位与时间、条件、测量的关联；有纵向、簇集、重复或交叉结构时记录层级及既往处理。观察研究不可随机化的因素通过设计和实际信息保留，不能照抄干预研究盲法。原始测量、过程记录和可分析范围交14，因果解释交15。

<a id="execution-detail-delivery"></a>
#### 原分配、实际递送、接受与结局，怎样逐层核对

仅在干预、服务实施或操纵路线需要时使用。先引用06/07已定的问题：要判断分配/提供某方案的效果，还是在明确条件下遵从方案的效果，或某个机制是否被改变；它们不是同一个问题。若前序尚未说到足以指导取证，先补该科学选择，13不看完结果再换目标。

AI沿一名对象的实际过程读取既有记录：何时按什么规则分到哪组→提供者实际上递送了哪些内容、何时、多少→对象实际接触、接受或使用到哪种程度，依据是什么→何时取得哪项结局，未取得为什么。只留会改变解释的时间、程度和原因，不新增逐秒日志或统一依从表。计划允许的个性化、未按计划递送、对象未接受、改用其他服务与结局缺失分别说明；未知原因保留未知。设备显示“已发送”、对象打开内容及真正掌握某能力也属于不同依据，不能互相替代。影响比较的额外措施或跨组接触联系发生时点和实际对象，不据此自行重新分组。

**构造例**：假设原计划随机分配线上课程A或既有资料B，已定问题是分配A相对B的效果，未使用课程是该分配问题所保留的实际情形。A原分配100人，计划提供四次课程；为说明流程，把此次实际情况暂分成互不重叠的三类：

| 原分配仍为A | 实际递送及接受事实 | 规定终点取得结局 | 未取得结局 |
|---|---|---|---|
| 70人 | 四次内容均按计划提供，也有四次参与依据 | 64 | 6 |
| 20人 | 因平台故障未提供，未参加 | 18 | 2 |
| 10人 | 四次内容均可取得，实际只参与一次 | 8 | 2 |

这些数只说明100人的去向及90份已取得结局，不含任何效果值。后20人与后10人的原因、时间及记录不同，不能都笼统写成“30份失败数据”；未参加也不等于结局必然缺失。反过来，前70人仍有6份结局缺失，不能把“完成课程”当成“观察完整”。是否接受课程的依据不足时，也不能凭账号开通推定参与或理解。

下一步依既定问题与实际条件分流：

- 若问题出在本可纠正的递送故障，按原计划的补救及时间窗处理；超过窗口或须实质改变方法/资源时回07及13确认关系。补送要保留原先未递送的时间，不追写成全程按计划实施。
- 对上述分配效果问题，保留100人的原分配关系、递送/接受事实及结局去向；不能把未参与者删掉，或把参与者改归另一组。14另行处理10份结局缺失及其假设，保留原分配不自动解决缺失或保证估计无偏。符合计划的未使用不一律判技术失败；平台故障可构成执行偏离，是否使核心比较无法解释需按其范围判断。
- 若原问题关注按特定方案持续接受的效果，需要与该目标相符的设计、信息及分析假设；仅比较“实际完成的人”会按分配之后发生的行为选择对象，不能冒称保留了随机比较。若要判断机制被改变，实际递送与参与仍不保证操纵到达目标机制；缺这条依据时不能仅以终点无差异证明机制无效，也不能仅以参与充分证明机制成立。相关判读交14/15，不由执行者临时增加对人或材料的新测量。

## 7. 一次运行结束、任务完成和阶段完成怎样区分

### 7.1 三种完成不能互相替代

| 层次 | 表示什么 | 不能据此断言什么 |
|---|---|---|
| 操作/运行结束 | 进程退出、测量时段结束、访谈结束、调阅结束或推导尝试停下 | 产物完整、证据有效、研究问题回答了 |
| 当前科研任务完成或按事实终止 | 本项必要工作已完成并有可验收证据，或者失败/无可行方案/停止有清楚事实、影响与剩余问题 | 预期假说成立、本阶段所有证据已齐、可以扩展授权 |

### 7.2 独立验收看执行事实与证据资格

共用验收流程、独立性、退修和关闭规则见00。本阶段验收者应针对新增取证及受影响依赖，核对：

1. 本项确实在有效方案确认、资源和版本范围内，前置依据仍有效。
2. 原始证据可读可定位，实际输入、对象、单位、条件与尝试能够联系，关键控制及步骤有执行依据。
3. 预定必要产物与实际覆盖对得上；失败、缺失、异常、排除、偏离、重试和停止没有消失。
4. 不把技术成功当证据有效，不把不利结果当执行失败，不把部分或探索材料冒充完整的事前验证。

## 8. 假设情景中的状态与分流

以下例子均为假设，用于说明不同结果、缺口和范围变化如何进入后续阶段。

### 场景A：一个小范围测量得到负结果

已确认计划只比较特定条件，实际测量和必要设备检查完成，原始记录可定位，预期现象未出现。13记录有效范围与不利观察，当前执行任务可以通过；14评估精度、敏感度与异常，15决定是反证还是仍不确定。不会为了得到预期方向重复运行，也不会仅因贡献范围较小判执行不合格。

### 场景B：计算输出有数值，却缺一个必要比较

主方法成功运行，基线因错误输入失败。两个尝试及资源消耗都记录，必要比较仍缺。若修复属于有效确认范围，回11/12补受影响检查后重试，保留与失败尝试关系；不能只把主方法结果写成任务全部完成。若需要更换关键数据或评价方式，先更新计划并重新判断方案确认。

### 场景C：质性访谈引出计划外对象

研究者在现有材料发现新视角，记录原始片段、情境和提纲迭代。原确认方法已允许的追问可继续逐项验收；新增一类研究对象若实质扩大范围或资源，则先回计划与13商讨。新视角作为材料驱动发现交14，不回写为事前主题，也不以预定访谈场数宣称解释充分。

### 场景D：理论研究的数值例子都成立，但证明缺一类边界

13保留已完成推导、数值帮助及边界缺口，不把有限例子称为证明。原计划允许的边界推导继续；发现原前提不足回06。找不到证明记为未解决，满足前提的反例另作为真实证据，交14/15判断原命题。

### 场景E：档案或综述没有找到某项材料

记录实际检索/调阅范围、条目去向、访问和缺页限制。未找到不等于事件不存在；无法取得全文不等于研究未满足纳入标准。14可分析已获得材料并评价覆盖，15限制相应主张；若必要来源始终无法取得，按计划停止或提出有意义的范围修订。

## 10. 从取证动作到可核查产物

本节补第3—6节的具体开展办法，记录仍用第4节及00的既有位置。以下对象、读数、问题和处理情节均为教学构造，没有真实受试者、数据、运行、访谈、档案取证或新研究结论。具体路线只选所需段落，不强制所有研究有实验、代码、统计或录音。

### 10.1 执行者拿到已确认方案，怎样开始并结束当前一项工作

先引用有效方案、当前输入和必要12依据，确认本次要补的证据缺口。AI不再让用户重答选题、假说和期刊；只说明尚会阻断本次的实际未知，以及有依据的处理建议。若确认范围或进入条件不成立，沿第2节补具体缺口，不把它包装成可以立即执行。

构造一个同对象A/B测量任务，可按实际动作推进：

1. 对照本次对象及条件，找出正式输入和预定输出；打开适用协议，定位关键顺序、测量单位和失败判据。若只写“按标准方法”而标准版本、材料或装置不明，先补真正影响操作的部分。
2. 按计划安排对象与顺序，实际核身份及装置状态；需要分配、盲评或过程控制时落实该环节，不能仅在方案写有这些词。无此要求的路线不临时增设。
3. 实施本次取证，按会影响解释的时点记录实际操作及条件。原始读数、图像或原话联系对象和测次；操作失败也留下已发生事实。此处不把观察立即改写成支持假说的句子。
4. 核对产物：能读到什么、覆盖了哪些必要对象/条件、对照与原始数据是否存在、哪些缺失或偏离使比较受限。识别到技术问题先按10.2诊断；有效不利结果按原状保留。
5. 结束本项时，从原记录提取实际覆盖、产物、异常/修复、资源及剩余缺口供独立验收。只有当前必要工作和受影响依据可核查，才按其范围通过；所见方向不作通过标准。
6. 根据验收与剩余缺口决定下一项是否仍必要。已有覆盖可复用，不以“还剩列表中的几项”机械继续，也不把单项通过直接写成13阶段所有证据齐备。

足以交接的结果可以很短，但必须可回到实际产物。一次读数成功、脚本退出或访谈结束之后补写“已完成”而没有上述对象与证据关系，不能替代这个过程。

<a id="execution-detail-diagnosis"></a>
### 10.2 看到异常或零结果，怎样判断下一步

先冻结“目前看到的事实”，不以期待方向判断设备或代码。选最接近异常的一条原始记录，沿来源→输入/身份→操作→过程控制→输出解释寻找最早偏差；只检查能区分当前合理原因的事实，不能为每个负结果重新全面审计。

**构造分支**：计划中某参考检查的允许读数范围已定为9—11，某对象测得0。只有对象0，尚不能判断技术失败或可靠无现象；先看本次是否确为正确输入、单位、设置及操作，再看参考检查。若参考也读0，它至少使依赖该检查的测量能力未获支持，应查未实施、连接/模式错误、失效材料或设备状态；不能拿对象0反驳假说。若参考为10且其他必要条件成立，也只支持被该参考实际检验的能力，不能由一个控制推定所有构念、灵敏度和外推有效。随后交14分析精度和范围，15才判断“不支持、反证或仍不确定”。9—11是构造条件，不是任何仪器建议阈值。

异常有多种来源时用最小辨别步骤：原记录与导出不一致先查转换/单位；同一输入在不同实现出现差异先回11/12；某时段或批次失去控制时标出受影响区间，保留相邻仍有效记录。若故障状态不能追到何时开始，说明不确定区间及证据限制，不能随意只排掉最不利的一段。

图像取证同样先核能力：需要区分的结构是否有足够采样和正确尺度，信号是否在设备有效范围，照明、通道或时点差异是否与条件混同。直方图顶端堆积可能提示截断，也可能来自图像内容，须结合采集规格与原始像素判断；不能仅按16位文件上限认定未饱和。原件准备见[10原始影像指导](../10-数据与研究资源准备/数据与资源阶段详细手册.md#resource-detail-image)，具体采集协议与验证限值取自实际装置和方法。论文显示对比度或拼图不能修复原始取证能力。

<a id="execution-detail-resume"></a>
### 10.3 中断后续做：先分清恢复的是什么

中断后先读取当前真实状态和既有产物，不按最后一条聊天中的“完成”判断。构造例：12个预定条件中5个已取得有效产物，第6个只有部分结果，其余未执行。先核五个完成项确有当前版本的证据，再判断第6项能否续做；不能从第7项开始后把第6项默认为完成，也不能把前5个再跑一次当新增独立证据。

- **彼此独立的计算条件**：依据对象/条件标识与有效配置恢复待完成部分，核重复、漏项和旧缓存混入。变化影响前5项时按依赖补查，未影响则复用。
- **迭代训练或求解**：确认保存的是最终输出、模型权重还是可继续状态。PyTorch官方教程的通用检查点例包括模型、优化器、轮次等信息；只有权重通常不足以声称原训练完整续做。实际方法还可能需要学习率状态、随机过程、数据顺序/采样位置等；哪些已恢复、哪些不保证相同要说明，不能只重设初始种子便声称随机流接续。[PyTorch保存和恢复教程](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html)
- **现场/长时测量**：核中断改变了哪一时点、暴露时长、材料状态或随访窗口，不能直接套计算断点；只有方案允许且状态仍可解释才继续。失去的不可重复时点要保留缺失，不补造读数。
- **访谈/档案阅读**：已有片段和原始定位保留，注明中断处及后续联系；新一次谈话或新版本材料有新的情境，不能拼成一次连续原话。

恢复后先核一段必要状态与产物对应，按计划继续当前任务。是否能重现原轨迹、仅能继续原目标或必须作为新尝试，是三个不同判断。无法恢复而重做时保存前次部分证据与消耗；范围、方法或资源实质变化仍沿既有规则处理，不引入续做平台或新关口。

<a id="execution-detail-interview"></a>
### 10.4 访谈、焦点小组与观察，怎样取得有用材料

访谈前从已选方法和提纲提取本次要理解的经验或过程，准备必要的场景和记录方式。按已有访问与参与安排开始，说明谈话目的和方式，确认当下能正常记录；不把准备变成让参与者预先给研究答案。进入时用容易谈的具体情境，随后根据对方表达展开，避免照表逐项抢问。

**构造对话**：主问题可为“请讲讲最近一次你做这个选择的经过”。对方只说“很麻烦”时，先停顿并倾听，再追问“你说的‘麻烦’是哪一部分”“当时发生了什么”“后来怎样处理”。不能替对方解释成“所以是因为成本太高”，也不连续抛出多个问题迫使选择研究者的答案。对方用词不明时用其原词请澄清，不能把AI生成的理论术语塞回原话。

若对方说法前后不同，先询问是否谈不同时间、场景或经历；可以中性指出“前面谈到A，这里是B，能帮助我理解两次情况的区别吗”，不急着裁定矛盾或要求改口。离题内容可能揭示原提纲遗漏，也可能与当前问题无关；先判断其作用，再温和回到过程，不为了预期主题截掉反向经验。未发生过某种经历也可成为范围信息，不要求每个人都讲同样的故事。

结束前请对方补充重要但未谈内容，核必要的事实性澄清，及时记情境与研究者反思。直接原话、所见行为、事后记忆和分析想法分开；如果录音在某处失败，注明可定位到的录音与现场笔记范围，不能把记忆恢复成逐字引文。转写及译文核对见[10第9.5节](../10-数据与研究资源准备/数据与资源阶段详细手册.md#95-ocr转写与翻译从可搜索到可引用)。

焦点小组选择相应方法时，主持者注意谁回应谁、共识如何形成以及分歧或沉默的情境；不能只把发言拆成若干独立个体回答。可邀请愿意者补充不同经历，给尚未发言者机会，并避免某人持续替全组回答；没有发言不等于同意。需要怎样识别说话者和互动，依实际记录能力决定，不能一律规定组数、人数、助理或双录音。

观察路线先明确当前观察者的位置、时间、关注过程和参与程度。现场先写可定位的动作、顺序、环境与原话，再标研究者解释及疑问；“他不满意”应能区分是对方原话、某个可观察行为还是研究者推断。保留正常、反常和与预期不符的事件；记下场景无法进入、哪些过程没有被观察到，不能由片段推定整体普遍如此。

本节访谈操作借鉴质性Skill及DeJonckheere/Vaughn方法原文，属半结构访谈的有限适配；不能当所有民族志、会话分析或叙事传统统一技术。材料形成与初步分析可在方法允许时迭代，实际主题、解释与充分性由14/15处理；不是等全部访谈结束才允许思考。

### 10.5 理论与概念执行：推一步、核一步，而非只选证明名称

承接[07的构造命题计划](../07-制定实验计划/实验计划阶段详细手册.md#116-理论与概念计划先把缺桥指出来)：有限非空实数集合，`wᵢ≥0`且`W=Σwᵢ>0`，要说明加权均值位于最小值m和最大值M之间。实际书面推演应能逐步读出：对每项`m≤xᵢ≤M`；因权重非负，乘后得`wᵢm≤wᵢxᵢ≤wᵢM`；有限求和得`mW≤Σwᵢxᵢ≤MW`；因W正可除，得到目标上下界。这里分别指出了非负、有限求和及正分母的作用，不以“显然”跳过关键操作。

再核边界：零权重项允许且不影响和；所有权重零时分母不定义，原前提已经排除。若有人把主张扩大为“权重可为负但总和为正也必在区间内”，取`x=(0,1)`、`w=(2,-1)`，总和1、加权值-1，落在[0,1]外，才是满足新前提的真正反例。它不是对原非负命题的反驳。有限数值例可帮助发现这个候选反例，是否构成反例仍需核原条件与断言。

这段是教学级既有数学性质的构造说明，不是新理论成果。复杂研究中，某步不通先标缺失引理、引用条件或不允许的变换，尝试一条有理由的路线再检查；不能在证明中临时加前提，却仍声称原命题已证明。引用已有定理读原版本及适用条件，形式工具的结果也要核实际验证了哪个命题。

概念论证可逐段重构为“原文用法/经验事实→明确前提→推理→结论”，把价值前提与经验依据区分。若一个边界案例推不出原结论，先查它是否真属原范围、是否偷换定义、还是原论证缺经验桥梁；保留竞争解释和未解部分，不靠改写语句消除反例。方法取向沿06，实际材料联系10的原文定位，论证检查交14、允许主张交15。

### 10.6 档案取证：从一条线索到可核实的引用

先把当前问题转为可能的形成者、机构、时段及历史名称变体，再读所选馆藏范围和目录层级。假设一条人物线索命中了某系列：先看系列怎样形成和覆盖什么，再定位卷/件及原页，不直接把搜索片段当正文。若馆藏说明记录存在但没有数字化件，记为“已定位、尚未取得”，不要记“未找到材料”。

取得原页后核档号、页/图像位置、作者、收件者/受众、日期及上下文；OCR只用于发现候选词和定位，再回原页核要引用的段落。摘录保留省略、译文与原文关系，研究者的解释另标。若另一网页重复同一份转录，沿引用追到相同档号后视为同源传播，不增加独立证据数。两件材料叙述相冲突时，先保留各自形成时间、目的与来源关系，把冲突交14分析，不能只留更符合故事的一件。

具体网站示范可用NARA的Using the Catalog：了解目录可能同时检索描述、数字对象和OCR；用关键词及适用筛选缩小范围，沿Record Group/Collection/Series/File Unit等实际层级定位。仅筛“Available Online”会限制到可在线取得的部分，不代表馆藏全貌；其他机构按其本来层级和检索说明操作。该页有早期界面描述，本节不保证按钮位置，实际界面以当次显示为准。[NARA官方使用说明](https://www.archives.gov/research/catalog/help/using)

完成一轮后交代已检索的范围、词项、目录和实际取得/未取得状态，以及关键原页位置；一次空检索不能证明事件不存在。有限个案只对确认范围作论证，不自动补全国或全部馆藏，也不把联系档案员作为本轮已执行行为。

### 10.7 综述取证：让资格与抽取真正可判断

沿06/07已定综述目的执行，先把纳入条件转成材料能回答的几个具体判断。**构造例**：协议需要对象P、设计D和已测量结果O。标题摘要只看不出D，先进入可能相关/待全文，而非以资料不足排除；全文明确不属于D才能按对应标准排除。全文未取得是获取状态，全文有而资格信息仍不清是待判状态，符合资格但O的数值未报告又是另一种缺失，不能都记成“无数据、排除”。

若两份报告登记号、地点、时间与样本对应，同属研究S，一份报告主要结果、一份后续随访，应联系到S而非两项独立研究；不同随访或分析样本不一定数值相同。对应关系不确定时保留待核，不能只按作者或题名合并。抽取时先读表题、表头、单位、对象、时间点和脚注，再抄值及页表定位；把观察到的均值、变化值、组间差、标准差、标准误和区间分开，不因都是“±”就互换。

假设原表均值为10、标准误为2，只有当样本量、独立结构与统计量定义足以支持相应转换时，才可按方法推得标准差；缺这些依据时只保留原报值。报告间冲突先核勘误、分析群体、时间点和版本，再按协议理由决定用于该结果的来源，保留其余相关报告与冲突。自动抽取同样核源，不凭工具输出的置信标签直接验收。

筛选或抽取出现分歧时，先比较两方据哪个条件、哪段原文和哪项定义判断，修正模糊规则后检查受影响材料；不是只投票或取平均。Cochrane对其干预综述的最终纳入及结果抽取有独立人员要求，若实际声称遵循它，应落实相应要求，不能用代理数或AI自检冒充；其他综述按所采用方法说明独立性和限制，不统一新增人数。偏倚工具按实际设计与具体结果使用，表格填齐不等于评价充分。

检索记录、报告、研究及抽取结果的去向与数量联系起来后，14才能作相应综合；缺可合并结果不使符合资格的研究凭空消失。操作依据为[Cochrane第4章4.6](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04)及[第5章5.2、5.4—5.5](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05)，这里有限迁移资料判断，不强制所有综述采用健康干预方法或做元分析。
