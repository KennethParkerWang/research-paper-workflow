# 任务与阶段衔接规则

更新日期：2026-10-15。本页集中维护各阶段共用的运行规则。当前15主线与24个资料编号的归属见[完整科研流程](../docs/workflow-design.md)；各手册只补充本阶段特有的判断和验收依据。

## 确认与任务安排

01默认用户没有前期科研工作；02继承01确认的选题，默认用户没有假说；03继承01与02，默认用户未选刊。已有用户工作或选择仅在用户明确说明时接入，并核对适用范围。AI负责提出候选、解释依据与取舍、围绕关键问题逐轮询问，按反馈调整；用户不知道时提供可理解的选项。

三项分别由用户明确确认。对话中的局部偏好不等于阶段最终确认，独立代理核查依据质量，不替用户决定。保存确认对象、版本与约束；只有它们仍适用时继承已有确认，不能用选题认可替代假说或期刊确认。尚未确认时，不启动依赖该决策的工作。拟改变选题、核心假说或目标期刊时返回相应关口；日常工作由独立代理验收。

第9主线大阶段（目录13）另设[实验启动确认](../13-完成实验/实验启动确认规则.md)：AI承接已有设计、计划和步骤，与用户逐轮商讨目标、方法、待检验结论、关键细节及资源安排。独立代理核查方案质量，用户明确确认当前方案后才执行。启动讨论可在07／08方案形成后开展；确认记录包含范围、版本与约束，普通资料查阅及方案草拟可先准备，预实验、研究性试运行或正式取证必须在相应确认范围内。

每个大阶段保持中心职责，先依据具体设计形成候选小任务表，再用上一阶段交接结果修订。首次01由AI按[选题手册](../01-选题要求与确认/选题阶段详细手册.md)主动询问用户、从零形成方向；回退选题依据新证据或约束。每次只发布一项任务，该项结束后再判断剩余任务是否仍必要。考虑点、目录和文档段落都不自动等于单独任务。

任务至少交代目标与范围、已有输入、具体工作、应有成果、验收依据、预算与停止条件。发布指形成当前研究任务说明，外部发送按其实际授权处理。

## 执行与独立验收

共用循环为：**发布 → 执行 → 独立验收 → 更新证据与交接 → 检查临时材料 → 调整下一项。**

验收分别回答工作是否正确完成、证据意味着什么。这两个判断写在同一任务结果记录中，不能把科学结论是否符合期待作为执行通过条件。可靠反证可以完成任务，失败或无合适方案也可按事实终止；必要前提不成立时暂停依赖工作。

验收者检查当前任务的新增成果，并引用有效的已有验收。输入、实现、方法、主张或版本变化，或新证据、既有验收遗漏与错误影响其依据时，复查相关部分；文件未变不自动证明判断仍有效。需退修时明确发现、影响和通过条件；独立发现应经独立复查关闭。

完成时记录实际输入和版本、产物位置、偏离、验收结论、证据判断及剩余问题。结果可为支持、反驳、不确定或条件混合；解释与原始依据分开，保留异常及不利结果。

## 记录与交接

同一事实只维护一个正式位置。任务结果引用数据、代码、文献、推导和图表；阶段交接从这些记录提取下游需要的信息，不复制整套证据。具体课题选用已有正式记录格式，保持证据身份、位置和版本可辨认。

交接只增加接收者需要知道的内容：当前有效决策与产物链接、适用条件、未决事项、已失效内容、下一步输入及阻碍。接收者核对引用与前提，不重新开展已经通过且依赖未变的工作。没有新增交接事项时，引用现有记录并说明可继续即可。

正式结果、分析、科学判断和稿件可以分工维护，但共用来源与证据索引。03形成期刊匹配、要求高低与任务负担说明，04补充格式依据，05复用资料细化必要证据与预算，17增加表达建议；目标或相关要求变化时再更新对应内容。

24承接选刊或具体投稿疑问，维护论坛经验及其适用性判断，不把未经核实的比例、身份效应或个案改成科学要求；目标改变仍回03。18交初稿，23就当前文字处理表达、保留含义并交改稿及未决影响，19继续独立核科学主张与稿件。两阶段复用同一稿件、来源及既有备注，不新增固定证据表、检测记录或确认关口；已有可用表达及无关阶段不重做。

## 变更与回退

先判断最早受影响的位置，暂停直接及传递依赖，保留仍适用的成果。失效记录保留版本和理由；可复用部分不因其他部分改变而全部重做。

| 变化 | 处理位置 |
|---|---|
| 研究问题、对象或关键范围改变 | 返回01，由用户确认选题。 |
| 核心假说或对应研究预期改变 | 返回02，由用户确认。可靠反证本身不自动触发重新确认。 |
| 目标期刊改变 | 返回03，由用户确认，再更新相关校准或格式依据。 |
| 方法设计不成立 | 返回06；若涉及核心决策，再回相应确认关口。 |
| 新增验证或改变对照、测量、分析安排 | 先更新07／08与任务依赖；实验目标、核心方法、待检验结论、关键数据／参数／指标或资源安排实质变化时，回13商讨并由用户确认后执行，再补相应资源、实现与正确性检查。 |
| 原计划内补验，设计、输入与实现仍有效 | 还须已有有效用户实验确认且补验属于该范围；独立代理判断适用性后复用授权、准备与检查。未确认或确认已失效时先回13启动商讨。 |
| 数据、实现、分析或文字错误 | 修复来源，重查受影响成果；同步更新依赖它的结论、图表及稿件。 |

实验确认范围内的执行修复、重复运行和已约定补验继续逐项验收，无需每个任务再次请求用户确认。发现错误后若必须实质改变实验方案，先商讨并更新确认；独立代理不能代替该决定。

预算不足时缩小有意义的范围或调整资源，保留支撑实际主张的必要证据。期刊要求较低允许范围明确的小贡献，较高要求对应更充分的贡献与证据，不能用任务数量或方法复杂度替代判断。超出既有资源授权时提出具体取舍。

## 审查修订与交付

19负责科学主张、证据和稿件的独立审查。20组织缺陷修订，科学内容或稿件改变后重新经过19。21复用有效审查结论，核对交付版本、文件完整性、引用与未关闭问题；仅文件整理的问题在21复核。22固化通过验收的版本及依赖。

无问题时直接通过对应检查，不增加形式性的补缺任务。无法补齐必要证据时，根据实际影响调整主张、研究决策或按停止条件结束。当前终点是本地研究包，投稿与外部发送属于另行安排的工作。

## 临时材料处理

每项任务结束先确认正式成果、失败依据、复现材料和下游引用已保存，再检查实际临时内容。可重建且无引用的缓存或重复中间材料才属于处理候选；存疑材料保留。阶段交接与必要证据不能只存于临时位置。

无对象时记录无需处理。存在残留时，只要证据、交接与下一项执行不受损，可以登记待处理项继续；依赖或空间问题会阻碍执行时先解决。实际删除按明确目标与已有授权范围执行，唯一证据或不可恢复的处理另行确认。
